# 작업 방법

담당 폴더에서 작업하고 변경 사항은 Pull Request로 합칩니다. 한 사람이 여러 폴더를 맡을 수 있습니다. 다른 담당자가 사용하는 입출력을 바꿀 때는 contracts 변경을 함께 검토합니다.

새 기능은 해당 폴더 README에 실행 명령, 필요한 환경변수 이름, 테스트 방법을 추가합니다. 공통 실행 명령은 실제 통합이 된 뒤 작성합니다.

실제 원천 데이터, 계좌 정보, API 키, 토큰, 환경 파일과 학습 모델 파일은 커밋하지 않습니다. 환경변수 예시는 값이 비어 있는 파일로만 작성합니다. Fabric 연결 자격증명과 클라우드 비밀값은 연결 설정 및 Key Vault에서 관리합니다.

분석 결과에는 데이터 기준 시각, 관측 범위, 사건 ID, 사용한 계산 방식과 검증 상태를 남깁니다. 실험 코드를 옮겼다는 이유로 정식 기능으로 표시하지 않습니다.

공개 저장소이므로 누구나 열람하고 복제할 수 있습니다. 팀원의 직접 push 권한은 별도 초대가 필요합니다. 초대 전에는 fork와 Pull Request로 참여할 수 있습니다.
