새 예측에는 Huber 또는 뉴스 AI 보정값을 합치지 않습니다. 기존 Huber 모델과 뉴스 입력 재계산 기능은 보존합니다.

학습과 구간
2023년까지 학습, 2024년 구간 보정, 2025년 이후 평가입니다. 경계의 미래 타깃은 제거했습니다.
이번 연결 작업에서 모델을 재학습하거나 테스트로 튜닝하지 않았습니다.
기존 로컬 Test의 25,747개 중심값을 재계산해 일치를 확인했습니다.
화면의 기존 90% 구간 계약을 지원하도록 2024년 자료만으로 80/90% 구간을 보정했습니다.
서로 독립적으로 학습한 q10/q50/q90의 envelope에 비음수 보정량을 더합니다.
이 명목 구간은 실제 포함률 보장이 아닙니다. 연구 결과의 구간 포함률은 목표에 미달했습니다.

입력 10개 (순서 고정)
shock_usdkrw_pct, shock_us10y_bp, shock_wti_pct, shock_vix_pt,
kospi_vol20, kospi_trend20, vix_level, us10y_level, usdkrw_trend20, wti_level
충격은 사용자가 선택한 기간 전체에 대한 가정입니다. 5일 값을 나누거나 곱해 다른 기간의 결과를 만들지 않습니다.
KOSPI 미래 수익률은 이 단독 CatBoost 입력에 사용하지 않습니다.
과거 성능 평가는 실제 미래 거시 충격을 사용한 조건부 평가이며 순수 사전 주가 예측 성능과 구분합니다.

API 호환성
기존 서명 경로 /service/metadata 및 /service/predict/auto만 재사용합니다.
플랫폼 인증 제외 경로와 JWT 검증은 변경하지 않습니다.
GET /metadata: 기존 응답은 유지하고 catboost_multihorizon 하위에 새 지원 정보를 추가합니다.
POST /predict/auto: horizon_days를 명시한 model=catboost 요청만 새 모델로 처리합니다.
기간을 생략한 기존 요청은 기존 5일 모델로 처리합니다. Ridge를 1/20일로 가장하지 않습니다.
operation=catboost_history 및 snapshot_sha256을 명시하면 같은 서명 경로로 Train 유사 사례를 조회합니다.

공통 API와 웹
새 화면은 X-StressLab-Client-Contract: catboost-multihorizon-v1을 전송합니다.
이 표식은 인증 수단이 아니라 구버전 화면의 가격 환산을 보존하기 위한 요청 계약 구분입니다.
표식 없는 기존 화면은 기존 5일 계약을 유지합니다. 기존 로그인·APIM 구독·서명 검증은 별도로 적용됩니다.
GET /api/stress/support: 새 화면에 20종목과 [1,5,20]을 반환합니다.
POST /api/stress/analyze: horizon_trading_days로 선택한 기간을 계산합니다.
POST /api/stress/catboost/history: 같은 분석 스냅샷에 고정한 Train 사례를 최대 5개 반환합니다.
각 사례는 2024년 이전에 타깃이 종료되며, 선택 사례 간 기간이 겹치지 않게 합니다.
가격 기준은 Gold의 수정주가입니다. 현재 실시간 미수정 시세를 모델 기준가 대신 사용하지 않습니다.
예측 종가 = 기준 수정종가 × exp(예측 로그수익률 / 100).
일별 종가 예측 종점을 반환하며, 중간 모든 거래일을 별도로 예측했다는 뜻은 아닙니다.

입력 파이프라인
기존 PostgreSQL conditional-v4의 header 1행 / 20종목×3기간 state를 한 SQL 스냅샷으로 읽습니다.
골드/스테이징/서빙 테이블 스키마를 변경하거나 삭제하지 않았습니다.
state의 패키지 ID와 새 CatBoost의 패키지 ID는 의미가 다르므로 각각 보존합니다.
학습 데이터 버전과 현재 state 데이터 버전도 분리해 표시하며 허용된 스키마·버전·유한값·종목 수를 검증합니다.
기존 주기적 state 갱신은 재사용합니다. CatBoost를 다시 학습할 때는 새 패키지와 이미지가 별도로 필요합니다.
