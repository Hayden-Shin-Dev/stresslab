## 보존 범위

- 시나리오 전체 페이지, 그래프 엔진, 모델·기간·충격 입력, API·인증·DB 스키마를 유지.
- 자산 중복 처리는 기존 서버 합산 정책을 사용. 서버 저장 전 선택 표시를 성공 상태로 바꾸지 않음.
- 조회 시세·평가금액과 실행 기준 시세·투입금액은 구분하여 표시.
- 수치 설명 문장은 유지하고 수치 비교표를 추가. 소수 비율은 원본 × 100으로 % 표시(표 아래 명시). %p·상관계수는 원래 단위 유지. 원본 자료는 변경하지 않음.
- 기존 저장 대화 중 구조화 수치 메타데이터가 없는 항목은 기존 인용 텍스트 유지. 새 응답부터 표 제공.
- 반응형은 기존 전체 화면 축소 방식을 유지. 모바일에서 정보가 작게 보이는 기존 한계는 남아 있음.

## 검증

- Node: 기존 스트레스 차트·데이터 10개, 기본20종목/부분수신/수치단위 3개 통과.
- 실제 Chromium 렌더링 + 로컬 fixture API: 20종목, 검색, 미수신, 로그인 연결, 필수값 오류, 저장 실패→입력 보존→재시도, 동일 종목 합산, 모션 감소, 포트폴리오→스트레스 요청(3주 × 178,850원 = 536,550원), 에이전트 표 6개 수치, 기존 뉴스·문서·채팅 회귀 통과.
- 1440/768/390px에서 패널 수평 넘침 및 JS 오류 없음. 데스크톱 스크린샷에서 포트폴리오/결과 강조와 기존 그래프 보존 확인.
