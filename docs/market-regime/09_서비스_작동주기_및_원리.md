# 09. 시장 국면 분석 서비스 — 작동 주기와 작동 원리

> 과거 데이터 기반 시장 분석이며 투자 권유·종목 추천·수익 보장이 아닙니다.

---

## 1. 서비스가 하는 일 (한 문장)

매일 장 마감 확정 데이터로 **KOSPI 시장이 지금 상승장·횡보장·폭락장 중 어디에 있는지** 판정하고, 국면 이력과 현재와 비슷했던 과거 시기를 보여 줍니다.

---

## 2. 작동 주기

### 2.1 무엇이 언제 바뀌나

| 대상 | 주기 | 계기 |
|---|---|---|
| 입력 데이터 (팀 Gold) | 하루 1~2회 (08:00·12:00 수집 후) | 팀 파이프라인 |
| 국면 계산 (`PL_MarketRegime_Daily`) | **하루 1회** (일정 10:30 또는 12:30 KST, 현재는 꺼져 있어 수동 실행) | 일정 / 수동 |
| 분석 기준일 | 실행 때마다 **직전 거래일 종가** 기준 | 팀 Gold 최신일 |
| 국면 확률 (상승·횡보·폭락) | 하루 1회 | 새 거래일 데이터 |
| 국면 라벨 | 새 국면 확률 0.6 이상이 **5거래일 연속**일 때만 변경 | 깜빡임 방지 규칙 |
| 모델 재학습 | **21거래일마다** (약 한 달) | walk-forward 규칙 |
| 유사 시기 Top 5 | 하루 1회 | 새 거래일 데이터 |
| Power BI 보고서 | 계산 직후 바로 | Direct Lake 자동 반영 |
| API·웹 (연결 후) | 계산 → DB 복사 직후. API는 최대 5분 캐시, 웹은 팝업을 열 때 조회 | — |
| 장중 | **변하지 않음** | 장중 실시간 데이터는 쓰지 않음 |

- 주말과 휴장일에는 새 거래일이 없으므로 실행해도 기준일과 결과가 같습니다.
- 과거 날짜의 판정은 그날까지의 데이터로만 계산했으므로 새 데이터가 들어와도 바뀌지 않습니다. 팀 Gold의 과거 값 자체가 수정된 경우만 예외입니다.

### 2.2 하루 흐름 예시 (일정 10:30 기준)

| 시각 (KST) | 일 |
|---|---|
| 08:00 | 팀 수집 → Bronze → Silver → Gold, 인증 스냅샷 발행 |
| 10:30 | `PL_MarketRegime_Daily` 시작 (R01 → R02 → R03, 약 8분) |
| 약 10:40 | `LH_MarketRegime` 갱신 → Power BI 바로 반영 → (연결 후) PostgreSQL 복사 |
| 이후 | 사용자가 웹 팝업을 열면 API에서 최신 스냅샷 조회 |
| 장중 | 국면 화면은 그대로. 장중 변화는 팀 실시간 화면에서 확인 |

사용자 안내 문구: *"시장 국면은 하루 한 번, 직전 거래일 장 마감 기준으로 갱신됩니다. 국면이 바뀌려면 새 국면 신호가 5거래일 연속 확인되어야 합니다."*

## 3. 작동 원리

### 3.1 입력
팀 인증 Gold(`gold_stress_daily` v1.1)만 읽습니다.
- KOSPI 일별 종가: KRX 공식 API → `silver_kospi_daily` → Gold `kospi_close`
- 20종목 수정주가 종가·거래량
- 원/달러, 미국 10년물, WTI, VIX, 국고채 3년

Gold가 `ready`가 아니거나 해시가 맞지 않으면 계산을 시작하지 않습니다.

### 3.2 계산 3단계

| 단계 | 노트북 | 하는 일 |
|---|---|---|
| ① 시장 상태 지표 | NB_R01 | 날짜별 20일 수익률, 20일 변동성, 하락 종목 비율, 종목 간 상관, VIX, 환율 변화 등 계산 |
| ② 국면 판정 | NB_R02 | **HMM(은닉 마르코프 모델)**이 지표 6개로 3개 국면의 확률을 계산합니다. 그날까지의 데이터만 쓰고, 21거래일마다 재학습합니다. 확률이 0.6 이상인 날이 5일 연속이면 라벨을 바꿉니다. |
| ③ 결과 게시 | NB_R03 | 국면 구간·요약·전환 빈도, 유사 시기(KNN) 계산 → 검사 통과 시에만 스냅샷 게시 |

### 3.3 HMM이 국면을 나누는 방식
- 시장 국면은 직접 보이지 않는 **숨은 상태**이고, 지표들은 그 상태가 만들어 낸 관측값이라고 가정합니다.
- 각 국면에서 지표들이 보통 어떤 값을 갖는지(평균·분산)와, 국면이 서로 바뀌는 확률을 함께 학습합니다.
- 그래서 오늘 지표 하나만이 아니라 **어제까지의 흐름**도 반영되어, 하루 이틀 튀는 값에 국면이 흔들리지 않습니다.
- 국면 이름은 상태별 "추세 − 변동성" 점수 순서로 붙입니다. 실제로는 **변동성 크기**가 국면을 가르는 주된 기준입니다. 폭락장은 급락과 급반등이 함께 나타나는 고변동 국면입니다.

### 3.4 유사 시기 (KNN)
오늘의 지표 11개를 표준화해 거리가 가장 가까운 과거 날짜 5개를 찾습니다. **이후 수익률은 계산하지도 보여 주지도 않습니다.** 예측이 아니라 비교 참고용입니다.

### 3.5 안전장치
| 장치 | 효과 |
|---|---|
| Gold 상태·해시 확인 | 검증되지 않은 데이터로 계산하지 않음 |
| 모듈 해시 확인 | 코드가 바뀌면 멈춤 |
| 팀 Lakehouse 보호 | 팀 `lh_whatif`에는 쓰지 않음 |
| 게시 전 검사 | 기준일 불일치, 이력 부족, 합성 데이터면 게시하지 않음 |
| 원자적 교체 | 모든 기록이 끝난 뒤에만 최신 포인터를 바꿈 → 화면이 중간 상태를 보지 않음 |

---

## 4. 이 서비스가 하지 않는 것
- 미래 수익률·국면 예측, 매수·매도 신호, 종목 추천
- 장중 실시간 판정 (장중 상태는 팀 실시간 파트가 담당)
- 스트레스 테스트·충격 시뮬레이션 (시나리오 분석 메뉴가 담당). 시장 국면 화면에는 사용자 입력이 없습니다.
