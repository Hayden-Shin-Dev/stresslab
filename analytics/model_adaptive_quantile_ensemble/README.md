# 적응형 수익률 분위수 앙상블

## 로컬 실행

```powershell
.\.venv\Scripts\python.exe analytics/model_adaptive_quantile_ensemble/train_adaptive_ensemble.py --out analytics/outputs/model_adaptive_quantile_ensemble_rerun
```

기존 종목 상태 CatBoost와 Huber의 학습 파일은 `analytics/outputs/model_catboost_asset_state`, `analytics/outputs/model_huber_interactions`에서 읽습니다. 데이터 버전, 학습 행 수, 평가 행 해시와 종목 목록을 대조합니다. 기본 출력은 `analytics/outputs/model_adaptive_quantile_ensemble`입니다. `run_info.json`과 `validation_choices.csv`에 기간별로 실제 선택된 가중치와 보정식을 기록합니다.

## 데이터 분할

- 로컬 Gold를 한국 거래일로 정렬한 뒤 기준일과 목표일, 종목의 키를 사용합니다. 1·5·20거래일 후 종가로 `y = 100 × ln(close[t+h] / close[t])`를 계산합니다. 기존 D/E 품질 조건을 공유합니다.
- 2020년 이전에 전체 기간 CatBoost와 Huber를 적합한 기존 모델 파일을 재사용합니다. 새로운 최근 가중 CatBoost는 이 학습 구간의 2010년 이후 행으로 학습합니다. 가중치는 `2^(-경과 연수/5)`이며, 각 기간·분위수의 반복 수는 기존 CatBoost가 2017~2019년으로 선택한 수를 사용합니다.
- 2020~2021년에는 중심값의 혼합 가중치를 MAE로, 꼬리 분위수의 혼합 가중치를 평균 pinball loss로 선택합니다. 합이 1인 가중치에 0.25 단위 격자를 사용합니다.
- 2022년에는 고정 보정과 최근 63·126·252거래일 보정, 양측 공동 점수와 위·아래 별도 점수, 정규화 수익률과 예측 반폭 대비 점수를 비교합니다. 90% 구간의 실제 포함률이 88% 이상인 후보 중 구간 점수가 가장 낮은 방식을 선택합니다. 이 조건을 만족하는 후보가 없으면 전체 후보의 구간 점수를 비교합니다. 이 실험에서 사용한 선택 기준입니다.
- 2023년 이후는 가중치와 보정방식 선택이 끝난 뒤 평가합니다. 기준일에 아직 종가가 확정되지 않은 행은 앞 구간에 포함하지 않습니다. 롤링 방식은 정답 종료일이 기준일보다 앞선 오차만 사용합니다. 최근 창 내 표본이 200행보다 적을 때는 고정 보정값을 씁니다.

## 모델 입력과 계산

- CatBoost는 기존 종목 상태 모델의 수치 30개와 종목·업종 범주 2개를 사용합니다. 네 충격은 환율과 WTI 변화율(%), 미국 10년물 변화(bp), VIX 차이(pt)입니다. 시장 피처는 코스피 5·20일 추세와 60일 낙폭, 20일 변동성, 환율 20일 추세, 미국 금리·WTI·VIX의 수준 및 변화, 국고채 3년물 수준과 20일 변화입니다.
- 종목 피처는 5·20일 수익률, 코스피 대비 20일 강약, 같은 날짜 20일 수익률 순위, 60일 낙폭, 20·60일 변동성과 비율, 코스피·환율·미국 금리·WTI·VIX에 대한 60일 베타입니다. 베타는 과거 종목 수익률과 요인 변화의 공분산을 요인 변화의 분산으로 나눈 값입니다. 범주값의 결측은 unknown으로 표시합니다.
- 충격은 코스피 변동성 척도로 나눕니다. 종목 정답은 `s = max(0.05, sqrt(h × (vol20² + vol60²)/2))`로 나눠 학습하고, 최종 출력에 `s`를 다시 곱합니다.
- CatBoost는 2.5·5·10·50·90·95·97.5% 분위수 각각의 pinball loss를 최적화합니다. 두 CatBoost 분위수는 오름차순으로 정렬한 뒤 가중 평균합니다. Huber는 기존 수치 입력 10개와 상태×충격 곱 24개를 표준화한 뒤, 작은 잔차에는 제곱 손실, 큰 잔차에는 선형 손실을 적용합니다. 중심값은 두 CatBoost의 중앙값과 Huber 중심값의 가중 평균입니다.
- 구간 후보가 공동 보정이라면 `max(L-y, y-U)`의 목표 분위수를 양쪽에 적용합니다. 별도 보정이라면 `L-y`와 `y-U`의 분위수를 각각 적용합니다. 선택된 방식으로 80·90·95% 구간을 계산합니다.

동일 평가 행에서 튜닝 Model E 고정·롤링, 기존 종목 상태 CatBoost, Huber, NGBoost와 비교합니다. 실현 시장충격을 입력하는 리서치이며, 과거 공개시각이 확인되지 않았고 평가 기간도 기존 실험에서 사용했습니다.
