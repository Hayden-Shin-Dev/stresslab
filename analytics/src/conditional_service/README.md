# 조건부 스트레스 로컬 연구

최신 연결 기준은 [최종 서비스 API](SERVICE_INTEGRATION.md)입니다. `api:app`과 `tiered_service:app`은 동일한 고정 모델을 사용합니다. 아래 연구별 실행 안내는 기록으로 보존하며 새 모델 실험은 하지 않습니다.

현재 로컬 서비스 후보는 확정했습니다. [최종 비교와 오류 점검](FINAL_CANDIDATE.md)을 확인하세요. 추가 모델 실험은 이번 비교로 종료합니다.
현재 API는 최종 50종목 모두에 네 충격을 입력받습니다. [종목 확대 및 네 충격 분석](FOUR_SHOCK_SERVICE.md)은 이전 연구 기록입니다.
현재 충격별 지원 후보와 실행 방법은 [선정 종목 서비스 검증](SELECTED_SERVICE.md)을 확인하세요.
현재 민감도 서비스 후보의 계산식, 실행 방법과 검증 결과는 [SENSITIVITY.md](SENSITIVITY.md)에 있습니다. 아래 내용은 보존한 초기 연결 실험입니다. 새 후보는 종목별 계수로 무충격 기준값, 충격별 기여도와 가상 손익을 계산합니다.

Gold v1.1을 읽어 직전 확정 일별 시장 상태와 이후 5거래일 실제 충격, 종목 수익률을 구성합니다. 사용자 충격 0은 해당 변수 수준 유지입니다. 금리는 bp, 환율과 WTI는 %, VIX는 지수 포인트입니다.

## 실행

저장소 루트에서 `PYTHONPATH=analytics/src`를 설정합니다. Python에는 numpy, pandas, pyarrow, scikit-learn, threadpoolctl, joblib, fastapi, httpx가 필요합니다.

```text
python -m conditional_service.state_comparison --gold data/dev_gold/gold_stress_daily.parquet --out outputs/state_comparison
python -m conditional_service.train --gold data/dev_gold/gold_stress_daily.parquet --out outputs/service_candidate --research
python -m conditional_service.verify --gold data/dev_gold/gold_stress_daily.parquet --bundle outputs/service_candidate/bundle.joblib
```

## 구현 범위

`core.py`는 입력 검사, 피처 생성, 부분 풀링 팩터 회귀, 과거 환경 검색과 보유금액 계산입니다. 종목별 계수는 공통 계수에 대한 편차로 학습합니다. 통계적으로 조건을 통제한 반응이며 독립적인 인과효과는 아닙니다.

`state_comparison.py`는 시장 비교를 계산에 연결하는 별도 실험입니다. 학습 기간의 시장 상태만으로 세 환경을 만들고, 유사도에 따라 각 환경의 학습 가중치와 계산 비중을 정합니다. 사용자 충격은 환경 선택에 사용하지 않습니다. 적은 사건만으로 재학습하지 않고 전체 학습 자료를 유지합니다. 환경별 결과와 전체 모델을 절반씩 혼합합니다. 세 환경, 혼합 비중과 정규화 강도는 고정한 개발 실험 설정이며 금융적으로 승인된 값이 아닙니다.

`api.py`는 기존 전체 팩터 모델 후보를 실행합니다. 새 유사도 가중 실험을 API나 운영 모델에 자동 반영하지 않습니다.

## 2026-11-04 결과

동일 표본에서 전체 팩터 모델과 유사도 가중 모델을 비교했습니다.

| 범위 | 전체 모델 MAE | 유사도 가중 MAE | 유사도 가중 방향 일치율 |
| --- | --- | --- | --- |
| 기존 20종목, 145일, 2,717행 | 4.561%p | 4.567%p | 57.64% |
| 추가 후보 포함 26종목, 155일, 3,627행 | 4.317%p | 4.317%p | 59.14% |

20종목에서 날짜 블록 재표본추출 기준 MAE 개선율은 -0.126%, 95% 구간은 -0.506~0.167%입니다. 개선 근거가 없습니다. 26종목의 80% 구간 포함률은 79.46%, 폭은 13.88%p이며, 실제 -5% 이하 급락 사례의 61.19%가 하한을 벗어났습니다. 최종 모델로 채택하지 않습니다. 두 종목 집합의 평균을 직접 비교해 종목 확대 효과라고 해석하면 안 됩니다.

학습, 보정, 평가는 시간순으로 분리하고 정답 종료일을 검사합니다. 2023~2026년은 반복 사용한 개발 평가 기간입니다. 실제 미래 충격을 사후 입력한 반응 재구성이며 사전 예측이나 인과효과 검증이 아닙니다. 현재 입력의 공표 시각 누락 때문에 완전한 시점 정합성은 미확인입니다. 추가 6종목의 과거 권리변동 전체도 미인증 상태입니다.

## 남은 연구

일별 충격 경로와 지연 반응, 시간순 외표본 잔차를 이용한 비선형 보정은 이번 연결 실험에서 구현하지 않았습니다. 사용자 입력은 5일 누적 충격이므로 일별 경로를 사용하려면 별도 가정을 표시해야 합니다. 최종 손익은 종목 중심값과 보유금액을 곱해 합산하며, 종목별 구간을 더해서 포트폴리오 확률 구간으로 표시하지 않습니다.

Azure, Gold 계약, 운영 모델은 변경하지 않았습니다.
