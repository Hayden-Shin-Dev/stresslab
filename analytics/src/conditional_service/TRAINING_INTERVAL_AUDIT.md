# 중심값과 구간 계산 검수

2026-11-05 로컬 결과입니다. 개별 종목이라는 이유로 불가능하다고 결론 내리지 않고, 계산 방식의 영향을 분리했습니다. Azure, Gold 계약, 기존 모델 파일은 변경하지 않았습니다.

## 비교 조건

50종목, 2023-01-02~2026-10-22의 동일한 85개 날짜, 4,150개 종목 관측을 사용했습니다. 모든 방식의 실제 정답이 같은지 검사했습니다. 이전 보고서의 4,100개 표본은 미국 보조 자료가 없는 날짜를 제외한 것이며, 이번에는 해당 입력을 사용하지 않습니다.

기존 Gold 파생 입력, Ridge alpha=100, 종목별 최근 최대 2,520행, 분기별 재학습을 유지했습니다. 학습 정답 종료일과 공표 확인 시점 모두 분기 시작 이전이어야 합니다. 미래 5거래일의 실제 네 충격을 사후 입력하는 조건부 재구성 평가입니다. 가상 충격의 정답이나 인과효과 검증은 아닙니다. 반복 사용한 개발 기간이며 독립 블라인드 결과가 아닙니다.

## 구현에서 확인한 부분

1. `gold_quarterly_trial.py`의 `fit_predict`는 잔차가 아닌 학습 수익률 전체의 분포를 붙입니다. 원본 B134를 따른 설계이지만, 중심값이 설명한 부분을 제외한 오차 구간은 아닙니다. 중심값을 개선해도 이 구간이 자동으로 좁아지지는 않습니다.
2. 같은 함수에서 CatBoost는 중앙값을 학습하지만, 붙이는 분포는 평균을 뺍니다. 따라서 출력 중앙값이 학습한 중앙값에서 다시 이동합니다. CatBoost용 비교에서는 분포 중앙값을 빼도록 수정했습니다. 원본 Ridge의 평균 위치와 분포 중앙값이 다른 것 자체를 버그라고 판정하지 않았습니다.
3. `prep`의 EWMA는 양수 가격만 확인하고 품질 상태나 거래 공백을 검사하지 않습니다. 별도 수정 경로에서는 전체 거래일 달력에 맞추고 유효한 연속 가격만 사용했습니다. 평가 174행의 변동성이 바뀌었지만, 전체 MAE 변화는 약 0.00004%p였습니다. 큰 오차의 주원인은 아니었습니다.

원본 분기별 Ridge 결과는 최대 0.000000000001%p 이내로 재현됐습니다. 기존 결과를 재현한 다음 수정안을 비교했습니다.

## 중심값 검증

기존 방식은 로그수익률을 변동성으로 나눠 학습한 뒤 예측값에 현재 변동성을 곱합니다. 이 과정에서 시장 상태에 따른 양수 기준값도 고변동성에서 확대될 수 있습니다. 이는 구현 오류라기보다 학습 목표와 함수 형태의 문제입니다.

동일 Ridge가 일반 수익률을 직접 학습하도록 한 가지 대조 실험을 추가했습니다. 구간은 기존 폭 그대로 중심만 이동해 중심값 효과만 확인했습니다. 이 이동 구간을 새로 보정된 서비스 구간으로 승인한 것은 아닙니다.

| 지표 | 기존 정규화 위치값 | 수익률 직접 학습 |
|---|---:|---:|
| 중심값 MAE | 4.999%p | 4.869%p |
| 방향 일치율 | 52.63% | 52.66% |
| 급락 표본 중심값 MAE | 9.246%p | 9.217%p |
| 90% 구간 포함률 | 88.39% | 88.77% |
| 90% 전체 폭 | 20.58%p | 20.58%p |
| 급락 표본 하단 이탈률 | 28.05% | 27.18% |

40/50종목에서 MAE가 감소했습니다. 날짜별 평균 오차 개선은 0.127%p이며 날짜 블록 재표본추출 95% 구간은 0.063~0.202%p입니다. 최근 2025~2026년 MAE는 6.025→5.817%p지만 방향 일치율은 50.22→49.39%로 낮아졌습니다. 단순 0 수익률 기준선 전체 MAE 4.621%p보다 여전히 나쁩니다. 새 최종 모델로 선정하지 않았습니다.

| 종목 코드 | 기존 MAE | 수정 MAE |
|---|---:|---:|
| 066570 | 5.249 | 4.692 |
| 000660 | 7.226 | 6.727 |
| 010130 | 7.408 | 6.988 |
| 207940 | 2.914 | 3.070 |
| 010950 | 4.052 | 4.189 |

충격 입력도 변동성 단위로 맞추는 별도 대조는 평균 MAE 개선 약 0.001%p이며 불확실성 구간이 0을 포함했습니다. 효과가 입증되지 않았습니다.

## 급락 때 놓친 계산

종목마다 가장 큰 급락 오차 두 개씩 100개를 추렸습니다. 그중 88개는 무충격 모델 기준값이 양수였고, 67개는 충격 효과가 음수였지만 최종 모델값이 양수인 사례가 84개였습니다. 실패 사례를 고른 진단이며 전체 급락 빈도로 해석하면 안 됩니다.

LG전자 2026-06-05 기준 5거래일 사례는 실제 -25.58%, 기존 위치값 +4.12%였습니다. 무충격 모델 기준값 +17.56%에서 충격 효과 -13.44%를 차감한 결과입니다. 직접 수익률 학습도 +2.29%로, 큰 실패를 해결하지 못했습니다. 한국가스공사 2024-11-27 사례는 실제 -27.06%인데 기준값 -0.39%, 충격 효과 +0.40%, 최종 +0.01%였습니다.

즉 일부 사례는 시장 상태 기준값이 과도하고, 일부는 관측한 네 충격과 학습 계수가 큰 하락을 설명하지 못했습니다. 어떤 미관측 기업 사건이 원인인지는 이 계산만으로 단정하지 않았습니다. 네 충격 기여도는 로그수익률 단위에서 합계가 실제 모델 변화와 일치하는지 검사했습니다.

## 구간 폭 검증

매 분기 이전 1년의 시간순 외표본 잔차로 바꿨습니다. 보정 관측은 종목·분기별 79~143개이며 겹치는 5일 구간이므로 독립 사건 수가 아닙니다. 평가 시점에 정답과 공표 확인이 끝난 잔차만 사용했습니다.

아래는 중심값을 완전히 동일하게 고정한 비교입니다.

| 90% 구간 | 학습 수익률 분포 | 이전 외표본 잔차 분포 |
|---|---:|---:|
| 전체 폭 | 20.58%p | 20.26%p |
| 포함률 | 88.39% | 84.77% |
| 급락 표본 하단 이탈률 | 28.05% | 37.50% |

폭이 0.32%p 줄었지만 포함률과 하방 포착이 악화돼 채택하지 않습니다. 잔차의 중앙값까지 추가 보정하면 중심값 MAE도 5.105%p로 나빠집니다. 잔차를 사용한다는 이유만으로 더 정확한 구간이 되는 것은 아닙니다.

CatBoost 중앙값 정렬 수정은 MAE 4.673→4.682%p, 90% 폭 20.69→20.72%p였습니다. 출력의 중앙값 정의는 일치시켰지만 큰 폭과 중심값 오차를 해결하지는 못했습니다. 이 CatBoost 대조는 공표 시각이 완전히 검증되지 않은 장기 연구 자료로 학습한 경로이므로 운영 승격 근거로 사용하지 않습니다.

## 결론과 실행

품질 필터와 CatBoost 중앙값 정렬의 수정 경로를 구현했습니다. 중심값 정규화 방식도 실제 오차에 일부 영향을 줬지만, 급락 실패와 넓은 구간을 모두 해결했다는 결과는 아닙니다. 구간을 억지로 줄이거나 종목별 좋은 결과만 골라 채택하지 않았습니다.

코드는 `training_interval_audit.py`, `report_training_interval_audit.py`, `center_scale_audit.py` 순서로 실행합니다. 기존 로컬 연구 폴더에서 `PYTHONPATH`에 이 저장소의 `analytics/src`를 지정하고 각각 `python -m conditional_service.모듈명`으로 실행합니다. 원천 파일 위치는 코드에 명시돼 있습니다.

결과는 [training_interval_audit_evidence](training_interval_audit_evidence)에 있습니다. `per_asset.csv`와 `center_scale_per_asset.csv`는 전 종목 결과, `crash_attribution.csv`는 실패 계산 분해, `splits.csv`는 시간 경계, `paired_ci.csv`는 날짜 블록 비교입니다. 보호 대상 데이터와 운영 모델의 해시도 변경되지 않았습니다.
