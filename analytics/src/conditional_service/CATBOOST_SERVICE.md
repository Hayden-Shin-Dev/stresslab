# CatBoost 서비스 연결

사용자가 선택한 종목별 CatBoost로 로컬 서비스 모델을 정정했습니다. 업종 Ridge는 비교 기준으로 보존합니다. Azure와 Fabric은 변경하지 않았습니다.

## 같은 조건 비교

20종목, 2023~2026년 85개 평가일, 동일한 1,600건입니다. 학습일, 보정일, 정답과 변동성 계산은 같으며 기존 CatBoost 설정을 바꾸지 않았습니다. 보정 기간의 종목별 외표본 잔차로 80%와 90% 구간을 만들었습니다.

| 항목 | CatBoost | 업종 Ridge |
| --- | ---: | ---: |
| 중심값 MAE | 4.746%p | 4.609%p |
| 방향 일치율 | 52.56% | 55.71% |
| 80% 구간 실제 포함률 | 68.19% | 69.69% |
| 80% 평균 전체 폭 | 13.50%p | 13.53%p |
| 90% 구간 실제 포함률 | 79.25% | 82.00% |
| 90% 평균 전체 폭 | 17.69%p | 18.01%p |
| 급락 사례에서 모델이 하락 방향을 낸 비율 | 69.96% | 49.38% |
| 급락 사례에서 모델도 -5% 이하를 낸 비율 | 2.06% | 2.06% |

급락은 실제 5거래일 수익률 -5% 이하인 243건입니다. CatBoost가 하락 부호를 더 자주 계산했지만 손실 크기까지 잘 잡았다는 뜻은 아닙니다. 0% 수익률 기준선 MAE는 4.639%p입니다. CatBoost가 전체 오차나 구간에서 더 좋은 모델이라는 결론은 아닙니다. 반복 사용한 개발 평가이며 독립 블라인드 검증도 아닙니다.

## 서비스에서 보여줄 것

CatBoost는 종목별로 시장 상태와 네 충격을 함께 입력받습니다. 사용자가 선택한 이 모델을 유지하고, 첫 결과에는 아래 내용을 반환합니다.

1. 충격이 없을 때와 입력했을 때 모델값이 얼마나 달라졌는지
2. 네 충격이 모델값 변화에 각각 얼마씩 기여했는지
3. 그 변화와 전체 모델 수익률을 보유금액에 적용하면 각각 얼마인지
4. 과거 유사 시장의 실제 충격, 종목 반응과 해당 종목 검증 오차

구간 폭을 줄이거나 숨겨서 정확도가 좋아진 것처럼 표시하지 않습니다. 검증된 80%·90% 위험 구간으로 제공할 수준이 아니므로 첫 결과에는 해당 구간을 쓰지 않습니다. 평가 수치는 `GET /model-info`와 응답의 `validation`에서 확인할 수 있습니다.

방향은 **무충격 대비 모델값이 증가했는지 감소했는지**입니다. 실제 미래 주가 방향이나 해당 충격만의 인과효과가 확인됐다는 뜻은 아닙니다.

예를 들어 2026-10-30 기준 환율 +1%, 나머지 변화 0으로 계산하면 다음과 같습니다.

| 종목, 보유금액 | 무충격 모델값 | 충격 적용 모델값 | 충격으로 바뀐 부분 | 변화분을 금액으로 환산 |
| --- | ---: | ---: | ---: | ---: |
| 삼성전자 100만원 | -0.261% | -0.065% | +0.196%p | 약 +1,960원 |
| 현대차 100만원 | -1.073% | -1.295% | -0.222%p | 약 -2,216원 |

이것은 실제 모델 계산 예시입니다. 첫 번째 종목의 변화분이 양수여도 최종 모델값이 양수라는 뜻은 아닙니다. 이 데이터 기준일은 오래된 상태로 표시합니다.

## 기여도 계산

CatBoost에는 고정된 선형 충격 계수가 없습니다. 네 충격을 24가지 순서로 추가했을 때 생기는 변화량을 평균해 기여도를 계산합니다. 모든 상호작용을 한 번씩 나누므로 네 기여도의 합은 `f(시장 상태, 사용자 충격) - f(시장 상태, 변화 0)`과 일치합니다. 별도의 24순서 계산으로도 대조했습니다.

기존 `sensitivities_pp_per_input_unit`는 CatBoost에서 `null`입니다. 대신 `shock_contributions_pp`와 `insight`를 사용하세요. 0을 넣은 충격은 해당 지표 수준을 0으로 만들지 않고 변화 없음으로 처리합니다.

환율 +5%와 +10%, 미국 금리 +100bp와 +200bp에서 20종목 모두 출력이 같았습니다. 트리의 큰 충격 반응 포화 현상이며, 영향이 같거나 없다는 의미가 아닙니다. 극단 입력은 지원 범위 밖으로 표시하고 기여도를 확정적인 충격 반응으로 설명하지 마세요. 단순한 범위 검사 통과도 정확도 보장은 아닙니다.

## 실행

```powershell
$env:PYTHONPATH = "$PWD\analytics\src"
$research = "C:\Users\shinm\OneDrive\문서\ChatGPT\새로운 프로젝트 2"
$ridge = "$research\reports\gold20_ready_20261109"
$cat = "$research\reports\gold20_catboost_20261109"
python -m conditional_service.gold_catboost --source "$ridge" --out "$cat"
python -m conditional_service.verify_gold_catboost --out "$cat"
$env:STRESSLAB_GOLD_BUNDLE = $cat
python -m uvicorn conditional_service.gold_ready_api:create_app --factory --host 127.0.0.1 --port 8161
```

`GET /model-info`의 `model_kind`가 `catboost`인지 확인하세요. `POST /analyze` 요청 형식과 20종목은 그대로입니다. 학습 결과는 요청마다 다시 만들지 않습니다. 로컬 결과 폴더의 `response.json`, `small_shock_response.json`에 실제 출력이 있습니다.

[전체 비교 결과](gold_catboost_results.json)에 종목별 결과와 동일 표본 검사, 보정 조건을 기록했습니다. 모델 파일과 원본 데이터는 로컬에 보존합니다. Fabric Gold의 수정주가 기준과 공표 근거를 연결하는 입력 검사는 [Gold 연결 문서](GOLD_READY.md)를 따릅니다.
