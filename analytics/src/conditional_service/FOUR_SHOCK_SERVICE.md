# 네 가지 충격 입력과 종목 확대

현재 로컬 서비스 후보는 확정했습니다. [최종 비교와 오류 점검](FINAL_CANDIDATE.md)을 확인하세요. 추가 모델 실험은 이번 비교로 종료합니다.
모든 분석 대상은 환율, 미국 금리, WTI, VIX를 입력받습니다. 민감도 근거가 부족하다는 이유로 입력을 막거나 영향을 0으로 바꾸지 않습니다. 이전 SELECTED_SERVICE.md의 미지원 충격 차단 방식은 보존한 이전 실험이며 현재 API에는 적용하지 않습니다.

## 종목 범위

KRX 공식 원본을 확보한 206개 후보에서 업종 노출을 기준으로 73종목을 검토했습니다. 73개에는 기존 17종목이 포함됩니다. 추가 73개가 아닙니다. 이미 확보된 원본을 재사용했으며 중복 다운로드하지 않았습니다.

| 구분 | 종목 수 | 제공 내용 |
| --- | ---: | --- |
| 정량 계산 후보 | 50 | 기존 17개 유지, 추가 33개. 네 계수와 가상 손익, 신뢰 수준 |
| 탐색 분석 | 18 | 학습된 계수와 가상 계산을 탐색용으로 표시, 실제 과거 사례 |
| 과거 사례만 제공 | 5 | 학습 이력이 부족해 수익률을 만들지 않고 실제 이력 제공 |

50개는 운영 승인이나 모든 충격의 신뢰성 입증을 뜻하지 않습니다. 종목 자체의 구분과 개별 시나리오의 근거 수준은 다릅니다. 정량 계산 후보라도 불안정한 충격, 드문 충격 조합, 외삽 입력이면 결과는 탐색용입니다.

전체 명단과 네 계수는 [service50.csv](results/support_expansion_20261104/service50.csv), 탐색 대상을 포함한 명단은 [service_tiers.json](results/support_expansion_20261104/service_tiers.json)에 있습니다. 보험, 증권, 지방은행, 운송, 조선, 유틸리티, 화학 등을 검토했습니다. 선정에 쓰인 업종은 경제적 노출 가설이지 기업별 인과효과 인증이 아닙니다.

## 선정 규칙

2021-12-12 이전에 정답이 완성된 자료만 사용합니다. 이력 5년 이상, 최근 252행 정상 비율 95% 이상, 겹치지 않는 학습 구간 100개 이상 기준은 유지했습니다. 네 민감도 중 3개 이상이 기존 안정성 기준을 통과하고, 네 계수의 평균 변동계수가 0.75 이하며, 경제적 노출 가설이 2개 이상인 종목을 우선 검토합니다.

기존 안정성 기준은 전체 학습과 종료일을 6, 12, 18개월 앞당긴 학습의 부호 일치, 변동계수 0.75 이하, 충격 사분위 범위당 반응 0.1%p 이상입니다. 서로 겹치는 학습 구간이므로 독립적인 재현 4회나 통계적 유의성을 뜻하지 않습니다.

기존 17개도 같은 종목 기준을 통과했습니다. 추가 후보가 33개보다 많아 부족한 업종과 충격 노출을 우선하고, 같으면 학습 계수의 변동이 작은 순서로 범위를 정했습니다. 평가 MAE는 순위에 사용하지 않았습니다. 현재 부분 풀링 학습에는 68종목을 이용하지만 최종 계산 후보는 50개입니다. 기존 17개는 이전 학습 모델을 그대로 사용합니다.

## 계산과 계수 출처

무충격 기준 모델값 + 환율 기여도 + 미국 금리 기여도 + WTI 기여도 + VIX 기여도 = 조건부 모델 수익률입니다. 각 기여도는 계수 × 입력 변화량입니다. 0은 변수 수준이 0이 된다는 뜻이 아니라 변화가 없다는 뜻입니다.

현재 계수 출처는 asset_partial_pool입니다. 공통 계수와 종목별 편차를 합친 추정값이며, 종목별 완전 독립 학습이 아닙니다. API에서 공통 부분과 종목별 편차도 확인할 수 있습니다.

불안정한 종목 계수를 공통 계수로 교체하는 방식도 비교했습니다. 학습 다음의 별도 보정 기간에서 표본 30개 이상, 급락 3개 이상, MAE 1% 이상 개선, 급락 과소평가 비악화를 요구했습니다. 여러 계수를 동시에 바꾸는 경우도 다시 검사했습니다. 통과한 경우가 없어 이번에는 교체하지 않았습니다. 업종 평균 모델의 성능이 좋다는 이유만으로 그 계수를 개별 종목에 그대로 넣지도 않았습니다.

불안정한 계수도 입력을 차단하지 않습니다. 기존 학습값으로 계산하되 unstable_exploratory 등으로 표시합니다. 모델을 만들 근거 자체가 부족한 5종목은 숫자를 꾸며내지 않고 null을 반환합니다.

A는 확정 일별 시장 상태로 과거 환경을 검색합니다. 사용자 충격을 바꿔도 최초 후보 날짜는 유지됩니다. 과거 사건의 실제 수익률과 B의 모델 수익률을 구분합니다. 종목 손익은 모델 수익률 × 보유 평가금액이며 별도 포트폴리오 ML은 없습니다.

## 전체 수익률 오차와 민감도 근거는 별도입니다

기존 MAE 4.119%p는 18종목, 155개 날짜, 2,642개 관측의 조건부 수익률 오차입니다. 100만 원이면 평균 절대오차 약 4만 1천 원에 해당합니다. 최대 오차나 손실 한도가 아닙니다. 실제 발생한 이후 충격을 사후 입력한 개발 평가이며 인과효과 검증이 아닙니다.

| 같은 표본의 기준선 | MAE | 모델의 상대 개선율 |
| --- | ---: | ---: |
| 0 수익률 | 4.269%p | +3.53% |
| 학습 표본 내 과거 업종 평균 | 4.295%p | +4.09% |
| 네 충격을 반영한 업종 Ridge | 4.106%p | -0.32% |

업종 기준선은 당시까지 학습한 자료만 사용했습니다. 미래 실제 업종 수익률은 입력하지 않습니다. 단순 업종 평균은 표본 내 평균이며 전체 KRX 업종지수 성과가 아닙니다.

새 50종목의 실제 API 모델 구성은 기존 17개 모델을 보존하고 추가 종목 모델을 연결합니다. 155개 날짜, 7,588개 관측에서 MAE 4.416%p입니다. 0 수익률 대비 개선은 1.66%지만 날짜 블록 95% 구간은 -0.93~+4.19%로 개선을 확정하지 못합니다. 충격을 반영한 업종 Ridge보다 2.05% 나빴습니다. 종목 확대를 성능 개선으로 보고하지 않습니다.

## 충격 민감도 검증

각 충격에 대해 나머지 세 충격과 시장 상태를 학습 자료로 조정했습니다. 평가 구간에서 남은 충격 변화와 종목 반응의 관계, 부호 일치, 충격 반응 오차, 연도별 계수 안정성을 따로 계산했습니다. 관측되지 않은 요인을 제거한 순수 인과효과는 아닙니다.

50종목에서 모델 방향과 같은 외표본 관계의 95% 구간이 0을 제외한 조합은 환율 21개, 미국 금리 0개, WTI 6개, VIX 33개입니다. 여러 비교를 고려한 근사 BH q값 0.1 기준까지 적용하면 각각 18개, 0개, 4개, 29개입니다. 이 수치를 보고 종목을 다시 골라내지는 않았습니다. API의 근거 수준에 반영합니다.

예를 들어 대한항공의 WTI 관계는 이번 조정 후 외표본에서도 음의 방향을 보였지만, S-Oil은 양의 점추정에도 구간이 0을 포함했습니다. 두 학습 계수가 반대라는 사실만으로 둘의 반응이 동일하게 검증됐다고 설명하면 안 됩니다. 미국 금리는 학습 계수의 안정성과 별개로 이번 개별 종목 외표본 근거가 약했습니다.

조정 관계 진단은 확대 학습군 기준입니다. 기존 17개 API 모델의 실제 수익률 성능은 별도로 평가했습니다. 이를 같은 모델의 검증이라고 섞지 않습니다. 상세 결과는 [shock_evidence.csv](results/support_expansion_20261104/shock_evidence.csv), [served_per_asset.csv](results/support_expansion_20261104/served_per_asset.csv)에 있습니다.

## 실제 복합 충격 예시

환율 +1%, 미국 금리 +10bp, WTI +5%, VIX +1포인트, 각각 100만 원 보유를 입력했습니다.

| 종목 | 환율 기여도 | 금리 기여도 | 유가 기여도 | VIX 기여도 | 기준값 포함 모델 수익률 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 대한항공 | -0.898%p | +0.408%p | -0.568%p | -0.402%p | -2.219% |
| S-Oil | -0.403%p | +0.338%p | +0.362%p | -0.346%p | +0.201% |

가상 손익은 각각 약 -22,190원, +2,008원입니다. 미국 금리 등의 종목별 외표본 근거가 약하므로 두 결과 모두 탐색용입니다. 불확실한 금리 기여도를 0으로 바꾸지는 않았습니다.

## 실행

PYTHONPATH는 analytics/src로 설정합니다. ROOT는 기존 공식 원본과 로컬 검증 결과가 있는 작업 폴더입니다. 기존 Gold 34개 열은 변경하지 않았습니다.

```text
python -m conditional_service.expansion --root ROOT --out OUTPUT
python -m conditional_service.benchmark_primary --root ROOT --out OUTPUT
python -m conditional_service.four_shock_policy --root ROOT --out OUTPUT
python -m conditional_service.summarize_expansion --root ROOT --out OUTPUT
python -m conditional_service.tiered_service OUTPUT/tiered_bundle.joblib
python -m conditional_service.enrich_tiered OUTPUT
python -m conditional_service.verify_tiered OUTPUT/tiered_bundle.joblib
```

STRESSLAB_TIERED_BUNDLE에 신뢰하는 로컬 tiered_bundle.joblib의 절대 경로를 설정합니다.

```text
python -m uvicorn conditional_service.tiered_service:app --host 127.0.0.1 --port 8134
```

GET /support, GET /model-info, POST /analyze를 제공합니다. 입력 형식은 기존 positions와 shocks를 유지합니다. 반환값에 네 계수, 출처, 학습 안정성, 외표본 근거, 관측 범위, 데이터 기준일, 모델 버전, 가상 손익을 포함합니다.

## 확인한 범위와 남은 검증

50종목에 무충격, 단일, 2개, 3개, 4개, 극단 충격을 적용했습니다. 기여도 합계, 직접 모델 계산, 종목 손익, 포트폴리오 합계가 일치했습니다. 탐색 종목과 학습 불가 종목도 별도 경로로 확인했습니다.

현재 모델은 가산형입니다. 동시에 발생한 충격의 비선형 상호작용이 입증된 것은 아닙니다. 충격 조합의 과거 지원 여부를 함께 표시하고 상호작용 검증은 별도 과제로 남깁니다.

2023~2026년은 반복 사용한 개발 평가입니다. 공표 시각 열과 전체 기업행사 처리의 최종 검증도 남아 있습니다. 급락 손실을 정확하게 예측하는 모델로 승인하지 않습니다. 이번 결과는 범위를 제한한 민감도 시뮬레이션 후보와 탐색 분석으로 사용하며, Azure 배포와 운영 모델 승격은 하지 않았습니다.
