# B134 방식의 종목별 스트레스 적용

원본 `project_b_ewy_forward.py`, `project_b_ewy_preopen.py`, `distribution.py`, `short_scenarios.py`를 읽고 계산 방식을 옮겼습니다. 코스피 전용 학습 계수를 개별 종목에 그대로 적용한 것은 아닙니다.

## 옮긴 계산

1. 5거래일 종목 수익률을 `100 * log(1 + 수익률/100)`으로 변환합니다.
2. 기준 시점의 변동성으로 나누어 학습 정답을 정규화합니다.
3. 입력을 StandardScaler로 정규화하고 Ridge(alpha=100)를 학습합니다.
4. 학습 정답의 1,001개 분위수에서 학습 정답 평균을 뺍니다. 외표본 잔차 분위수와 다른 방식입니다.
5. 정규화된 모델 중심값에 이 분위수들을 더하고 현재 변동성을 곱합니다.
6. 지수함수로 일반 수익률에 복원하고, 생성한 분포의 중앙값과 80/90% 구간을 계산합니다.

원본 변동성은 일별 로그수익률 제곱의 EWMA(alpha=0.06)를 제곱근한 뒤 하한 0.05를 적용하고 sqrt(5)를 곱한 값입니다. 이 버전과 기존 20/60일 변동성을 유지한 대조 버전을 모두 실행했습니다. JSON으로 회귀계수, 입력 평균과 표준편차, 분위수도 저장했습니다.

## 원본과 달라진 부분

대상은 코스피가 아니라 같은 50개 개별 종목입니다. 입력은 기존 Gold에서 계산한 시장 상태·종목 특성·네 충격이며 EWY와 장전 미국 수익률은 포함하지 않았습니다. Gold 계약을 변경하지 않았습니다.

원본은 최근 2,520개를 사용합니다. 이번에는 동일 CatBoost 비교 조건과 공표 검증이 가능한 행을 유지하므로 실제 종목별 학습 행은 564~1,296개입니다. 없는 행을 채우거나 검증되지 않은 과거 자료를 합치지 않았습니다. 따라서 2,520개 상한과 전체 이력 대조 버전의 결과가 동일합니다.

평가 날짜와 종목은 기존 CatBoost의 4,150개 행, 50종목, 85개 날짜에 정확히 맞췄습니다. 학습 종료 시점도 기존 CatBoost와 같으며 정답 종료일과 공표 시각 검사를 유지했습니다. 원본의 분기별 갱신까지 가져온 실험은 아닙니다. 실제 발생한 미래 충격을 사후 입력한 재구성 평가이고 반복 사용한 개발 기간입니다.

## 결과

| 방식 | 방향 일치율 | 중심값 MAE | 80% 포함률 / 전체 폭 | 90% 포함률 / 전체 폭 |
|---|---:|---:|---:|---:|
| 기존 CatBoost | 53.49% | 4.686%p | 78.17% / 15.23%p | 88.34% / 20.91%p |
| B134 분포 방식 + 기존 변동성 | 52.58% | 5.077%p | 78.00% / 15.10%p | 88.05% / 20.35%p |
| B134 분포 방식 + 원본 EWMA | 52.46% | 5.041%p | 77.86% / 15.02%p | 88.07% / 20.30%p |

80% Interval Score는 CatBoost 23.93, B134 EWMA 24.39입니다. 90%는 각각 30.67, 30.94입니다. 낮을수록 좋은 지표입니다. 전체 중심값과 구간 점수는 기존 CatBoost가 조금 낫습니다.

급락(-5% 이하) 688개에서 90% 하한 이탈률은 CatBoost 38.08%, B134 EWMA 21.95%입니다. 급락 시 중심값 MAE는 8.185→7.982%p로 줄었습니다. 그러나 전체 표본의 상한 이탈률은 4.96→8.10%로 증가했습니다. 하방 개선만으로 전체 분포 성능이 좋아졌다고 판단하지 않습니다.

2025~2026년 중심값 MAE는 CatBoost 5.410%p, B134 EWMA 5.942%p입니다. 이 기간의 90% 폭은 각각 24.49%p와 24.01%p, 포함률은 87.94%와 88.19%입니다.

## 판단

원본 방식을 실제로 옮겨 학습했지만 개별 종목에서 원본 코스피의 6.81%p 폭이 재현되지는 않았습니다. 하방 참고 구간에는 개선 신호가 있으나 중심값 오차와 전체 구간 점수가 악화돼 CatBoost의 전면 대체 모델로 채택하지 않았습니다.

이 결과는 원본 EWY 입력·장전 정보·2,520개 학습 행·분기별 갱신을 모두 재현한 검증이 아닙니다. 그 요소들 중 무엇이 원본 성능을 만들었는지 이번 실험만으로 단정할 수 없습니다. 원본 방법 자체가 무의미하다고 결론 내리지 않습니다.

웹 통합은 중단 상태이며 Azure, Gold, 운영 모델은 변경하지 않았습니다.

## 파일과 실행

`preopen_method_trial.py`가 학습과 JSON 추론을 함께 구현합니다. 팀 저장소 `analytics/src`를 PYTHONPATH로 지정하고 기존 로컬 연구 루트에서 `python -m conditional_service.preopen_method_trial`을 실행합니다.

로컬 결과는 `reports/preopen_method_trial_20261105`에 저장합니다. `models.json`은 평가 연도별 연구 모델이며 운영 모델이 아닙니다. Git에는 `preopen_method_evidence` 아래 예측, 종목별·연도별 성능표, 프로토콜과 기간 경계를 저장했습니다. 학습 원천 파일은 별도로 필요합니다.
