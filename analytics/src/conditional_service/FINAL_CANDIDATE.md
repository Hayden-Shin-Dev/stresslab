# 로컬 서비스 후보 확정

50종목과 네 충격 입력 API는 유지합니다. 현재 종목별 부분 풀링 Ridge를 가상 민감도 시뮬레이션용 서비스 후보로 확정하고, 이번 추가 모델 실험은 종료합니다. Azure 배포나 운영 모델 승격은 하지 않았습니다.

## 성능 비교

2023~2026년 동일한 50종목, 155개 날짜, 7,588개 관측을 사용했습니다. 이후 실제 충격을 사후 입력한 조건부 재구성 평가입니다. 반복 사용한 개발 평가이며 독립 블라인드 결과가 아닙니다.

| 방식 | 중심 수익률 MAE |
| --- | ---: |
| 기존 서비스 후보, 유지 | 4.416%p |
| 동일 50종목으로 다시 학습한 기본 부분 풀링 | 4.428%p |
| 정규화 강도 증가 | 4.426%p |
| 종목 편차 정규화 증가 | 4.429%p |
| 종목 편차 정규화 감소 | 4.429%p |
| 최근 10년 학습 | 4.454%p |
| 충격 반영 업종 Ridge | 4.332%p |

전체 모델군을 바꾸거나 새로운 변수를 추가하지 않았습니다. 부분 풀링과 업종 모델의 학습 자료, 보정 기간, 평가 표본을 맞췄습니다. 기존 서비스는 17종목의 이전 모델과 추가 33종목 모델을 보존한 구성으로, 동일 평가 표본의 참고선입니다. 이를 동일 학습 종목군이라고 주장하지 않습니다.

각 연도 직전 보정 기간만으로 모델을 선택하는 정책도 평가했습니다. MAE는 4.357%p였고 최신 보정 기간은 업종 모델을 선택했습니다. 이는 별도 선택 정책이며 고정된 단일 모델의 성능이 아닙니다.

최종적으로 업종 모델보다 오차가 약 1.94% 크다는 점을 공개하고 종목별 계수를 유지합니다. 업종 모델로 바꾸면 같은 업종 종목의 계수가 같아지므로 종목별 민감도 설명이라는 목적에서 차이가 있습니다. 이 결정은 개발 결과와 서비스 요구를 함께 본 판단이며 통계적으로 우월한 모델을 찾았다는 의미가 아닙니다.

기존 모델의 급락 중심값 과소평가는 평균 8.40%p, 업종 모델은 7.96%p였습니다. 급락 손실을 정확히 예측하거나 안전한 손실 한도를 제공하는 용도로 승인하지 않습니다. 상세 수치는 results/final_model_20261104에 있습니다.

## 오류 점검

| 항목 | 확인 결과 |
| --- | --- |
| 학습, 보정, 평가 정답 구간 | 겹치지 않도록 분리, 20일 경계 적용 |
| 스케일러와 학습 시점 | 저장된 두 모델의 평균값을 학습 행으로 재계산해 일치 확인 |
| 미래 피처 누수 | 미래 가격과 거시값을 바꿔도 기준일까지의 상태 피처 불변 |
| 단위와 타깃 | 200개 표본 직접 대조. 금리 1bp는 금리 수준 0.01%p, 환율과 유가는 %, VIX는 포인트 |
| 계수와 입력 | 비유한 값, 중복 키, mock 행 없음 |
| 계산 정합성 | 50종목에 6종류 입력. 네 기여도, 직접 모델값, 종목 손익, 합계 일치 |
| 이상 수익률 | +101% 사례를 KRX 원본과 대조. 실제 3,550원에서 7,140원으로 변한 경로이며 임의 삭제하지 않음 |
| 학습 오차 집계 | 10년 모델의 학습 오차에 더 오래된 행이 포함된 집계 오류 수정. 모델 학습과 평가 수익률은 변하지 않음 |

학습과 보정 성능에 차이는 있습니다. 기본 부분 풀링의 최신 학습 MAE 4.084%p, 보정 4.193%p입니다. 0 수익률 대비 상대오차도 0.944에서 0.991로 나빠집니다. 이를 과적합이 전혀 없다고 표현하지 않습니다. 정규화를 강화해도 개선되지 않아 추가 튜닝을 중단했습니다.

실제 공표 가능 시각 6개 열은 비어 있습니다. 관측일이 기준일 이후인 행은 없지만 공표 시각과 수정 이력까지 포함한 누수 검증은 완료하지 못했습니다. 기업행사 처리의 전체 원천 인증도 남아 있습니다. 코드의 시간 분리 검사 통과와 원천 데이터의 시점 인증을 구분합니다.

현재 분석 스냅샷은 2026-10-30이고 모델 학습 정답은 2026-10-08까지입니다. 해당 스냅샷의 환율 관측일은 2026-10-23입니다. 실시간으로 갱신된 현재 시장이라고 표시하지 않습니다. API에 원천 관측일을 추가했습니다.

## 민감도 신뢰 수준

네 충격 모두 입력할 수 있습니다. 계수는 공통 계수와 종목별 편차를 합친 실제 학습값입니다. 불안정한 계수를 0으로 바꾸지 않습니다. 앞선 외표본 관계 진단과 학습 안정성을 구분해 표시하고, 근거가 약한 입력이나 극단 조합은 탐색용으로 반환합니다.

미국 금리는 현재 데이터의 외표본 근거가 약합니다. 학습 계수의 부호가 안정적이어도 개별 종목의 실현 반응까지 설명됐다는 뜻은 아닙니다. 이 한계를 표시하고 추가 변수 연구는 반복하지 않습니다. 다른 충격과의 비선형 상호작용도 검증된 것으로 표시하지 않습니다.

## 확정 파일과 실행

로컬 reports/final_model_20261104/final_service_bundle.joblib가 확정 후보입니다. 기존 bundle은 보존했습니다. STRESSLAB_TIERED_BUNDLE을 이 파일의 절대 경로로 지정하면 기존 tiered_service API를 그대로 사용합니다. 신뢰하는 로컬 학습 파일만 불러오세요.

```text
python -m conditional_service.finalize_model --root ROOT --out OUTPUT
python -m conditional_service.audit_final --root ROOT --out OUTPUT
python -m conditional_service.close_research --root ROOT --out OUTPUT
python -m conditional_service.verify_tiered OUTPUT/final_service_bundle.joblib
```

finalize_model의 bounded_model.joblib는 제한 튜닝 비교 산출물입니다. 서비스 확정 파일과 혼동하지 마세요. 최종 결정은 decision.json에 기록되어 있습니다. 이번 범위는 로컬 프로젝트용 시뮬레이션 후보 확정이며, 공표 시각과 데이터 품질 검증 없이 운영 모델을 자동 승격하지 않습니다.
