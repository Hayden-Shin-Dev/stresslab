# 코스피 예측값과 종목 스트레스 모델 연결

2026-11-05 로컬 연구입니다. 코스피 모델의 공식을 종목에 복사한 실험과 다릅니다. 과거 시점별 코스피 예측값을 생성하고 종목 모델에 실제 입력했습니다. Gold 계약, Azure, 운영 모델은 변경하지 않았습니다.

## 구현

코스피 모델은 참고 B134의 변동성 정규화, Ridge alpha=100, 최대 2,520행, 분기별 재학습, 학습 수익률 분포 방식을 사용합니다. 코스피 가격은 현재 Gold의 지수 이력을 사용합니다.

Gold 시장 상태만 쓰는 경로와 미국 수익률·EWY를 추가하는 경로를 분리했습니다. 후자는 연구용 보조 입력이며 Gold 필수 컬럼으로 추가하지 않았습니다. 종목 모델의 기준 시각인 한국장 종가까지 이용 가능한 미국 관측만 사용합니다. 원본의 다음 날 08:30 장전 입력을 전날 종가에 사용하지 않았으므로 원본 장전 모델과 정보 시점이 같지는 않습니다. 미국 자료의 시각은 원본의 시장 종료 시각 가정이며 실제 수신 시각 인증은 아닙니다.

종목 학습에 들어가는 코스피 예측도 당시 분기 이전에 끝난 정답만으로 만든 외표본 값입니다. 실제 미래 코스피 수익률을 추론 입력으로 사용하지 않습니다.

다음 세 방식을 같은 학습 행에서 비교했습니다.

1. 연결 없음: 기존 Gold 파생 입력과 네 충격으로 일반 종목 수익률을 학습합니다.
2. 추가 입력: 위 입력에 코스피 외표본 예측값 하나를 추가합니다.
3. 시장 기본 반응: 과거 자료에서 종목별 시장 베타를 추정합니다. `종목 실제 수익률 - 베타 × 코스피 외표본 예측값`을 정답으로 잔여 반응을 학습하고, 추론에서는 `베타 × 코스피 예측 + 잔여 반응`을 계산합니다. 실제 미래 시장 수익률을 뺀 정답을 쓰는 실험과 다릅니다.

세 방식 모두 Ridge alpha=100과 네 충격을 유지했습니다. 구간은 이전 1년의 시간순 외표본 잔차로 같은 방식으로 계산했습니다. 시장 예측은 무충격 반사실이 아니며, 이 구성만으로 충격의 인과효과나 완전한 통계적 분리를 입증하지 않습니다.

## 동일 표본 결과

미국 자료가 없는 평가 날짜를 공통 제외해 50종목, 84개 날짜, 4,100개 표본을 비교했습니다. 반복 사용한 2023~2026년 개발 표본입니다. 네 실제 미래 충격을 사후 입력한 조건부 반응 재구성이며 독립 블라인드 검증이 아닙니다.

| 방식 | 중심 MAE | 방향 일치율 | 급락 중심 MAE | 90% 포함률 | 전체 폭 |
|---|---:|---:|---:|---:|---:|
| 연결 없음 | 4.859%p | 52.75% | 9.184%p | 84.95% | 19.83%p |
| Gold 코스피 예측 추가 입력 | 4.878%p | 52.73% | 9.200%p | 85.07% | 19.87%p |
| Gold 코스피 예측으로 기본 반응 계산 | 4.887%p | 51.76% | 9.341%p | 85.02% | 19.82%p |
| 미국·EWY 코스피 예측 추가 입력 | 4.839%p | 53.05% | 8.923%p | 85.00% | 19.84%p |
| 미국·EWY 코스피 예측으로 기본 반응 계산 | 4.889%p | 51.96% | 9.368%p | 85.07% | 19.86%p |

미국·EWY 추가 입력은 33/50종목의 MAE가 감소했습니다. 그러나 날짜 균등 MAE 개선은 0.018%p, 날짜 블록 95% 구간은 -0.021~0.070%p로 0을 포함합니다. 급락 시 구간 하단 이탈률도 39.32→39.03%로 거의 동일합니다. 최근 2025~2026년 MAE는 5.820→5.764%p, 방향은 49.50→50.60%였습니다.

같은 평가 행의 기존 CatBoost 중심 MAE는 4.679%p, 방향 53.61%입니다. 0 수익률 기준선 MAE는 4.613%p입니다. 새 연결 모델이 이 기준선을 넘었다고 보고하지 않습니다. 코스피 기본 반응을 강제로 더하는 방식은 채택하지 않습니다. 추가 입력은 작은 개선 단서만 보존하며 최종 모델로 승격하지 않습니다.

## 코스피 모델의 좁은 구간 확인

Gold만 쓰는 코스피 모델을 동일 방식으로 계산하면 2011~2016년 전체 1,482개 날짜에서 폭 6.80%p, 포함률 89.74%, MAE 1.595%p입니다. 현재 종목과 공유한 최근 84개 날짜에서는 폭 13.11%p, 포함률 86.90%, MAE 2.908%p입니다.

과거 보고서의 폭 6.81%p를 최근 종목 비교의 기준 성능으로 그대로 사용할 수는 없습니다. 기간별 표본과 변동성 조건이 달라진 참고 비교이며, 원본 1,477개 날짜와도 정확히 동일한 표본은 아닙니다. 미국·EWY를 추가한 최근 결과도 폭 13.11%p, MAE 2.899%p였습니다. 코스피 예측 자체의 최근 중심값 개선이 작아 종목으로 전달되는 정보도 제한적이라는 결과입니다.

## 서비스 형태의 계산 예제

모든 지원 종목의 모델 계수와 시나리오 예제를 저장했습니다. 기준일은 공통 평가의 마지막 날인 2026-09-30이며 현재 시세가 아닙니다. 환율 +5%, 미국 금리 +100bp, WTI +10%, VIX +5포인트를 동시에 적용하고 보유금액 100만 원으로 계산했습니다.

미국·EWY 추가 입력 방식에서 대한항공은 무충격 입력 모델값 -2.12%, 충격 변화 -5.19%p, 최종 -7.31%, 가상 손익 약 -73,082원입니다. 삼성전자는 기준값 +6.94%, 충격 변화 -3.59%p, 최종 +3.35%, 가상 손익 약 +33,498원입니다. 이 예제는 계산 연결 검증이지 해당 극단 조합의 신뢰성을 승인한 결과가 아닙니다. 기준값 과대 문제도 모두 해결되지 않았습니다.

네 충격별 기여도 합계가 모델 전후 차이와 일치하는지 검사했습니다. 입력하지 않은 충격은 변화량 0으로 처리합니다. 개별 충격의 학습 최솟값·최댓값을 함께 반환하며, 다변량 공동 지원 범위는 인증하지 않았습니다. 예제는 모두 탐색용입니다.

## 코드와 결과

`market_bridge_trial.py` 다음 `report_market_bridge.py`를 실행합니다. 기존 로컬 연구 폴더에서 저장소의 `analytics/src`를 `PYTHONPATH`로 설정하고 `python -m conditional_service.모듈명`으로 실행합니다.

[market_bridge_evidence](market_bridge_evidence)에 전체 예측, 종목별 성능, 날짜 블록 비교, 학습 경계, 과거 급락 계산 분해, 300개 종목·방식 조합의 모델 계수와 요청 조건별 계산 예제가 있습니다. `scenario_examples.json`은 웹 연동 확정 계약이 아닌 연구 출력입니다. 모델 파일과 원천 입력 해시는 변경되지 않았습니다.
