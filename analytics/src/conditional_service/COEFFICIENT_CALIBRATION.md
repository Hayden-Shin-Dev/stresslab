# 외표본 오차를 이용한 계수 보정

기존 모델을 유지하면서 무충격 기준값과 네 충격 계수의 크기를 보정했습니다. 평가 정답을 보고 계수를 수동으로 바꾸지 않았습니다. Azure, Gold와 기본 서비스 모델은 그대로입니다.

## 어떻게 비교했는가

각 평가 연도 이전 3년의 외표본 예측 오차를 만들었습니다. 앞의 2년에서 보정 계수를 학습하고 마지막 1년에서 설정을 선택한 다음, 이전 3년 전체로 보정 계수를 재학습했습니다. 실제 평가 연도의 수익률은 보정 선택에 사용하지 않았습니다.

무충격 기준값만 보정, 충격 기여도만 보정, 둘 다 보정하는 세 방식과 Ridge 정규화 10/100/1000의 9개 설정을 비교했습니다. 모든 보정 방식에는 정규화된 상수 오차 보정도 포함합니다. 같은 날짜의 전체 종목 가중치 합은 1입니다. 보정 계수는 종목별로 따로 고르지 않고 기존 학습 집단별로 공유합니다.

이전 검증에서 날짜별 MAE가 1% 이상 줄고 급락 과소평가가 기존보다 5% 넘게 악화되지 않을 때만 선택했습니다. 그렇지 않으면 기존 계수를 유지합니다. 시간 경계에는 20일 간격을 뒀습니다.

## 결과

기존과 같은 50종목, 85개 날짜, 4,150개 관측입니다. 최근 기간은 43개 날짜, 2,057개 관측입니다.

| 지표 | 기존 | 이전 기간에서 선택한 보정 |
| --- | ---: | ---: |
| 전체 2023~2026 MAE | 4.787%p | 4.763%p |
| 전체 방향 일치율 | 50.96% | 51.83% |
| 최근 2025~2026 MAE | 5.657%p | 5.638%p |
| 최근 방향 일치율 | 48.86% | 49.10% |
| 전체 급락 과소평가 | 8.277%p | 8.332%p |
| 최근 급락 과소평가 | 9.311%p | 9.298%p |

전체 MAE 감소는 약 0.5%입니다. 날짜 블록 재표본추출의 개선량 95% 구간은 전체 +0.004~+0.047%p, 최근 -0.001~+0.045%p입니다. 반복 사용한 개발 평가 기간이므로 독립 검증의 유의성으로 해석하지 않습니다. 최근 개선은 확실하지 않고 전체 급락 과소평가는 악화됐습니다.

0 수익률 기준선은 전체 4.621%p, 최근 5.285%p이므로 보정해도 더 낮은 오차를 달성하지 못했습니다.

## 실제로 무엇을 바꿨는가

2026년 기본 학습 집단에서는 무충격 기준 수익률을 `기존 값 × 0.63615 + 0.11599%p`로 보정하는 설정이 선택됐습니다. 네 충격 계수는 유지됐습니다. 확장 학습 집단은 보정하지 않는 것이 선택됐습니다. 이 값들은 2023~2025년 외표본 오차로 학습한 값이며 사용자가 입력한 금리·환율 수준을 바꾼 값이 아닙니다.

2023년 기본 집단에서는 충격 계수 보정이 선택됐지만, 모든 연도에 충격 보정을 적용하면 성능은 악화됐습니다. 충격 보정 강도 10을 일괄 적용한 경우 전체 MAE는 5.015%p, 최근은 6.008%p입니다. 따라서 충격 계수를 크게 만드는 것 자체는 개선 방법이 아닙니다.

기여도는 `기존 민감도 × 보정 배수 × 사용자 충격`으로 계산합니다. 무충격 기준값과 네 기여도의 합이 전체 수익률이며, 50종목 16개 조합의 800개 계산에서 이 등식을 확인했습니다. 상수 보정은 무충격 기준값에만 넣어 충격 기여도로 오인하지 않도록 했습니다.

## 서비스 판단

보정 코드는 연구 후보로 보존하고 기본 API에는 적용하지 않았습니다. 평균 오차가 조금 줄었지만 전체 급락 대응이 나빠졌고 최근 개선도 불확실합니다. 또한 고정 백테스트의 학습 시점과 최신 서비스 모델의 학습 시점이 달라, 보정 배수를 최신 모델에 그대로 붙이는 것은 별도 검증이 필요합니다.

현재 서비스는 학습된 관계에 따른 탐색용 가상 손익 비교로 제공할 수 있습니다. 실제 충격 반응이 검증된 예상 수익률, 손실 확률 또는 확정 손실 한도로 제공하면 안 됩니다. 계산의 근거가 있다는 것과 실제 반응 설명력이 충분하다는 것은 별도입니다.

## 코드와 자료

`calibrate_coefficients.py`가 학습과 시간순 평가를 수행합니다. 연구 폴더에서 팀 저장소 `analytics/src`를 PYTHONPATH로 지정하고 실행합니다.

```powershell
python -m conditional_service.calibrate_coefficients
```

전체 예측은 로컬 `reports/coefficient_calibration_20261105/predictions.parquet`에 있습니다. 저장소의 [검증 자료](service_evidence/coefficient_calibration)에는 종목별 성능, 실제 보정 계수, 내부 검증 점수, 기간 경계와 불확실성을 정리했습니다. `candidate_correction.json`은 연구용이며 배포 설정이 아닙니다.
