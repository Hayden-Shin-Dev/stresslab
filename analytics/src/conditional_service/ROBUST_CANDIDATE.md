# 학습 손실함수와 국면별 민감도 비교

이번 비교에서는 Huber 학습 후보의 평균 오차와 급락 과소평가가 함께 줄었습니다. 후보를 별도 파일로 학습하고 API까지 검증했습니다. 기존 기본 모델과 Azure, Gold는 변경하지 않았습니다.

## 결과

같은 50종목, 2023~2026년 85개 날짜와 4,150개 관측입니다. 최근 기간은 2025~2026년 43개 날짜, 2,057개 관측입니다. 실제 발생한 충격을 사후 입력한 재구성 평가이며, 미래 가상 사건의 정답을 검증한 것이 아닙니다.

| 방식 | 전체 MAE | 최근 MAE | 전체 급락 과소평가 | 최근 급락 과소평가 |
| --- | ---: | ---: | ---: | ---: |
| 기존 Ridge | 4.787%p | 5.657%p | 8.277%p | 9.311%p |
| Huber 후보 | 4.726%p | 5.537%p | 8.014%p | 8.834%p |
| 급등락 가중 학습 | 5.083%p | 6.116%p | 8.154%p | 9.612%p |
| 시장 국면 상호작용 | 4.829%p | 5.707%p | 8.260%p | 9.283%p |
| 국면 상호작용 + Huber | 4.750%p | 5.571%p | 8.045%p | 8.861%p |
| 0 수익률 기준선 | 4.621%p | 5.285%p | 8.838%p | 9.379%p |
| 업종 충격 Ridge | 4.615%p | 5.329%p | 8.673%p | 9.251%p |

급락은 실제 수익률 -5% 이하입니다. 과소평가는 max(모델값-실제값, 0)의 평균입니다. 구간을 넓힌 결과가 아니라 중심값을 비교한 결과입니다.

Huber의 전체 MAE는 기존보다 약 1.28%, 최근 MAE는 약 2.11%, 최근 급락 과소평가는 약 5.13% 줄었습니다. 전체 방향 일치율은 기존과 같은 50.96%, 최근은 48.86%에서 49.05%로 거의 같습니다. 큰 폭의 예측 성능 개선이라고 표현하지 않습니다.

종목-연도 200개 중 136개에서 MAE가 줄었습니다. 2023년은 MAE와 급락 과소평가가 모두 소폭 악화됐고 2024~2026년은 개선됐습니다. 종목별 값은 `stock_metrics.csv`에 있습니다.

## 무엇이 달라졌는가

변수, 네 충격의 단위, 부분 풀링 구조와 정규화 300은 유지했습니다. 큰 잔차에 제곱 비례로 끌리는 기존 학습 대신, 일정 크기를 넘는 잔차의 영향력을 제한했습니다. Huber 경계는 학습 잔차의 MAD로만 정했고 평가 자료로 맞추지 않았습니다.

최종 학습에서 약 21%의 관측은 가중치가 줄었고 약 4~4.5%는 절반 미만이 됐습니다. 데이터를 삭제하거나 실제 수익률을 바꾸지는 않았습니다. 일부 큰 오차에 계수가 끌리는 것을 줄였을 때 성능이 개선됐다는 실험 결과이며, 모든 실패의 원인을 이것 하나로 확정한 것은 아닙니다.

급등락을 더 잘 학습시키기 위해 과거 학습 정답의 상하위 10%에 3배 가중치를 주는 방식도 비교했지만 오차가 커졌습니다. 상태별 충격 계수에는 학습 범위로 표준화한 추세와 변동성의 tanh 상호작용을 사용했으나 Huber 단독보다 좋지 않았습니다.

## 검증 한계와 채택 상태

모든 고정 후보는 평가 전에 정한 방식으로 학습했습니다. 추가로 전년도 검증에서만 후보를 선택하는 정책도 평가했습니다. 그 정책의 전체 MAE는 4.785%p, 최근은 5.649%p로 개선이 작았습니다. 따라서 Huber를 모든 연도에 사용한 성능과, 당시에 선택할 수 있었던 정책의 성능을 구분해야 합니다.

4개 날짜 블록으로 계산한 Huber MAE 개선량의 95% 구간은 전체 +0.009~+0.121%p, 최근 +0.029~+0.219%p입니다. 반복 사용한 개발 기간에서 여러 방법을 비교한 결과이므로, 독립 검증이나 다중 비교까지 반영한 확증으로 해석하지 않습니다.

전체 기준선보다 MAE가 3% 넘게 나쁘지 않다는 기존 허용 기준은 통과했습니다. 하지만 0 수익률과 업종 기준선보다 MAE가 더 낮지는 않습니다. 미래 수익률 예측 승인이나 충분한 충격 설명력을 입증한 것은 아닙니다.

후보의 `production_approved`와 `service_candidate_confirmed`는 false로 유지합니다. `performance_gate_passed`는 위의 제한적 허용 기준만 뜻합니다. 기존 모델 파일과 기본 매니페스트는 변경하지 않았습니다.

## 모델과 API 확인

연구 폴더에 `reports/robust_candidate_20261105/final_service_bundle.joblib`과 매니페스트가 있습니다. SHA256은 `346e85088fa60cdb3c1c984d8d19889ad780c08a1c841dcb20625cffcac429cc`입니다. 모델을 다른 PC에서 실행하려면 해당 파일과 저장소 코드를 함께 전달해야 합니다.

기존 API에 아래 환경변수를 지정하면 이 후보를 별도로 확인할 수 있습니다. 연구 폴더에서 팀 저장소 `analytics/src`를 PYTHONPATH로 설정한 뒤 실행하세요.

```powershell
$env:STRESSLAB_TIERED_BUNDLE = "$PWD\reports\robust_candidate_20261105\final_service_bundle.joblib"
$env:STRESSLAB_MODEL_MANIFEST = "$PWD\reports\robust_candidate_20261105\final_service_manifest.json"
python -m uvicorn conditional_service.api:app --host 127.0.0.1 --port 8141
```

50종목의 무충격, 15개 충격 조합, 극단 입력을 포함한 850개 계산을 실제 HTTP로 확인했습니다. 민감도 구성요소 합계, 네 충격 기여도 합계, 가상 손익, 과거 검색 유지와 데이터 근거 누락 시 차단을 검증했습니다.

시장 기준일은 2026-10-30의 고정 상태입니다. 최신 실시간 시장으로 표시하지 않습니다. 후보의 민감도 비교는 `sensitivity_comparison.csv`, 실제 요청과 응답은 아래 검증 자료에 있습니다.
