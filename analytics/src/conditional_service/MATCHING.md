# 유사 시장의 충격 차이 비교

기존 KMeans 가중 모델과 별도 실험입니다. Gold 계약과 운영 모델을 변경하지 않습니다.

## 계산 순서

1. 학습 기간의 확정 일별 시장 상태만으로 유사한 과거 날짜를 찾습니다. 사용자 충격은 이 검색에 사용하지 않습니다.
2. 날짜가 겹치지 않는 5거래일 관측 구간 중 가까운 후보를 최대 120개 선택합니다.
3. 환율을 분석한다면 시장 상태, 종목의 기존 추세와 변동성, 금리와 유가와 VIX 충격이 비슷한 날짜끼리 짝짓습니다. 환율 충격에는 충분한 차이가 있어야 합니다. 다른 충격도 같은 방식으로 분석합니다.
4. 각 쌍의 실제 충격 차이와 종목 수익률 차이를 저장합니다. 단순 관측 기울기와 전체 팩터 모델로 설명한 부분을 제외한 잔차 기울기를 구분합니다.
5. 전체 모델의 충격 민감도에 잔차 기울기를 더한 방식, 국소 회귀로 보정한 방식, 매칭 보정 비중을 최대 50%로 제한한 방식을 비교합니다.

전체 모델의 중심값을 버리고 몇 건의 평균을 붙이는 방식이 아닙니다. 동일한 현재 상태에서 충격이 없는 모델값을 기준으로 충격 차이에 따른 보정을 계산합니다. 네 충격의 보정을 합산하는 것은 검증 대상인 계산 가정이며 인과효과의 분해가 아닙니다.

## 매칭 기준

변수는 학습 기간의 중앙 50% 범위인 IQR로 단위를 맞춥니다. 통제 변수 차이의 평균제곱근은 0.5 IQR 이내, 다른 세 충격은 각각 0.5 IQR 이내, 분석할 충격 차이는 0.5 IQR 이상으로 정했습니다. 같은 비교에서 날짜를 여러 쌍에 중복 사용하지 않습니다.

비교 쌍 15개 이상, 유사도 가중 유효 표본 40개 이상, 다른 조건을 통제한 후 남는 충격 분산 비율 20% 이상이고 입력 충격이 후보의 관측 범위 안일 때만 보정합니다. 그 외에는 전체 모델을 사용합니다. 국소 회귀에도 이번에는 같은 보수적인 적용 조건을 사용합니다.

이 수치는 사전에 고정한 연구 설정이지 승인된 금융 기준이 아닙니다. `matching_support_sweep.py`는 후보 120개와 360개, 허용 차이 0.5와 0.75와 1.0을 비교합니다. 수익률 성능을 보고 설정을 선택하지 않습니다. 후보를 늘리면 현재와 덜 유사한 시장까지 포함하고, 허용 차이를 늘리면 다른 충격도 더 달라집니다.

## 실행과 산출물

`PYTHONPATH=analytics/src`를 설정하고 실행합니다.

```text
python -m conditional_service.matched_comparison --gold data/dev_gold/gold_stress_daily.parquet --out outputs/matched
python -m conditional_service.summarize_matching outputs/matched
python -m conditional_service.matching_support_sweep --gold data/dev_gold/gold_stress_daily.parquet --out outputs/matched
```

| 파일 | 확인할 내용 |
| --- | --- |
| matched_pairs.parquet | 실제 비교 날짜, 두 충격값, 두 종목 수익률, 다른 조건의 차이 |
| support.csv | 종목별 충격별 비교 쌍 수, 적용 비율, 민감도 범위 |
| fold_slopes.csv | 평가 연도별 관측 민감도 |
| metrics.csv / per_asset.csv | 동일 표본의 모델별 및 종목별 성능 |
| stock_specific.csv | 날짜별 공통 수익률을 제거한 방향 일치율과 상관 |
| comparison_ci.json | 날짜 블록 단위의 개선율 불확실성 |
| crash_failures.csv | 실제 급락에서 오차가 큰 사례 |

학습, 보정, 평가는 시간순으로 분리하고 20일 간격을 둡니다. 미래의 실제 충격을 사후 입력한 조건부 재구성 평가입니다. 2023~2026년은 이미 사용한 개발 평가 기간이며 독립 블라인드 테스트가 아닙니다. 현재 Gold의 공표 시각과 추가 종목의 권리변동 검증 한계도 유지됩니다.

쌍이 적으면 비교 자료 부족, 다른 조건을 통제한 뒤 충격 분산이 적으면 분리 어려움으로 기록합니다. 자료가 충분해도 성능이 개선되지 않을 수 있습니다. 그 경우 매칭 설정, 반응의 비선형성, 관측되지 않은 변수 중 무엇이 원인인지는 이 실험 하나로 확정할 수 없습니다.

## 실제 결과

2026-11-04 실행 결과입니다. 20종목은 145개 평가일의 2,717행, 26종목은 155개 평가일의 3,627행입니다. 모델끼리는 동일 표본이며 두 종목 집합의 평균을 직접 비교하지 않습니다.

| 방식 | 20종목 MAE | 26종목 MAE | 26종목 방향 일치율 |
| --- | --- | --- | --- |
| 전체 팩터 | 4.561%p | 4.317%p | 59.28% |
| 기존 KMeans 가중 | 4.567%p | 4.317%p | 59.14% |
| 매칭 차이 보정 | 4.727%p | 4.501%p | 56.85% |
| 국소 회귀 보정 | 4.562%p | 4.342%p | 58.04% |
| 매칭 보정 비중 제한 | 4.592%p | 4.342%p | 58.23% |

26종목에서 매칭 보정 적용 비율은 환율 58.1%, 미국 금리 51.6%, VIX 59.9%, WTI 61.7%입니다. 비교 쌍 중앙값은 16~18개입니다. 전체 조건이 매칭 불가능했던 것은 아닙니다. 통제 후 남는 충격 분산 비율 중앙값도 약 73~82%이므로, 다른 충격과의 동조화만을 실패 원인으로 단정할 수 없습니다.

매칭 보정의 MAE 개선율은 -4.20%, 날짜 블록 95% 구간은 -5.73~-2.96%입니다. 급락 하한 이탈률은 61.19%에서 55.25%로 낮아졌지만 구간 폭이 13.87%p에서 14.99%p로 커지고 급락 중심값 오차도 악화됐습니다. 개선으로 채택하지 않습니다.

26종목 104개 종목-충격 조합 중 연도별 매칭 기울기의 부호가 모두 유지된 것은 54개입니다. 대한항공의 유가 기울기는 네 연도 모두 음수, S-Oil은 모두 양수입니다. 이 값은 관측 비교의 기울기이며 외삽용 확정 계수가 아닙니다. 두 종목의 차이가 관측된다는 사실과 최종 모델의 정확도 개선은 별개입니다.

대한항공의 국소 회귀 MAE는 2.961%p에서 2.868%p로 줄었습니다. 개선율 3.15%의 날짜 블록 95% 구간은 -1.04~7.52%이므로 개선을 확정할 수 없습니다. S-Oil의 MAE는 3.915%p에서 3.892%p로 거의 같습니다. 이 종목들만 사후 선택해 모델을 승인하지 않습니다.

시장 공통 움직임을 제거한 상관은 전체 팩터 0.033, 국소 회귀 0.046, 매칭 보정 0.041로 여전히 작습니다. 비교 가능한 충격 차이는 존재하지만 종목의 전체 5일 수익률을 안정적으로 복원한다는 근거는 부족합니다.

현재 확정할 수 있는 결론은 비교 자료 부족과 민감도 불안정이 일부 존재하고, 이번 매칭 차이를 중심값에 더하는 방식은 전체 성능을 개선하지 못했다는 것입니다. 관측되지 않은 기업 사건이 얼마나 설명하는지는 이 실험으로 측정하지 못했습니다. 새 모델은 운영에 반영하지 않았습니다.
