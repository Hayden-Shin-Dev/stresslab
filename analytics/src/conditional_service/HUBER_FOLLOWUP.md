# Huber 후속 검증

2026-11-05 기준입니다. Azure, Gold, 운영 모델과 기존 Huber 후보 파일은 변경하지 않았습니다.

## 비교 조건

50종목, 2023~2026년 85개 평가일, 4,150개 종목 관측을 동일하게 사용했습니다. 2025~2026년은 43일, 2,057개 관측입니다. 반복 사용한 개발 평가이며 독립 블라인드 검증이 아닙니다. 학습, 보정, 평가의 정답 구간을 분리하고 20일 엠바고를 유지했습니다. 같은 날짜의 종목을 독립 사건으로 세지 않았습니다.

기존 Huber 외에 오차 전환점 0.75와 2, 종목별 추세 상호작용, 사전 변동성으로 정규화한 학습, 정규화 강도 변경, 방향 오류 벌점 1과 4를 비교했습니다. 구간 폭은 조정하지 않았습니다. 전환점은 학습 잔차의 MAD 기반 척도에 곱하는 값입니다. 0.75는 큰 오차의 영향력을 더 일찍 제한하며, 급락 표본을 삭제하는 방식은 아닙니다.

## 결과

2025~2026년 결과입니다. 오차와 손실 과소평가는 %p 단위입니다.

| 방법 | 중심값 MAE | 방향 일치율 | 급락 손실 과소평가 |
| --- | ---: | ---: | ---: |
| 기존 Huber 1.35 | 5.537 | 49.05% | 8.834 |
| Huber 0.75 | 5.491 | 49.73% | 8.699 |
| 종목별 추세 추가 | 5.537 | 49.00% | 8.835 |
| 사전 변동성 정규화 | 5.590 | 50.36% | 8.258 |
| 방향 벌점 4 | 5.421 | 49.00% | 8.887 |

급락은 실제 5거래일 수익률이 -5% 이하인 경우입니다. 과소평가는 max(모델 수익률 - 실제 수익률, 0)의 평균입니다. 최근 급락 관측은 412개이며 독립 사건 412개라는 뜻은 아닙니다.

Huber 0.75의 전체 기간 MAE는 4.726에서 4.709로, 방향 일치율은 50.96%에서 51.54%로 개선됐습니다. 날짜 블록 재표본추출의 MAE 개선 95% 구간은 전체 -0.005~0.041%p, 최근 0.011~0.086%p입니다. 후보를 여러 개 비교했고 평가 기간도 반복 사용했으므로 최근 구간의 결과만으로 확정 채택하지 않습니다.

이전 연도 검증에서 날짜별 MAE 1% 이상 개선, 급락 과소평가 비악화, 방향 일치율 하락 1%p 이내를 요구하면 모든 평가 연도와 학습군에서 기존 Huber가 선택됐습니다. 따라서 0.75는 후속 연구 후보이며 운영 모델로 승격하지 않았습니다. 최근 0 예측 MAE 5.285, 업종 기준선 5.329보다도 아직 높습니다.

## 급락 실패 분석

최근 급락 412개 중 373개가 학습 기간 시장 변동성 상위 25% 기준을 넘는 상태였습니다. 이 상태의 Huber 손실 과소평가는 9.192%p, 나머지는 5.408%p였습니다. 이는 실패가 집중되는 조건이며 변동성의 인과효과를 뜻하지 않습니다.

| 종목 | 최근 급락 관측 수 | 실제 평균 | 기존 Huber 평균 | Huber 0.75 평균 |
| --- | ---: | ---: | ---: | ---: |
| 삼성전기 | 6 | -12.90% | +0.43% | +0.24% |
| 현대차 | 6 | -12.54% | -0.30% | -0.49% |
| S-Oil | 6 | -10.03% | +1.45% | +1.35% |

Huber 0.75는 급락 중 음수 중심값 비율을 63.1%에서 67.0%로 높였지만, 중심값이 -5% 이하인 비율은 3.4%로 그대로입니다. 삼성전기는 오차가 조금 줄어도 전체 방향 일치율이 악화됐습니다. 종목별 개선을 일반화하지 않습니다.

종목별 추세 계수를 추가해도 개선은 거의 없었습니다. 변동성 정규화는 급락 규모를 더 반영했지만 전체 MAE를 악화시켰습니다. 방향 벌점은 MAE를 줄이는 대신 급락 손실 과소평가를 악화시켰습니다. 현재 확인한 병목은 구간 폭보다 급락 중심값이 0 부근에 머무는 현상입니다. 이번 실험으로 누락된 특정 변수나 관계가 원인이라고 확정하지는 못했습니다.

## 재현 및 증거

프로젝트 데이터가 있는 작업 폴더에서 analytics/src를 PYTHONPATH에 지정한 뒤 실행합니다.

```text
python -m conditional_service.huber_followup
python -m conditional_service.direction_huber
python -m conditional_service.huber_failure_report
```

[검증 자료](service_evidence/huber_followup/)에 동일 표본 예측값, 종목별 성능, 실패 사례, 내부 선택 결과, 날짜 경계와 데이터 해시를 보관했습니다. 모든 학습이 수렴했고, 기존 Huber 재현 및 충격별 기여도 합계 검증을 통과했습니다. 원본 데이터와 기존 모델의 해시는 실행 전후 동일합니다.
