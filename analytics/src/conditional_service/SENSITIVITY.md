# 종목별 충격 민감도 서비스 후보

핵심 결과는 종목별 민감도와 가상 손익입니다. 과거 검색과 순위는 근거를 보완하며 계산을 대신하지 않습니다. 기존 Gold 계약, Azure, 운영 API는 변경하지 않았습니다.

## 계산식

```text
종목의 모델 수익률 = 무충격 기준 모델값
                  + 환율 계수 × 환율 변화율
                  + 미국 금리 계수 × 금리 변화 bp
                  + WTI 계수 × 유가 변화율
                  + VIX 계수 × 지수 변화 포인트

가상 손익 = 보유 평가금액 × 모델 수익률 / 100
```

무충격은 변수 수준을 0으로 만드는 것이 아니라 변화가 없다는 조건입니다. 기준 수익률은 0으로 강제하지 않습니다. 포트폴리오에 별도 ML을 학습하지 않습니다.

계수는 공통 계수와 종목별 편차를 함께 학습하는 Ridge로 추정합니다. 종목별 편차에는 더 강한 정규화를 적용합니다. 시장 추세와 변동성에 따른 충격 계수 변화도 별도 모델에서 추정합니다. 충격끼리의 곱항은 없으므로 네 기여도의 합이 입력 전후 모델값 차이와 정확히 일치합니다. API에서 공통 계수, 종목별 편차, 상태 보정까지 확인할 수 있습니다.

## 시장 상태와 계수 선택

A는 확정 일별 상태로 과거 환경을 검색합니다. 사용자 충격을 바꿔도 최초 후보는 유지됩니다. 계수의 상태 보정에는 시장 추세와 변동성을 사용합니다. 유사도만 높인 재학습 방식이 아닙니다.

학습 종료를 18개월, 12개월, 6개월 앞당긴 모델과 전체 학습 모델에서 계수 부호가 같고, 계수 표준편차/중앙값 절댓값이 0.75 이하이며, 충격 1 IQR 변화의 모델 반응이 0.1%p 이상인지 검사합니다. 상태별 계수는 유사 환경 30개 이상일 때만 선택합니다. 아니면 전체 기간 계수를 사용합니다. 이 설정은 사전 고정한 연구 규칙이며 통계적 신뢰구간이 아닙니다.

불안정한 활성 충격이나 관측 범위를 넘는 충격은 주 결과 수익률과 손익을 비워 두고 탐색용 숫자만 별도 제공합니다. 계수는 안정적이지만 현재 상태와 충격 조합의 사례가 적으면 계산은 제공하되 `assumption_dependent`로 표시합니다. 모든 응답은 운영 승인 전 연구 후보입니다.

## 동일 조건 비교

2023~2026년 155개 평가일, 26종목의 3,627행입니다. 종목별 Ridge, LightGBM, CatBoost는 기존 설정으로 같은 자료에서 다시 학습했습니다. 이전 보고서의 다른 표본 수치와 직접 비교하지 않습니다.

| 모델 | MAE | 방향 일치율 | 80% 구간 포함률 |
| --- | --- | --- | --- |
| 기존 종목별 Ridge | 5.039%p | 58.2% | 77.3% |
| 기존 종목별 LightGBM | 4.970%p | 55.4% | 79.1% |
| 기존 종목별 CatBoost | 4.940%p | 53.3% | 77.6% |
| 종목별 Ridge, 원수익률 대조군 | 4.323%p | 57.5% | 76.1% |
| 전체 기간 부분 풀링 | 4.272%p | 58.6% | 80.1% |
| 상태 계수 선택 부분 풀링 | 4.259%p | 59.4% | 80.2% |

기존 모델은 변동성으로 정규화한 수익률을 학습하고 새 모델은 원수익률을 학습합니다. 개선 전부를 부분 풀링 효과로 주장하지 않도록 원수익률 종목별 Ridge도 대조했습니다. 이 대조군 대비 상태 계수 모델의 날짜별 MAE 개선율은 1.37%, 날짜 블록 95% 구간은 0.49~2.19%입니다.

상태별 계수 선택은 전체 기간 계수 대비 개선율 약 0.26%이며 구간이 0을 포함합니다. 상태 보정의 추가 효과는 입증되지 않았습니다. 80% 구간 폭은 13.91%p이고, 실제 -5% 이하 급락의 56.0%가 하한을 벗어났습니다. 급락 보호나 정밀한 위험 구간을 승인한 결과가 아닙니다.

환율 +2.5%와 금리 +50bp에서 입력을 4배로 키운 시험에서 트리 모델은 각각 26종목 중 22종목이 같은 값을 냈고 부분 풀링은 0종목이었습니다. 선형 반응이 유지된다는 뜻이며 극단 손익의 정확성이 검증됐다는 뜻은 아닙니다.

## 실제 후보 계산 예

최종 후보는 정해 둔 설정으로 다시 학습했으며 정답 종료일은 2026-10-08까지입니다. 시장 상태 기준일은 2026-10-30입니다. 이 최종 재학습 모델 자체의 새로운 독립 평가는 아직 없습니다.

유가 +10%, 다른 충격 0, 각각 100만 원 보유 조건입니다.

| 종목 | 무충격 모델값 | 유가 기여도 | 적용 후 모델값 | 가상 손익 |
| --- | --- | --- | --- | --- |
| 대한항공 | -0.607% | -1.167%p | -1.774% | 약 -17,736원 |
| S-Oil | +0.420% | +0.704%p | +1.123% | 약 +11,233원 |

이는 실제 발생 손익이 아니라 학습된 계수를 적용한 가상 손익입니다. 두 종목은 현재 상태의 유사 환경이 6개뿐이어서 전체 기간 계수로 돌아갔습니다. 입력 충격과 상태를 함께 만족하는 근접 사례는 0개라 가정 의존 상태로 표시합니다. 비슷한 실제 사건의 충격값과 실제 수익률은 별도로 반환합니다.

## 종목 범위

기존 20종목과 추가 6종목을 모두 보존했습니다. 평가 성능을 보고 종목을 제거하지 않았습니다. 지원은 종목 전체가 아니라 종목과 충격 조합별로 판단합니다. 최종 후보의 학습 안정성 규칙을 통과한 조합은 환율 26개, 미국 금리 24개, WTI 10개, VIX 26개입니다. 이것이 곧 정식 서비스 승인 목록은 아닙니다.

유가에 대한 경제적 노출을 우선 검토한 항공, 정유, 화학 중 대한항공, 아시아나항공, S-Oil, SK이노베이션, 롯데케미칼은 유가 계수 기준을 통과했고 LG화학은 통과하지 못했습니다. 경제적 노출은 후보를 정하는 근거이며 반응 방향을 강제로 정하는 제약이 아닙니다. 공표 시각과 권리변동 품질 검증도 완료해야 최종 지원으로 승인할 수 있습니다.

## 로컬 실행

저장소 루트에서 `PYTHONPATH=analytics/src`를 설정합니다. 기존 Python 의존성에 catboost, lightgbm, uvicorn이 필요합니다.

```text
python -m conditional_service.train_sensitivity --gold data/research_input.parquet --out outputs/sensitivity
python -m conditional_service.raw_target_control --gold data/research_input.parquet --out outputs/sensitivity
python -m conditional_service.audit_sensitivity outputs/sensitivity
python -m conditional_service.finalize_sensitivity --gold data/research_input.parquet --out outputs/sensitivity
python -m conditional_service.verify_sensitivity outputs/sensitivity/candidate_bundle.joblib
```

PowerShell에서 API를 실행합니다. 본인이 생성한 신뢰할 수 있는 모델 파일만 지정하세요.

```powershell
$env:PYTHONPATH = "$PWD/analytics/src"
$env:STRESSLAB_SENSITIVITY_BUNDLE = "$PWD/outputs/sensitivity/candidate_bundle.joblib"
python -m uvicorn conditional_service.sensitivity_api:app --host 127.0.0.1 --port 8140
```

`POST /analyze` 입력 예입니다.

```json
{"positions":[{"asset_id":"003490","value_krw":1000000},{"asset_id":"010950","value_krw":1000000}],"shocks":{"wti_pct":10}}
```

`results/sensitivity_service_20261104`에 종목별 성능, 계수 안정성, 입력 전후 계산, 외삽 시험, API 검증을 저장했습니다. 전체 모델 파일과 원본 학습 자료는 로컬에 보존합니다.

2023~2026년은 반복 사용한 개발 평가입니다. 실제 미래 충격을 사후 입력한 재구성이고 독립 블라인드 검증이나 인과효과 검증이 아닙니다. Gold의 공표 시각 누락과 추가 6종목의 과거 권리변동 전체 미인증도 남아 있습니다. 이번 완료 범위는 재현 가능한 민감도 계산과 로컬 서비스 후보 구현입니다.
