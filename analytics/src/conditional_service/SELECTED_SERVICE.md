# 충격별 지원 종목과 로컬 서비스 후보

현재 API는 모든 종목에 네 충격을 입력받습니다. [종목 확대 및 네 충격 분석](FOUR_SHOCK_SERVICE.md)이 최신 기준이며, 이전 입력 차단 실험은 기록으로 보존합니다.
26종목 중 학습 기간 기준으로 18종목을 선정하고 다시 학습했습니다. 최신 재학습에서 셀트리온의 미국 금리 계수가 불안정해져 제외했습니다. 현재 지원 후보는 17종목입니다. 운영 승인 목록이 아닙니다.

## 선정 기준

2021년 12월 10일까지 정답이 확인된 자료로 선정했습니다. 업종의 경제적 노출 가설, 가격 이력 5년 이상, 최근 252행 정상 비율 95% 이상, 겹치지 않는 학습 구간 100개 이상을 요구합니다. 전체 학습과 종료일을 6개월, 12개월, 18개월 앞당긴 학습에서 계수 부호가 같고, 계수 변동계수가 0.75 이하이며, 충격의 사분위 범위당 반응이 0.1%p 이상인 조합을 선택합니다.

이는 개발용 선정 규칙입니다. 서로 겹치는 학습 자료에서의 안정성이며 독립 사건 4개나 통계적 유의성 검정 통과를 뜻하지 않습니다. 2023~2026년은 반복 사용한 개발 평가 기간입니다. 평가 오차가 작은 종목을 골라 지원 목록에 추가하지 않았습니다. 업종 노출 가설을 기업별 인과효과로 해석하지 않습니다.

## 계산

무충격 기준 모델값 + 각 충격의 학습 계수 × 입력 변화량을 합산합니다. 금리는 bp, 환율과 WTI는 %, VIX는 포인트입니다. 0은 수준 유지입니다. 종목별 계수는 공통 계수와 종목별 편차의 합입니다. 상태별 계수는 비교 실험에만 남기고 기본 계산에서는 사용하지 않습니다.

A는 확정 일별 시장 상태로 과거 환경을 찾습니다. 사용자 충격을 바꿔도 최초 후보 날짜는 같습니다. B는 전체 기간에서 학습한 계수로 계산합니다. A의 사례는 관측 근거로 함께 제공하며 B의 계산값으로 대체하지 않습니다.

대한항공과 S-Oil을 각각 100만 원 보유하고 WTI +10%, 나머지 변화 0을 입력한 실제 로컬 결과입니다. 상태 기준일은 2026-10-30, 학습 정답 마지막 날짜는 2026-10-08입니다.

| 종목 | 무충격 모델값 | 유가 기여도 | 충격 적용 모델값 | 가상 손익 |
| --- | ---: | ---: | ---: | ---: |
| 대한항공 | -0.76% | -1.14%p | -1.89% | -18,943원 |
| S-Oil | +0.25% | +0.72%p | +0.97% | +9,748원 |

학습된 조건부 관계의 가상 계산입니다. 같은 시장에서 유가만 바뀌는 실험을 관측한 것이 아니며 실제 미래 손익을 보장하지 않습니다. 네 충격과 시장 상태가 함께 비슷했던 사례 수가 적으면 assumption_dependent로 표시합니다. 개별 충격 관측 범위를 벗어나면 정식 숫자는 비우고 탐색 계산만 따로 남깁니다.

지원하지 않는 충격이 0이 아니면 그 기여도와 전체 시나리오 손익은 null입니다. 지원되는 부분의 합은 별도로 표시합니다. 한 종목이라도 부분 분석이면 포트폴리오 전체 손익도 null입니다. exploratory 필드는 운영 결과로 표시하면 안 됩니다.

## 같은 종목과 날짜에서 비교

초기 선정 18종목, 155개 평가 날짜, 2,642개 종목 관측을 비교했습니다. 현재 제외한 셀트리온도 평가에서는 제거하지 않았습니다.

| 방식 | MAE | 방향 일치율 | 80% 포함률 | 평균 폭 | 급락 시 하방 이탈률 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 26종목 풀링의 공통 표본 | 4.119%p | 58.14% | 80.09% | 13.57%p | 61.56% |
| 종목별 Ridge | 4.146%p | 57.15% | 76.08% | 12.94%p | 62.12% |
| 선정 종목 재학습, 기본 계수 | 4.119%p | 58.10% | 79.56% | 13.32%p | 61.84% |
| 상태별 계수 선택, 비교용 | 4.109%p | 58.29% | 79.41% | 13.15%p | 62.67% |

급락은 실제 5일 수익률 -5% 이하이며 359개 관측입니다. 종목을 좁혔다고 수익률 정확도가 개선된 것은 아닙니다. 기본 계수 모델과 기존 풀링 모델의 MAE 차이는 +0.0003%p, 날짜 블록 95% 구간은 -0.0091~+0.0092%p입니다. 상태별 계산은 급락 하방 이탈이 더 많아 기본값으로 채택하지 않았습니다. 구간은 평가용이며 안전한 손실 한도로 제공하지 않습니다.

## 파일과 실행

`results/selected_service_20261104`의 selection.csv는 탈락 후보까지 포함한 선정 근거입니다. coefficients.csv는 종목별 네 계수와 재학습 안정성, per_asset.csv와 failure_cases.csv는 성능과 실패 사례입니다. examples.json은 실제 API 계산과 과거 사건, api_verification.json은 연결 검증 결과입니다. 기존 전체 종목 결과는 results/sensitivity_service_20261104에 보존했습니다.

저장소 루트에서 PYTHONPATH를 analytics/src로 설정합니다. Gold 계약은 변경하지 않습니다. 학습 입력은 기존 26종목 연구 Gold이고 prior에는 기존 민감도 연구 결과 경로를 넣습니다.

```text
python -m conditional_service.service_release --gold INPUT.parquet --prior PRIOR_RESULTS --out outputs/selected_service
python -m conditional_service.summarize_release outputs/selected_service
python -m conditional_service.verify_release outputs/selected_service/candidate_bundle.joblib
```

STRESSLAB_RELEASE_BUNDLE에 생성된 joblib 절대 경로를 설정한 뒤 실행합니다. 신뢰하는 로컬 학습 파일만 불러오세요.

```text
python -m uvicorn conditional_service.release_api:app --host 127.0.0.1 --port 8134
```

GET /support, GET /model-info, POST /analyze를 제공합니다. 입력 예시는 다음과 같습니다.

```json
{"positions":[{"asset_id":"003490","value_krw":1000000},{"asset_id":"010950","value_krw":1000000}],"shocks":{"wti_pct":10}}
```

## 재학습과 통합 순서

1. 새 Gold의 날짜, 종목, 수정주가, 결측, 실제 공표 가능 시각을 검사합니다. 5거래일 정답이 완성된 행만 학습합니다.
2. 새 버전으로 부분 풀링 계수를 학습합니다. 이전 모델과 지원 목록을 보존합니다. 계수가 불안정해진 조합은 지원 제외 사유를 기록합니다.
3. 모델 선택에 쓰지 않은 새 날짜에서 기존 모델과 후보를 같은 종목으로 비교합니다. 같은 날짜의 종목은 묶어서 재표본추출합니다. MAE와 급락 과소평가, 계수 안정성, 적용 범위를 함께 비교합니다.
4. 새 지원 종목은 학습 자료로 기준을 고정한 뒤 별도 미래 구간에서 검증합니다. 기존 평가 결과를 보고 추가하지 않습니다.
5. 품질 검사를 통과하고 새 평가에서 개선이 확인된 후보만 승인 대상으로 올립니다. 수동 승인 후 배포 버전을 변경하고 이전 버전으로 복구할 수 있게 보존합니다. 자동 학습이 자동 승격을 의미하지 않습니다.

이번에는 로컬 재학습과 API 검증까지만 실행했습니다. Azure 예약 작업, 운영 배포, Gold 변경은 하지 않았습니다. 공표 시각 6개 열이 비어 있고 전체 종목의 기업행사 처리가 최종 인증되지 않아 운영 승격은 차단합니다. 이는 민감도 계산 기능 미구현과는 다른 데이터 검증 과제입니다. 실제 운영 연결 전에 해당 품질 확인과 미사용 평가 기간 검증이 필요합니다.
