# Gold 20종목 연결

현재 로컬 서비스 모델은 [종목별 CatBoost](CATBOOST_SERVICE.md)입니다. 사용자 선택을 바로잡아 같은 20종목과 날짜로 비교한 뒤 연결했습니다. 아래 업종 Ridge 재학습과 구간 평가는 비교 기록으로 보존하며, Gold 입력 검사와 연결 방법은 공통입니다.

기존에 선택한 충격 반영 업종 Ridge를 그대로 사용합니다. `alpha=300`이며 새 모델 탐색은 하지 않았습니다. 현재 Fabric에서 받은 Gold의 20종목에 맞춰 로컬에서 다시 학습했습니다. Azure, Fabric 노트북, Gold 계약과 기존 운영 모델은 변경하지 않았습니다.

## 처리 순서

1. Gold Parquet를 읽고 컬럼, 종목, 중복, 수정주가 기준, 거시 지표 이용 가능 시각을 검사합니다.
2. 확정 일봉으로 5·20일 추세, 20·60일 변동성, 시장 상태를 계산합니다. 학습할 때만 이후 5거래일 수익률과 실제 거시 변화량을 정답으로 연결합니다.
3. A는 시장 상태만 사용해 과거 환경을 검색합니다. 사용자 충격은 검색에 넣지 않습니다.
4. B는 기존 업종 Ridge의 네 충격 계수를 사용합니다. 무충격 기준값, 충격별 기여도, 최종 수익률을 계산합니다.
5. 종목별 수익률에 보유금액을 곱해 가상 손익을 구하고 합산합니다. 과거 사례와 모델 결과를 한 응답에 반환합니다.

이 모델의 계수는 **업종 공통 계수**입니다. 같은 업종 종목은 같은 수익률을 계산합니다. 종목별 고유 민감도를 학습한 모델로 설명하면 안 됩니다. 시장 상태는 A의 근거 검색에 사용하며 B의 계수를 바꾸지는 않습니다.

## 이번 데이터 처리

Fabric 사본의 가격을 기존 검증된 20종목 자료와 날짜별로 대조했습니다. 공통 102,909행의 종가, 거래량, 코스피가 일치했습니다. 로컬 입력에는 기존 가격 기준과 격리 표시를 보존하고, 거시 값은 공표 근거가 확인된 당시 이용 가능 값으로 선택했습니다. 실제 공표 시각을 임의로 채우지는 않았습니다.

검증 근거가 없는 최근 60행은 제외했습니다. 로컬 기준일은 2026-10-30이며 최신 시장이라고 표시하지 않습니다. 현재 Fabric 사본 자체는 가격 기준과 공표 근거 누락으로 연결 검사에서 차단됩니다. 로컬 보정본이 통과했다는 이유로 Fabric 수정까지 완료된 것은 아닙니다.

가격 이력은 2000년부터 있지만, 공표 근거와 피처 조건까지 충족한 학습 표는 2014-04-17부터 2026-10-23까지 28,711행입니다. 공표 근거가 없는 과거 날짜를 임의로 채워 학습하지 않았습니다. 이번 수치의 적용 범위도 이 자료와 평가일에 한정됩니다.

## 결과

2023-01-02~2026-10-22, 85개 평가일, 1,600개 종목 관측을 평가했습니다. 과거에 실제 발생한 거시 변화량을 사후 입력한 조건부 재구성 평가입니다. 반복 사용한 개발 평가이며 독립 블라인드 테스트가 아닙니다.

| 지표 | 이번 20종목 | 0% 기준선 |
| --- | ---: | ---: |
| 중심값 MAE | 4.609%p | 4.639%p |
| RMSE | 6.424%p | 6.479%p |
| 방향 일치율 | 55.71% | 방향을 제시하지 않음 |

MAE 개선은 0.64%이며 날짜 블록 신뢰구간은 개선 없음도 포함합니다. 급락 243건 중 하락 방향은 49.38%, 실제 -5% 이하일 때 모델도 -5% 이하였던 비율은 2.06%입니다. 급락 예측 성능이 충분하다고 볼 수 없습니다.

기존 모델과 겹치는 13종목·같은 날짜 1,012건에서는 MAE가 기존 4.170%p, 이번 4.180%p입니다. 종목을 맞춘 재학습이지 성능 개선으로 채택한 변경이 아닙니다. LG에너지솔루션과 SK스퀘어는 초기 학습 표본이 부족해 2023~2024년 평가에서 제외했으며 2025년부터 포함했습니다. 최종 로컬 모델은 20종목을 모두 지원합니다.

## 실행

저장소에서 Python 환경을 활성화하고 실행하세요. 아래 두 경로는 실제 연구 폴더와 결과 저장 폴더로 바꾸면 됩니다. 원본 데이터와 모델 파일은 Git에 포함하지 않습니다.

```powershell
$env:PYTHONPATH = "$PWD\analytics\src"
$research = "C:\Users\shinm\OneDrive\문서\ChatGPT\새로운 프로젝트 2"
$bundle = "$research\reports\gold20_ready_20261109"
python -m conditional_service.gold_ready --root "$research" --out "$bundle"
python -m conditional_service.verify_gold_ready --root "$research" --out "$bundle"
$env:STRESSLAB_GOLD_BUNDLE = $bundle
python -m uvicorn conditional_service.gold_ready_api:create_app --factory --host 127.0.0.1 --port 8161
```

`http://127.0.0.1:8161/docs`에서 요청할 수 있습니다. `GET /support`는 지원 종목, `GET /model-info`는 모델과 데이터 기준일, `POST /analyze`는 분석 결과입니다. API 요청 때 재학습하지 않습니다.

```json
{
  "positions": [
    {"asset_id": "005930", "value_krw": 50000000},
    {"asset_id": "005380", "value_krw": 50000000}
  ],
  "shocks": {"fx_pct": 5, "us_rate_bp": 100, "wti_pct": 0, "vix_points": 0}
}
```

환율과 WTI는 변화율 %, 미국 10년 금리는 bp, VIX는 포인트 변화입니다. 0은 현재 수준에서 변화 없음입니다. 위 로컬 모델 예시의 가상 손익은 삼성전자 약 -1.53만원, 현대차 약 -28.94만원, 합계 약 -30.47만원입니다. 이 조합은 과거 지원 범위가 부족한 탐색 시나리오로 표시됩니다. 확정 손실이나 미래 예측값이 아닙니다.

| 응답 필드 | 의미 |
| --- | --- |
| `market_candidates` | 충격과 무관하게 찾은 과거 시장 |
| `macro_observations` | 지표별 관측일과 이용 가능 근거 |
| `baseline_model_return_pct` | 네 충격 변화량이 모두 0인 모델값 |
| `shock_contributions_pp` | 학습 계수에 각 충격을 적용한 변화 |
| `conditional_return_pct` | 기준값과 네 기여도의 합계 |
| `hypothetical_pnl_krw` | 보유금액 × 최종 수익률 / 100 |
| `historical_examples` | 선택한 과거의 실제 충격과 종목 반응 |
| `portfolio_hypothetical_pnl_krw` | 종목별 가상 손익 합계 |

전체 요청·응답은 결과 폴더의 `request.json`, `response.json`에 있습니다. 종목별 평가와 분할 기간은 `stock_metrics.json`, `splits.json`에 있습니다. 아래 구간은 별도로 평가했으며 API에는 적용하지 않았습니다.

저장소의 [검증 결과](gold_ready_results.json)에 종목별 성능, 평가 조건과 실행 패키지 버전을 함께 기록했습니다. 마지막 전체 자료 재학습 모델이 과거 외표본 모델과 동일한 성능을 낸다고 보장하지는 않습니다.

## 80%와 90% 구간 평가

위와 동일한 1,600건의 중심값을 유지했습니다. 각 평가 연도 직전 1년의 외표본 잔차를 당시 변동성으로 나누고, 종목별 분위수를 계산했습니다. 평가 시점의 변동성을 다시 곱해 구간을 복원했습니다. 학습, 보정, 평가의 정답 기간은 분리했으며 평가 결과로 폭을 조정하지 않았습니다.

| 목표 구간 | 실제 포함률 | 평균 전체 폭 | 급락 시 하한 이탈률 |
| --- | ---: | ---: | ---: |
| 80% | 69.69% | 13.53%p | 68.72% |
| 90% | 82.00% | 18.01%p | 46.50% |

폭은 상한에서 하한을 뺀 값이며 ± 폭이 아닙니다. 급락은 실제 5거래일 수익률 -5% 이하인 243건입니다. 두 방식 모두 목표 포함률에 미달합니다. 보정 표본이 종목·연도별 12~23개로 적고, 2026년에는 구간이 더 넓어졌는데도 하방 이탈이 많았습니다. 검증된 80%·90% 미래 위험 구간으로 서비스에 표시하면 안 됩니다.

```powershell
python -m conditional_service.gold_ready_intervals --out "$bundle"
```

종목별·연도별 수치와 시간 분할은 [구간 평가 결과](gold_ready_interval_results.json)에 있습니다. 원본 예측과 최종 모델은 보존했습니다. 구간별 모든 평가 행은 로컬 결과 폴더의 `interval_predictions.parquet`에 저장했습니다.

## 담당자 Gold가 완성되면

Gold를 Parquet로 내보내고 `STRESSLAB_GOLD_FILE`에 경로를 지정해 API를 다시 시작하세요. 계약은 그대로이며 입력 경로만 교체합니다. 현재 기본 경로는 로컬에서 검증한 입력본입니다.

공표 시각을 알 수 없어 공식 날짜 근거로 확인한 데이터는 별도 검증 근거와 파일 해시가 필요합니다. 이때 `STRESSLAB_GOLD_PROVENANCE`, `STRESSLAB_GOLD_CERTIFICATE`를 함께 지정합니다. 기존 인증 파일을 다른 Gold에 재사용하면 차단됩니다. 종목 수가 바뀌면 자동으로 계수를 복사하지 않고 명시적으로 재학습해야 합니다.

20종목의 15가지 충격 조합, 기여도 합계, 손익 합산, 미래 행 제거 전후 피처 일치, 미지원 종목, 극단 입력, 누락 파일, 변경된 데이터 거부를 검증했습니다. 실제 클라우드 Gold 연결은 담당자 수정 후 최종 입력 검사와 요청 한 번을 다시 확인하면 됩니다.
