# 초기 PoC부터 현재까지 구간 폭 점검

2026-11-05 기준입니다. 웹 통합을 중단하고 결과 파일과 저장된 분포를 확인했습니다. Azure, Gold 계약, 운영 모델은 변경하지 않았습니다. 폭은 모두 상한에서 하한을 뺀 전체 수익률 구간 폭(%p)입니다.

## 확인된 결론

80%와 90%, 1거래일과 5거래일, 지수와 개별 종목, 서로 다른 평가 표본을 섞어 설명한 문제가 있었습니다. 최근 폭 증가에는 보정 방식과 평가 종목 구성이 영향을 주었으며, 동일 표본 재학습에서는 데이터 정정의 영향이 작았습니다. 좁았던 초기 구간도 목표 포함률을 충족한 것은 아닙니다.

## 초기 PoC의 실제 수치

`reports/validation.json`은 초기 모델 선택과 포함률을 보존하지만 전체 폭을 저장하지 않았습니다. 초기 선택 모델의 폭은 `reports/v2/matched_comparison.csv`에 저장된 `v1_selected`의 동일 평가 표본 재계산 결과로 확인했습니다. 최초 화면의 특정 사용자 시나리오 폭과 평가 표본 평균 폭이 동일하다는 뜻은 아닙니다.

| 초기 선택 모델 | 기간 | 목표 포함률 | 실제 포함률 | 전체 폭 |
|---|---|---:|---:|---:|
| 삼성전자 | 1거래일 | 90% | 77.87% | 5.11%p |
| 현대차 | 1거래일 | 90% | 81.89% | 6.07%p |
| 신한지주 | 1거래일 | 90% | 84.38% | 5.54%p |
| 삼성전자 | 5거래일 | 90% | 75.00% | 11.47%p |
| 현대차 | 5거래일 | 90% | 88.59% | 17.51%p |
| 신한지주 | 5거래일 | 90% | 82.07% | 10.91%p |
| 코스피 지수 | 5거래일 | 90% | 79.89% | 8.43%p |

한 자릿수 폭은 실제로 존재했습니다. 그러나 이를 현재 개별 종목의 5거래일 90% 구간과 같은 결과로 비교하면 안 됩니다. 초기 5거래일 평가 표본은 자산별 184개였습니다.

v2, v3, v4의 저장된 예측 분포에서도 80%와 90%를 다시 계산했습니다. v2 Ridge 삼성전자는 80% 폭 12.11%p/포함률 71.74%, 90% 폭 18.67%p/포함률 88.59%였습니다. 초기부터 5거래일 90% 구간이 항상 한 자릿수였던 것은 아닙니다. 요약 JSON과 저장 분포 재계산에는 분위수 산출 차이로 소폭 차이가 있어 각각 출처를 보존했습니다.

## 이전 20종목과 현재 50종목

아래 이전 결과는 `pooled_hybrid_20261104`의 CatBoost 예측과 보정 예측으로 80/90%를 재계산했습니다. 가장 처음의 CatBoost 13.695%p와는 다른 재실행 결과입니다.

| 데이터와 보정 | 80% 폭 | 실제 포함률 | 90% 폭 | 실제 포함률 |
|---|---:|---:|---:|---:|
| 이전 20종목, 종목별 보정 | 13.83%p | 76.74% | 18.06%p | 85.21% |
| 이전 20종목, 통합 보정 | 14.40%p | 79.64% | 18.99%p | 88.52% |
| 현재 50종목, 종목별 보정 | 13.84%p | 71.47% | 18.10%p | 80.27% |
| 현재 50종목, 통합 보정 | 15.23%p | 78.17% | 20.91%p | 88.34% |

이전 표본은 2,928개/169일, 현재 표본은 4,150개/85일입니다. 이 표 자체를 데이터 정정의 인과적 영향으로 해석하지 않습니다. 같은 80%·종목별 보정 기준이면 13.83→13.84%p로 폭은 거의 같고, 실제 포함률이 악화됐습니다.

## 원인을 분리한 검사

### 1. 목표 포함률 변경

현재 50종목의 중심값과 보정 자료를 그대로 두고 80%에서 90%로 바꾸면 15.23→20.91%p입니다. 증가분은 **5.68%p**입니다. 더 먼 양쪽 잔차를 포함시킨 효과이며 모델 중심값 개선이 아닙니다.

### 2. 보정 방식 변경

현재 50종목·같은 날짜·같은 중심값의 90% 구간에서 종목별 보정을 통합 보정으로 바꾸면 18.10→20.91%p입니다. **2.81%p** 넓어지는 대신 실제 포함률은 80.27→88.34%입니다. 80% 구간에서는 13.84→15.23%p, 포함률 71.47→78.17%입니다. 좁은 종목별 구간은 과소 보정된 결과였으며 그 상태를 우수한 성능으로 보아서는 안 됩니다.

### 3. 종목 구성 변경

이전 20종목과 현재 50종목의 공통 종목은 13개입니다. 같은 현재 모델과 50종목 통합 보정을 유지하고 공통 13종목만 집계하면 90% 폭 19.36%p입니다. 추가 37종목은 21.41%p이며 전체 50종목은 20.91%p입니다. 추가 종목들의 더 큰 폭이 평균을 높였습니다. 종목 수 자체가 각 모델의 폭을 자동으로 늘리는 것은 아닙니다.

공통 13종목만으로 보정할 때 90% 폭은 18.45%p이며 보정 풀을 50종목으로 늘리면 같은 13종목에서 19.36%p입니다. 따라서 보정 풀의 구성 변화와 평가 대상 구성 변화는 별개입니다. 이 집계는 실제 사용 가능 날짜 구성을 유지한 비교이며 종목만의 인과효과로 해석하지 않습니다.

### 4. 데이터 정정

현재와 이전 데이터가 모두 있는 공통 13종목·1,012개 평가 행에서 CatBoost를 다시 학습했습니다. 학습·보정·평가 행, 모델 설정, 날짜 경계, 보정 방식을 고정하고 정정 전후 값만 바꿨습니다. 정정된 모델의 예측과 종목별 구간은 기존 저장 결과와 1e-9 허용오차 이내로 재현됐습니다.

| 공통 13종목 | 정정 전 폭 | 정정 후 폭 | 정정 전 포함률 | 정정 후 포함률 |
|---|---:|---:|---:|---:|
| 80% 종목별 보정 | 12.50%p | 12.52%p | 72.43% | 70.75% |
| 90% 종목별 보정 | 15.99%p | 16.00%p | 80.24% | 80.24% |
| 80% 통합 보정 | 13.93%p | 14.12%p | 77.87% | 77.77% |
| 90% 통합 보정 | 18.33%p | 18.45%p | 86.76% | 87.15% |

이 공통 표본에서는 정정이 폭 증가의 주원인이 아닙니다. 정정으로 제외된 행과 과거 전체 학습기간 변경의 효과까지 없다는 뜻은 아닙니다. 정정 전 값은 진단용으로만 사용했으며 서비스에 복원하지 않았습니다.

## 한 경로로 연결한 폭 변화

같은 공통 표본의 정정 전 80% 종목별 폭 12.50%p에서 출발하면 다음과 같습니다. 변경 순서에 의존하는 산술 분해이며 앞의 90% 비교 증가분과 중복 합산하지 않습니다.

| 순서 | 전체 폭 | 직전 대비 |
|---|---:|---:|
| 정정 전, 공통 표본, 종목별 80% | 12.50%p | 기준 |
| 같은 표본의 데이터 값 정정 | 12.52%p | +0.02%p |
| 공통 13종목 통합 보정 | 14.12%p | +1.60%p |
| 보정 풀을 50종목으로 변경 | 14.13%p | +0.01%p |
| 평가 집계를 전체 50종목으로 확대 | 15.23%p | +1.10%p |
| 목표 포함률을 90%로 변경 | 20.91%p | +5.68%p |

## 서비스 판단

넓은 구간을 주요 결과로 제시하는 것만으로는 사용자가 원하는 구체적인 위험 판단을 충분히 제공하지 못합니다. 현재 20.91%p를 정밀한 손실 예측이나 손실 한도로 표현해서는 안 됩니다. 그렇다고 낮은 실제 포함률을 숨기고 좁은 초기 구간으로 되돌릴 수도 없습니다.

현재 확인된 사실은 중심값이 설명하지 못한 잔차가 크고, 특히 개별 종목 꼬리 손실을 포함하려면 폭이 커진다는 점입니다. 이번 작업은 폭 증가 원인 진단이며 성능 개선을 달성한 작업이 아닙니다. 웹 통합과 모델 승격은 진행하지 않았습니다.
