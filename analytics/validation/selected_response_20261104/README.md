# 종목과 충격 조합을 고정한 반응 학습

2022년 이전 근거로 42종목 49개 조합을 선정했습니다. 이후 평가 결과로 목록이나 부호를 바꾸지 않았습니다. Azure, Gold 계약, 운영 모델은 변경하지 않았습니다.

## 무엇을 바꿨는지

관련 변수를 넣는 것에서 그치지 않고, 선정된 충격의 반응 방향을 학습 제약으로 적용했습니다. 예를 들어 S-Oil 유가 반응을 양수로 선정했다면, 같은 시장 상태와 다른 충격을 고정한 상태에서 유가만 올릴 때 계산 수익률이 낮아지지 않도록 했습니다. 수익률 자체를 양수로 강제하지는 않습니다. 이 제약은 검증할 통계적 가정이며 인과 법칙이 아닙니다.

네 충격 중앙값 기준선, 선정 충격 중앙값, 선정 충격 평균, 반응 방향을 반영한 평균 모델을 비교했습니다. 중앙값과 평균의 차이, 변수 제외 효과, 반응 제약 효과를 구분합니다. LightGBM의 동일한 깊이와 학습 횟수를 사용했습니다.

## 왜 앞선 분석과 성능이 달랐는지

1. 앞선 값은 유가 상승군과 하락군의 평균 차이입니다. 특정 충격에서 개별 종목 수익률을 맞힌 성능이나 1% 충격의 계수가 아닙니다. 기존 모델은 중앙값을 학습했습니다.
2. 대한항공은 장기 평균 유가 반응이 음수지만, 2016~2021년 다른 변수를 고려한 잔차 회귀에서는 기울기가 +0.0175이고 유의하지 않았습니다. 따라서 안정적인 독립 반응이라고 선정할 수 없습니다. S-Oil 유가 조합은 같은 엄격한 기준을 통과했습니다.
3. 기존 적용은 입력 변수 선택이었고, 분석에서 확인한 방향을 실제 학습 조건으로 사용하지 않았습니다. 이번에는 그 부분을 직접 반영하고 효과를 분리했습니다.
4. 같은 충격군 안에서도 수익률의 분산과 반대 방향 사례가 큽니다. 반응 차이가 존재하는 것과 개별 구간 방향을 80% 맞히는 것은 다른 문제입니다.

## 선정 기준

통제 변수 평균 균형 통과, 두 과거 시기 ALE 반응 부호 일치, 균형 비교와 ALE 부호 일치, 평균 대비 1%p 이상의 반응 차이, 잔차 회귀 부호 일치, BY 보정 q<0.05, 연도별 부호 일관성 80% 이상을 모두 요구했습니다. 기존 분석 결과를 활용한 탐색적 선정이며 독립 검증으로 볼 수 없습니다. 부호 일관성만으로 인과관계나 전체 조건의 단조성을 증명하지는 않습니다.

환율 12개, 유가 5개, VIX 32개 조합입니다. 미국 금리는 통과 조합이 없습니다. 모델에 넣지 않은 충격을 바꿔도 계산이 바뀌지 않으며, 이는 영향이 없다는 결론이 아니라 해당 모델의 지원 범위 밖이라는 뜻입니다.

## 검증 범위

2023~2026년의 기존 평가 날짜를 그대로 사용했습니다. 매년 이전 연도 시작 20일 전까지 정답이 끝난 자료로 학습하고, 직전 연도 중 정답이 평가 시작 20일 전에 끝난 표본으로 잔차 구간을 보정했습니다. 보정 표본은 매 여섯 번째 관측을 사용합니다. 학습, 보정, 평가의 정답 기간을 분리했습니다. time_audit.csv에 실제 시각과 표본 수가 있습니다.

실제 이후 5거래일 충격을 사후 입력한 조건부 재구성입니다. 평가 기간을 이미 여러 연구에서 사용했으므로 독립 블라인드가 아닙니다. 일부 공표 시각과 거시 데이터 빈티지는 추가 검증이 필요합니다.

shock_interventions.parquet는 같은 입력 행에서 한 충격만 학습 구간 25% 및 75% 분위수로 바꾼 모델 계산입니다. 실제 반사실 정답이 아니며, 주변 충격과의 공동 관측 범위까지 보장하지 않습니다. evaluation_contrasts.csv의 실제 상승군/하락군 비교는 별도의 관측 집단 비교입니다. 둘을 같은 효과라고 해석하면 안 됩니다.

uncertainty.csv는 동일 시점의 모든 종목을 함께 묶은 분기 블록 재표본추출 2,000회의 차이 구간입니다. asset_uncertainty.csv는 종목별 탐색 결과이며 이후 종목을 다시 고르는 데 사용하지 않았습니다.

## 재실행

`python run_selected_response.py --data-root <기존 연구 데이터 경로> --stage train`

이후 stage를 diagnosis, air-control, report 순서로 실행합니다. 입력은 reports/rich_context_20261103/learning_table.parquet, effect_atlas_20261104 분석 자료와 기존 평가 날짜입니다. 원천 데이터와 API 키는 공개 저장소에 포함하지 않습니다.

## 추가 원인 분리와 최종 판단

첫 비교에서 선정되지 않은 충격을 빼면 성능이 나빠졌습니다. 통제 변수로서의 역할을 확인하기 위해 네 충격을 모두 유지하고, 평균 학습과 이상치에 덜 끌리는 Huber 학습을 추가했습니다. 부호 제약은 앞에서 고정한 49개 조합에만 적용했습니다. 이 추가 비교는 첫 결과를 본 뒤 수행한 탐색이며 새로운 블라인드 평가가 아닙니다.

| 방식 | MAE(%p) | 방향 일치 | 80% 포함률 | 폭(%p) | 급락 하방 이탈 | 급락 중심 포착 |
|---|---:|---:|---:|---:|---:|---:|
| 네 충격 중앙값 | 4.459 | 57.6% | 70.8% | 11.26 | 68.5% | 53/923 |
| 선정 충격 중앙값 | 4.556 | 56.4% | 70.6% | 11.38 | 67.3% | 71/923 |
| 선정 충격 평균 | 4.772 | 56.0% | 69.9% | 11.58 | 66.5% | 82/923 |
| 선정 충격 평균 + 부호 | 4.771 | 56.0% | 69.6% | 11.60 | 66.2% | 92/923 |
| 네 충격 평균 | 4.690 | 56.8% | 69.2% | 11.34 | 67.2% | 78/923 |
| 네 충격 Huber | 4.355 | 59.5% | 72.1% | 11.18 | 71.0% | 0/923 |
| 네 충격 Huber + 선정 부호 | 4.342 | 59.7% | 71.9% | 11.17 | 71.7% | 0/923 |

Huber와 선정 부호를 결합하면 기준선 대비 MAE가 2.6% 줄고 방향 일치율은 2.09%p 높아졌습니다. 그러나 급락 시 하방 이탈은 68.5%에서 71.7%로 악화됐고, 중심값으로 -5% 이하 급락을 잡은 건 0건입니다. 전체 오차의 개선을 스트레스 분석 개선으로 승인하지 않았습니다. 목표인 평균 폭 5%p와 포함률 80%에도 미달합니다.

단조 제약을 추가한 효과와 Huber 학습 자체의 효과는 final_uncertainty.csv에서 분리했습니다. 부호를 강제한 것만으로 예측 정보가 늘었다고 주장하지 않습니다. 기존 운영 모델과 선정 규칙은 그대로 유지합니다.

대한항공의 유가 입력을 낮은 학습 분위수에서 높은 분위수로 바꿨을 때 기존 모델은 평가 상태의 92.2%에서 하락 반응을 계산했습니다. S-Oil은 99.3%에서 상승 반응을 계산했습니다. 이는 모델의 입력 변화 반응이며 실제 방향 적중률이 아닙니다. 관계가 아예 반영되지 않았던 것이 아니라, 반응의 평균 차이만으로 개별 5일 수익률의 큰 변동을 설명하지 못한 것입니다.

## 네 충격과 시장 상태의 합산

기존 공동 잔차 모델도 직접 확인했습니다. 시장 상태로 설명되는 수익률과 네 충격을 과거 외표본에서 각각 계산하고, 설명되지 않은 네 충격을 동시에 넣어 잔여 수익률을 학습하고 있었습니다. 환율과 유가를 따로 회귀해서 결과를 무작정 합치는 구조는 아닙니다.

`종목 수익률 = 시장 상태의 평균 반응 + Σ 계수 × (사용자 충격 - 해당 상태의 평균 충격)`

시장 상태 평균에 이미 포함된 충격 부분을 빼고 사용자 충격을 더하므로 중복을 방지합니다. 사용자에게는 이를 0충격 기준 수익률과 네 충격의 추가 기여도로 다시 나눌 수 있습니다. four_shock_decomposition.csv는 보존된 2026년 모델의 실제 합산입니다. recomposition_check.csv에서 42종목의 기존 계산과 일치함을 검증했습니다. 이 모델은 이번 동일 학습 구간 모델들과 학습 종료일이 달라, 추가 성능 비교에는 섞지 않았습니다.

이 분해는 관측한 변수에 대한 통계적 분해입니다. 누락 변수, 비선형 관계, 공표 시각 문제를 모두 없앤 순수한 인과효과는 아닙니다. 이미 수집한 모든 변수의 영향까지 완전히 설명했다고 주장하지 않습니다.

## 충격 0과 미입력의 차이

금리 +1bp는 금리 4.20%를 4.21%로 바꾸는 뜻입니다. 나머지 충격 0은 환율, 유가, VIX의 기존 수준 유지입니다. 수준을 0으로 만드는 것이 아닙니다. shock_semantics_check.json에서 계산을 검증했습니다.

0은 향후 5거래일 누적 변화가 0이라는 뜻입니다. 기간 중 전혀 움직이지 않는 경로를 학습한 모델은 아닙니다.

기존 웹앱 엔진은 요청에서 빠진 요인을 과거 관측값으로 주변화합니다. 따라서 금리만 보내는 요청과 나머지 세 충격을 모두 0으로 보낸 요청은 다릅니다. 연구 시나리오 도우미는 네 변화량을 전부 요구하며 누락을 거절합니다. 이번 연구에서는 웹앱, API, Azure 설정을 바꾸지 않았으므로 웹앱의 미입력 동작은 여전히 남아 있습니다.

추가 재실행 단계: followup, joint-audit, finalize. 모델을 서비스로 자동 승격하지 않습니다.
