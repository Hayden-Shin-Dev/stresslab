# 과거 재구성과 가상 충격 검증 분리

환율 +5%, 미국 국채 10년 금리 +100bp, 5거래일을 실제로 계산했습니다. 종목별 계산값, 충격 기여도, 과거 지원 범위, 충격 변경, 모델과 학습 기간 변경, 특정 사건 제외를 확인했습니다. 결과는 연구용 탐색 기능으로 제공할 수 있지만 검증된 예상 손익이나 손실 확률로 승인할 수는 없습니다.

## 계산 조건

시장 상태는 최신 저장 Gold인 2026-10-30 기준입니다. 현재 실시간 상태를 새로 받은 것은 아닙니다. 환율은 원/달러, 금리는 미국 10년 국채 수익률입니다. 한국 기준금리 +100bp를 뜻하지 않습니다. 지정하지 않은 WTI와 VIX 변화는 0으로 고정했습니다. 이 두 조건을 바꾸면 계산도 달라질 수 있습니다.

추론용 시장 상태 생성에는 미래 5일 정답이 필요하지 않도록 분리했습니다. 기존 학습 표는 수정 전과 동일한 것을 검사했습니다. 현재 상태에 아직 존재하지 않는 미래 수익률을 채우지 않았습니다. Gold 계약과 Azure는 변경하지 않았습니다.

현재 재학습 모델은 정답 종료일이 상태 기준일보다 20일 이상 앞선 자료만 사용했습니다. 최근 8년만 학습한 모델, 이전 백테스트와 같은 2026년 고정 모델도 비교했습니다. 현재 재학습한 모델이 이전 백테스트의 성능을 그대로 보장받는 것은 아닙니다.

## 1. 과거 충격 재구성 성능

이 검증에는 실제 정답이 있습니다. 과거 시장 상태와 이후 실제 발생한 거시 충격을 입력하고 같은 5거래일 종목 수익률과 비교합니다. 사용자 가상 충격을 실제 미래 수익률과 비교한 것이 아닙니다. 인과효과 검증도 아닙니다.

이전 연구의 동일한 20종목, 2,872개 시간순 외표본을 근거로 사용했습니다. 이번 추론 경로 분리 후 학습 표가 동일한 것도 검사했습니다. 아래는 이미 수행한 재구성 평가이며 새 재학습 모델의 독립 검증 결과로 표시하지 않습니다.

| 방식 | 중심 MAE | 80% 포함률 | 평균 폭 | 실제 종목 급락 시 하방 이탈 |
| --- | ---: | ---: | ---: | ---: |
| 기존 Ridge + 변동성 | 4.77%p | 81.9% | 15.62%p | 40.6% |
| 확장 LightGBM + 잔차 | 4.64%p | 79.1% | 14.53%p | 48.3% |
| 확장 LightGBM + 검색 잔차 | 4.64%p | 79.3% | 14.58%p | 48.6% |

같은 평가 기간을 여러 연구에 사용했으므로 독립 블라인드 시험이 아닙니다. 이 성적을 아래 +5%/+100bp 시나리오의 확률로 표시하지 않습니다.

## 2. 사용자 가상 충격 계산값

아래는 현재 상태와 요청 조건을 넣은 연구용 모델 중심값입니다. 모델을 승인하거나 어느 값이 정답이라고 선택한 표가 아닙니다. 보유금액 100만원을 종목별로 적용했습니다.

| 종목 | 현재 재학습 Ridge | 100만원 기준 | 현재 재학습 LightGBM | 100만원 기준 |
| --- | ---: | ---: | ---: | ---: |
| 삼성전자 | -0.214% | -2,141원 | +0.902% | +9,017원 |
| 현대차 | +0.542% | +5,425원 | -1.092% | -10,921원 |

별도 포트폴리오 모델은 없습니다. 금액은 종목별 중심 수익률 × 보유금액 / 100입니다. 나머지 18종목도 scenario_returns.csv에 있습니다. 이 특정 가상 충격에 대해 실제 정답이 없으므로 적중률이나 MAE를 붙이지 않았습니다.

### 왜 이런 숫자가 나왔는가

충격이 0인 입력의 계산값과 환율 및 금리 입력 변경의 기여를 분리했습니다. 환율과 금리를 적용하는 순서를 서로 바꾼 두 결과를 평균해 비선형 상호작용을 나눴습니다. 합계는 최종 계산값과 일치합니다. 금융적 인과 기여도가 아니라 모델 입력 변경에 대한 수치 분해입니다.

| 종목 및 모델 | 환율·금리 0일 때 | 환율 +5% 기여 | 금리 +100bp 기여 | 합계 |
| --- | ---: | ---: | ---: | ---: |
| 삼성전자 Ridge | -0.974% | -3.122%p | +3.881%p | -0.214% |
| 삼성전자 LightGBM | -0.073% | +0.102%p | +0.873%p | +0.902% |
| 현대차 Ridge | -1.389% | -0.734%p | +2.666%p | +0.542% |
| 현대차 LightGBM | -0.339% | -1.229%p | +0.477%p | -1.092% |

반올림 때문에 표의 합계 끝자리에 차이가 있을 수 있습니다. 코드에서는 오차 1e-9 이내로 일치합니다. 잔차를 더해 중심값을 인위적으로 바꾸지는 않았습니다. 충격이 0인 경우도 현재 시장 상태를 조건으로 계산한 값이므로 0% 수익률을 뜻하지 않습니다.

Ridge에서 금리 입력이 양의 기여를 만드는 것은 과거 자료에서 추정한 계수 때문입니다. 금리가 오르면 주가가 오른다는 인과관계나 금융 이론으로 해석하면 안 됩니다. 특히 +100bp는 아래와 같이 관측 범위 밖입니다.

## 3. 과거에 이 조건을 뒷받침하는 사례가 있는가

희귀 충격을 건너뛰지 않도록 전체 일별 시작 구간도 별도로 검사했습니다. 6일 간격 표본만 보고 사례가 없다고 판단하지 않았습니다.

| 종목 | 학습 가능한 전체 일별 구간 | 실제 5일 미국 금리 변화 범위 | 요청과 가까운 조합 |
| --- | ---: | ---: | ---: |
| 삼성전자 | 6,485개 | -74~+58bp | 0개 |
| 현대차 | 6,493개 | -74~+58bp | 0개 |

가까운 조합은 환율 +5%에서 ±1.25%p, 금리 +100bp에서 ±25bp로 정의했습니다. 이 허용 범위는 근거 수 확인용이며 신뢰성 승인 규칙은 아닙니다. 금리 최소 경계 +75bp도 관측 최대 +58bp보다 높습니다. 전체 이력과 유사 시장 후보 안에서 모두 0개였습니다. 유가와 VIX 조건까지 적용해도 0개입니다.

현재 시장 상태만으로 골라낸 과거 후보 중에는 삼성전자 기준 2022-06-07 시작 사례가 있습니다. 실제 충격은 환율 +2.41%, 미국 금리 +39bp, 유가 +2.12%, VIX +8.95포인트였습니다. 삼성전자 실제 반응은 -5.50%였습니다. 이 수익률을 100만원에 적용하면 약 -54,962원입니다.

이것은 해당 과거 사건의 재현 손익입니다. 사용자가 입력한 +5%/+100bp의 손익으로 이름을 바꾸거나 비례 확대하지 않았습니다. 검색된 과거 사건과 사용자 조건의 차이를 historical_cases.csv에 보존했습니다. 검색용 간격 표본 수와 전체 일별 지원 범위 검사를 구분했습니다. 겹치는 날짜를 독립 사건으로 세지 않도록 지원 자료에는 겹치지 않는 정답 구간 수를 별도로 기록했습니다.

## 4. 충격을 변경하면 어떻게 되는가

현재 재학습 모델에서 시장 상태, 유가, VIX를 고정한 결과입니다.

| 환율 / 미국 금리 충격 | 삼성전자 Ridge | 삼성전자 LightGBM | 현대차 Ridge | 현대차 LightGBM |
| --- | ---: | ---: | ---: | ---: |
| +2.5% / +50bp | -0.594% | +0.785% | -0.423% | -1.136% |
| +5% / +100bp | -0.214% | +0.902% | +0.542% | -1.092% |
| +7.5% / +150bp | +0.166% | +0.902% | +1.508% | -1.092% |

Ridge는 추정된 선형 계수를 범위 밖까지 적용합니다. LightGBM은 두 큰 충격에서 같은 값을 반환했습니다. 이것은 +100bp와 +150bp가 금융적으로 같은 위험이라는 증거가 아니라 해당 입력들이 같은 트리 구간으로 들어간 결과입니다. 충격 값을 받아 계산하는 연결은 확인했지만 극단 구간의 반응 모양이 검증된 것은 아닙니다.

환율만 변경하거나 금리만 변경한 결과, 반대 방향 충격도 함께 저장했습니다. 충격만 바꿨을 때 A의 시장 상태 검색 입력은 그대로 유지되는 것을 확인했습니다.

## 5. 가정과 학습 자료를 바꿔도 결과가 유지되는가

동일한 +5%/+100bp 입력에서 학습 범위만 바꿨습니다.

| 종목 | 전체 이력 Ridge | 최근 8년 Ridge | 전체 이력 LightGBM | 최근 8년 LightGBM |
| --- | ---: | ---: | ---: | ---: |
| 삼성전자 | -0.214% | -11.016% | +0.902% | -1.701% |
| 현대차 | +0.542% | -6.709% | -1.092% | -1.387% |

이 차이는 확률 구간이 아니라 모델 민감도입니다. 가장 크게 손실이 나온 모델을 선택하지 않았습니다. 이전 백테스트의 2026년 고정 모델에서도 별도 계산했고 scenario_returns.csv에 남겼습니다.

삼성전자의 가까운 과거 후보인 2022-06-07 주변 자료를 제외하면 전체 이력 Ridge 계산은 -0.214%에서 +0.191%로 부호가 바뀌었습니다. 현대차에서 2008-09-12 주변 자료를 제외하면 LightGBM 계산은 -1.092%에서 -0.102%로 바뀌었습니다. 이것은 특정 사건의 인과효과가 아니라 학습 자료 선택에 대한 민감도입니다.

## 서비스 적용 판단

| 제공 항목 | 판단 |
| --- | --- |
| 과거 실제 사건과 실제 종목 반응 표시 | 제공 가능. 원래 충격과 기간을 명시합니다. |
| 과거 반응을 현재 보유금액에 적용 | 제공 가능. 과거 사건 재현으로 표시합니다. |
| 사용자 가상 충격의 모델별 계산값 및 요인 분해 | 연구용 탐색으로 제공 가능. 모델·가정·관측 범위와 차이를 함께 보여줍니다. |
| +5%/+100bp에서 예상 손실 하나를 대표값으로 확정 | 현재 근거로 승인하지 않습니다. 모델과 학습 범위에 따라 부호가 바뀝니다. |
| 이 충격의 손실 확률 또는 검증된 80% 구간 표시 | 승인하지 않습니다. 과거 전체 포함률을 이 시나리오의 확률로 전용하지 않습니다. |

결론은 계산 자체를 막자는 것이 아닙니다. 요청한 충격을 넣은 계산값과 실제 근거는 제공하되, 이 조건에서 모델이 신뢰할 만한 손실 수치를 산출한다고 약속할 근거가 부족하다는 판단입니다. StressLab의 핵심 가상 충격 모델이 완성됐다고 보고하지 않습니다. 화면 경고만 붙이면 모델이 검증되는 것도 아닙니다.

현재 로컬 service_payload.json은 이 구분을 담습니다. mode는 exploratory, approved_as_expected_loss는 false이며 각 종목의 모델별 값, 금액, 요인 분해, 과거 지원 범위를 제공합니다. 운영 웹앱에 반영하거나 Azure를 변경하지 않았습니다.

## 재실행과 자료

1. hypothetical_scenario_audit.py: 미래 정답 없는 최신 상태 생성, 20종목 실제 학습, 9개 충격 조건, 요인 분해, 학습 범위 및 사건 제외 실험
2. finalize_hypothetical_validation.py: 전체 일별 지원 범위와 겹치지 않는 표본 수 확인, 서비스 판정 데이터 생성

Gold v1.1과 이전 asset_feature_research_20261103/learning_table.parquet를 사용합니다. STRESSLAB_AUDIT_ROOT로 원래 프로젝트 경로를 지정할 수 있습니다. 과거 공표 시각과 수정 이력은 여전히 부족해 완전한 시점 일치 데이터는 아닙니다. Gold 원본 출처와 해시는 protocol.json에 보존했습니다.

scenario_returns.csv는 모든 종목과 조건의 실제 출력, factor_attribution.csv는 합산 가능한 입력 기여도, dense_support.csv는 전체 일별 지원 범위, historical_cases.csv는 과거 관측 반응, event_sensitivity.csv는 사건 제외 결과입니다. query_states.csv와 gold_snapshot.parquet에는 사용한 시장 상태가 있습니다.
