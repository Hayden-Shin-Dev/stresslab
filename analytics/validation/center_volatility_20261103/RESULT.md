# 중심값과 대칭 변동성 구간 비교

## 수행한 작업

Gold v1.1 데이터로 LightGBM, XGBoost, Ridge를 학습하고 같은 변동성 구간을 붙였습니다. LightGBM과 XGBoost는 50% 분위수, 즉 중앙값을 학습합니다. Ridge는 제곱 오차를 줄이는 평균 모델이므로 중앙값 모델이라고 표시하지 않았습니다. 학습 수익률을 당시 변동성으로 나누고 추론 시 해당 변동성을 다시 곱했습니다. 양의 고정 배율이므로 조건부 중앙값의 의미는 유지됩니다.

단순 비교용으로 학습 데이터의 고정 중앙값을 중심으로 쓰는 방식도 포함했습니다. 모든 방식은 같은 피처, 날짜, 종목을 사용합니다. 연도별 학습과 보정 구간은 이전 Gold 검증과 동일합니다. 평가에 맞춘 파라미터 조정은 하지 않았습니다.

## 구간을 만드는 공식

최근 20거래일 일별 수익률 표준편차를 s20, 60거래일 표준편차를 s60이라고 하면 다음과 같습니다. 수익률과 표준편차 단위는 %입니다.

```
5일 변동성 = sqrt(5 × (s20² + s60²) / 2)
하한 = 모델 중심값 − 1.645 × 5일 변동성
상한 = 모델 중심값 + 1.645 × 5일 변동성
전체 폭 = 2 × 1.645 × 5일 변동성
```

1.645는 정규분포를 가정했을 때 가운데 90%를 잡는 배수입니다. 수익률이 정규분포를 따른다거나 5일 변동성이 정확히 일별 변동성의 sqrt(5)배라는 보장은 없습니다. 추정된 수익률 변동성을 모델 오차의 변동성과 동일하다고 가정하는 것도 별도 검증이 필요합니다.

같은 공식에서는 중심값만 좋아져도 폭이 줄지 않습니다. 폭은 변동성에 의해서만 결정됩니다. 중심값 개선이 폭 축소로 이어지는지도 확인하려고 두 번째 실험에서는 이전 연도 abs(실제 수익률 − 중심값) / 5일 변동성의 90% 경계로 배수를 정했습니다. 평가 연도의 정답으로 배수를 고르지 않았습니다.

## 평가 범위

2023-01-02~2026-10-19, 20종목 2,928개 종목별 표본입니다. 포트폴리오는 삼성전자와 현대차 각 50%, 155개 평가일입니다. 매년 학습을 갱신하고 이전 연도는 보정에 사용했습니다. 관측 구간은 겹치지 않도록 추렸지만 경제적으로 독립된 사건이라는 뜻은 아닙니다.

이전에 살펴본 평가 기간이며 독립 블라인드 테스트가 아닙니다. Gold 공표 시각 누락, 과거 자료 수정 이력, 현재 종목 구성에 따른 생존 편향도 남아 있습니다. 실제 발생한 충격을 사후 입력하는 조건부 재구성 평가이며 충격 발생 예측이나 인과효과 검증은 아닙니다.

## 동일한 변동성 공식 결과

포트폴리오 평가금액 1억원 기준입니다.

| 중심 계산 | 평균 손익 오차 | 포함률 | 전체 구간 폭 | 하위 경계 초과율 |
|---|---:|---:|---:|---:|
| 고정 중앙값 기준 | 368만원 | 87.1% | 15.62%p | 4.5% |
| Ridge | 342만원 | 89.7% | 15.62%p | 3.2% |
| LightGBM 중앙값 | 364만원 | 89.7% | 15.62%p | 3.2% |
| XGBoost 중앙값 | 359만원 | 89.0% | 15.62%p | 3.2% |

Ridge의 평균 오차는 기준보다 약 7.3% 줄었습니다. 날짜 단위 블록 재표집에서 평균 오차 차이는 -0.535~-0.007%포인트였습니다. 구간 점수 차이 구간은 0을 포함하므로 구간 품질 전체가 확실히 개선됐다고 단정하지 않습니다. 여러 모델을 이미 본 자료로 비교한 탐색 결과입니다.

실제로 5% 넘게 손실 난 13개 구간에서는 하위 경계를 놓친 횟수가 기준 5회에서 세 모델 모두 3회로 줄었습니다. 이는 하락일만 고른 실패 분석이며 이 그룹에 목표 초과율 5%를 적용하면 안 됩니다.

20종목 전체 포함률은 Ridge 89.5%, LightGBM 89.7%, XGBoost 89.0%였습니다. 그러나 폭은 약 20.00%포인트이고 평균 오차는 각각 4.780, 4.616, 4.686%포인트였습니다. 고정 중심 기준은 4.621%포인트이므로 포트폴리오의 오차 개선을 전체 종목에 일반화할 수 없습니다.

## 중심값 개선으로 필요한 폭도 줄었는가

이전 연도 오차로 배수를 정한 대칭 구간 결과입니다.

| 중심 계산 | 포함률 | 전체 구간 폭 |
|---|---:|---:|
| 고정 중앙값 기준 | 96.1% | 24.95%p |
| Ridge | 95.5% | 21.50%p |
| LightGBM | 94.8% | 22.46%p |
| XGBoost | 94.2% | 22.24%p |

보정 방식 안에서는 Ridge가 기준 대비 폭을 약 13.8% 줄였습니다. 하지만 보정에 쓰인 37~38개 구간의 큰 오차 때문에 배수가 1.645보다 높았고, 평가 기간에서는 전체적으로 지나치게 넓은 구간이 됐습니다. 이 보정이 고정 공식보다 나은 정식 방식이라는 결과는 아닙니다.

## 폭 5%포인트 목표

현재 변동성 공식에서 전체 폭이 5%포인트가 되려면 혼합 일별 표준편차가 약 0.68%여야 합니다. 이번 포트폴리오 평가에서 공식이 만든 가장 좁은 폭도 5.78%포인트였습니다.

중심값 ±2.5%포인트로 강제로 줄인 진단 구간의 포함률은 Ridge 46.5%, LightGBM 45.8%, XGBoost 47.7%였습니다. 이것을 90% 구간으로 제공하지 않습니다. 고정 변동성 구간으로 포함률 약 90%는 나왔지만 폭 5%포인트 목표는 미달입니다.

## 신뢰성 판단

| 기준 | 확인 내용 |
|---|---|
| 데이터 지원 범위 | scenario_metrics.csv에 시장 상태와 충격 그룹별 근접 과거 구간 수와 평가 표본 수를 기록했습니다. 극단 충격까지 승인한 결과는 아닙니다. |
| 외표본 성능 | 동일 표본에서 중심 모델과 구간 공식을 분리해 비교했습니다. 포트폴리오 Ridge의 오차 감소는 관측됐지만 전체 종목에서는 일관되지 않았습니다. |
| 하방 위험 | 전체 하위 경계 초과율과 실제 큰 손실 구간의 누락 횟수를 함께 확인했습니다. 상방 초과율은 세 모델 모두 7% 안팎으로 대칭 구간의 양쪽 오차가 균형적이지 않았습니다. |
| 모델 안정성 | 연도별 학습을 수행하고 보정 배수를 저장했습니다. 배수는 연도마다 달랐습니다. 모든 학습 기간과 파라미터에서 결론이 유지된다는 검증은 아닙니다. |
| 포트폴리오 정합성 | 동일 날짜의 실제 50/50 손익으로 학습했습니다. 변동성은 종목 변동성을 단순 평균하지 않고 공동 일별 수익률에서 계산했습니다. 5일 목표는 최초 50/50 투자금 기준이며 일별 균등가중 수익률의 변동성 환산은 근사입니다. 임의 비중이나 종목별 위험 기여도까지 검증하지는 않았습니다. |

최근 약 3개월은 9개 평가일뿐이며 고정 공식의 폭이 31.62%포인트였습니다. 포함률 100%를 높은 정확도로 해석하지 않습니다.

## 결론

제안한 방법은 실제로 구현 가능하고, 중심값 개선이 같은 폭에서 위험 포착을 개선하는 사례를 확인했습니다. 다만 시장 수익률 변동성으로 폭을 고정하면 중심 모델 개선이 곧바로 폭 축소로 이어지지 않습니다. 이전 연도 오차로 폭을 조정한 실험에서도 요청한 폭과 포함률을 함께 달성하지 못했습니다.

서비스나 Azure는 변경하지 않았습니다. 결과를 좋은 부분만 골라 정식 모델로 승격시키지 않았습니다.

실행: STRESSLAB_AUDIT_ROOT를 로컬 작업 폴더로 지정한 뒤 center_volatility_benchmark.py를 실행하세요. Gold 입력은 exports/seongjin_gold_v1_1/gold_stress_daily.parquet입니다. 동일 표본 검사는 이전 reports/gold_quantile_benchmark_20261103/predictions.parquet을 사용합니다. 원본 데이터는 공개 저장소에 복제하지 않았습니다.
