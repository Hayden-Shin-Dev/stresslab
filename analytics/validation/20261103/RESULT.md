# 장 검색과 스트레스 성능 검증

2026-11-03 로컬 평가입니다. Azure 설정과 서비스 모델은 변경하지 않았습니다.

## 결론

장 검색은 비슷한 지수 환경을 설명하는 용도로 쓸 근거가 있습니다. 그러나 검색을 추가하거나 Ridge에 시장 상태를 넣는 것이 손실 계산 성능을 높인다는 결과는 나오지 않았습니다. 두 기능의 유용성을 구분해야 합니다.

## 평가 조건

KRX, ECOS, FRED 공식 자료를 사용했습니다. 기존 184개 평가일 중 모델 공통 입력이 있는 183개 날짜, 2023-01-02~2026-10-06을 평가했습니다. 20종목 중 학습 기간이 없는 LG에너지솔루션과 SK스퀘어는 제외했습니다. 나머지 18종목은 총 3,285개 종목별 평가 표본입니다. 삼성전자우를 포함하므로 보통주 18종목이나 코스피 전체 검증은 아닙니다.

학습은 2019년까지, 잔차 보정은 2020~2022년으로 고정했습니다. 모델끼리 같은 날짜와 종목을 비교했습니다. 기존에 살펴본 기간이므로 독립 블라인드 테스트가 아닙니다. 실제 발생한 충격을 사후 입력한 조건부 반응 평가이며 인과효과 검증도 아닙니다.

## A. 장 검색이 유용한가

사용자 충격 없이 확정 일별 상태 6개로 검색했습니다. 검색에 직접 넣지 않은 지표로 최근 사례 선택 및 무작위 선택과 비교했습니다.

| 확인 항목 | 결과 |
|---|---|
| 최근 60일 고점 대비 낙폭 차이 | 최근 사례 선택보다 29.8% 작았습니다. 다만 추세 피처와 관련된 지표입니다. |
| 관측 20종목의 하락 비율 차이 | 최근 사례 선택보다 개선되지 않았습니다. 코스피 전체 하락 비율은 아닙니다. |
| 작은 상태 변화 | 선택된 20개 구간 중 평균 95.9%가 유지됐습니다. |
| 큰 상태 변화 | 평균 23.4%가 유지됐습니다. |
| 상태 검색 후 충격 사례 재현 | 충격만으로 검색한 방식보다 손익 오차가 유의하게 줄지는 않았습니다. |

작은 변화와 큰 변화는 인위적인 격리 실험입니다. 실제 장중 틱 검증으로 해석하지 않습니다. 현재 확정 구조에서는 장중 데이터가 일별 모델에 들어가지 않습니다.

검색된 구간 12개는 독립 위기 12개가 아닙니다. 구간 하나를 제외했을 때 포트폴리오 대표 손익의 부호가 바뀐 날짜가 18.6%였습니다. 특정 위기 전체를 제외하는 검증보다 약한 검사이므로 상승 또는 하락을 단정할 근거로 부족합니다.

## B. 스트레스 성능

삼성전자와 현대차 각 50%, 평가금액 1억원 기준입니다. 오차는 실제 5일 수익률과 모델 중앙값의 평균 차이입니다. 구간 폭과 구간 점수는 %포인트 단위이며 점수는 작을수록 좋습니다.

| 계산 방식 | 평균 금액 오차 | 90% 구간 포함률 | 평균 구간 폭 | 구간 점수 |
|---|---:|---:|---:|---:|
| 단순 변동성 기준 | 366만원 | 92.3% | 17.41 | 22.62 |
| 충격만 입력한 Ridge | 355만원 | 91.3% | 16.53 | 22.08 |
| 시장 상태와 충격 Ridge | 365만원 | 92.3% | 16.50 | 22.15 |
| 시장 상태와 ECOS, 충격 Ridge | 369만원 | 91.3% | 16.46 | 22.36 |

시장 상태와 충격 Ridge의 기준 모델 대비 평균 오차 개선은 약 0.3%에 그쳤습니다. 날짜 단위 블록 재표집의 오차 차이 구간은 -0.195~+0.175%포인트로 개선을 뒷받침하지 못했습니다. ECOS 추가도 이 포트폴리오에서 개선되지 않았습니다.

18종목 전체에서도 시장 상태와 ECOS 모델의 평균 오차는 4.703%포인트로 변동성 기준 4.472보다 컸습니다. 같은 평가 표본 기준입니다. 시장 상태를 제외한 모델은 4.369였습니다. 시장 상태 입력의 추가 가치가 확인되지 않은 것이며, 시장 상태 자체가 불필요하다고 증명한 것은 아닙니다.

최근 약 3개월 구간은 11개 평가일뿐입니다. ECOS 포함 모델의 포함률은 100%였지만 구간 폭이 31.76%포인트이고 평균 금액 오차가 715만원이었습니다. 포함률만 보고 성능이 좋다고 판단할 수 없습니다. 전체 기간 하위 5% 경계 초과율도 포트폴리오는 0.55%로 목표 5%보다 훨씬 낮아 보수적으로 치우쳤습니다. ES의 신뢰성을 승인할 만큼 꼬리 관측이 충분하지 않습니다.

## 가상 충격

2026-10-06 상태를 고정한 ECOS 포함 모델에서 환율 +5%, 미국 10년 금리 +100bp는 중앙값 -176만원, +10%와 +200bp는 -86만원이었습니다. 큰 충격에서 손실이 줄어드는 반응이 여전히 있습니다. 이를 오류라고 단정하지도, 금융적으로 타당하다고 승인하지도 않습니다.

포트폴리오 학습 구간에는 환율 절대 변화 5% 이상과 금리 절대 변화 100bp 이상이 동시에 나타난 5일 구간이 0개였습니다. 방향까지 구분하지 않은 느슨한 검사에서도 0개이므로 이 수치를 검증된 극단 손실로 제공할 근거가 없습니다. 표의 값은 실패 사례를 공개하는 진단 결과입니다.

## 남은 제한과 개발 판단

거시 공표 시각 일부는 실제 기록이 아닌 일정 추정입니다. Gold의 공표 시각도 비어 있어 완전한 당시 이용 가능 정보 검증은 아닙니다. 현재 구성 종목만 사용한 생존 편향도 있습니다. 2019년까지 학습한 고정 모델의 평가이므로 최신 재학습 모델의 성능을 뜻하지 않습니다. 충격 관측 끝점은 기존 공식 패널 기준이며 모든 시장의 동시 체결 시각을 맞춘 것은 아닙니다.

따라서 A는 일별 시장 설명과 사례 탐색 기능으로 유지할 수 있습니다. B는 비교용 연구 모델로 유지하되 현재 결과로 정식 손실 추정 성능을 승인하면 안 됩니다. 다음 판단에 필요한 것은 알고리즘 추가가 아니라 실제 공표 시각과 충격 관측 구간을 확정하고, 평가 결과로 조정하지 않는 시점별 재학습을 수행하는 것입니다. 이후에도 기준 모델 대비 가치가 없다면 현재 상태 피처를 B에 넣는 설계를 재검토해야 합니다.

실시간 장 분석, 과거 사건 재현, ML 추정은 구분합니다. 검색이 된다는 사실과 모델이 유용하다는 주장은 별개입니다.
