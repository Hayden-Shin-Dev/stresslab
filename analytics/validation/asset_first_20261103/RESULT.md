# 종목별 조건부 스트레스 모델 검증

최우선 대상은 종목별 모델입니다. 입력은 확정 일별 시장 상태, 종목 상태, 사용자 충격입니다. 출력은 종목별 중심 수익률과 80% 수익률 구간입니다. 포트폴리오는 종목별 중심 수익률에 보유 평가금액을 곱해 합산합니다. 별도 포트폴리오 ML은 이번 평가와 선정 대상에서 제외했습니다.

이전 보고에서 포트폴리오 포함률을 앞세워 종목별 모델의 성능을 판단한 것은 적절하지 않았습니다. 이번 결과는 기존에 학습한 종목별 모델의 저장된 시간순 외표본 예측을 다시 평가한 것입니다. 새 모델 학습이나 성능 개선 결과로 표시하지 않습니다.

## 같은 종목과 시점의 결과

20종목, 종목과 날짜 조합 2,872개를 비교했습니다. 비교 방법마다 같은 행인지 확인했습니다. 종목별 표본 수는 72~152개입니다. 특정 종목의 부족한 학습 이력 때문에 평가 시작 시점이 다르며, 모델 사이에서는 해당 종목의 평가 날짜를 동일하게 맞췄습니다.

아래는 모든 종목 평가 행을 합친 결과입니다. 보정 기간은 5년이고 직접 분위수 방식만 별도입니다. 중심 오차는 잔차 보정 전 모델 출력과 실제 수익률 사이의 평균 절대 오차입니다. Ridge의 중심은 조건부 평균 회귀, LightGBM과 XGBoost의 중심은 중앙값 회귀입니다. 잔차 보정 이후 중앙값의 오차도 별도 저장했습니다.

종목 급락은 실제 해당 종목의 5거래일 수익률이 -5% 이하였던 389개 종목/날짜 표본입니다. 하방 이탈은 실제 수익률이 계산 구간의 하한보다 더 낮았다는 뜻입니다. 급락 조건을 사후에 골라 계산했으므로 명목 80% 구간의 일반적인 하방 이탈 목표 10%와 단순 비교하면 안 됩니다. 같은 급락 표본에서 방법끼리 비교해야 합니다. 같은 날 종목들이 함께 하락하므로 389개의 독립 사건이라는 뜻도 아닙니다.

LightGBM과 5년 정규화 잔차 기준 예시입니다. 낮은 성능의 종목을 제외하지 않았습니다.

전체 20종목 각각의 중심 오차, 포함률, 폭, 고변동성, 시장 급락, 종목 급락 결과는 per_asset.csv에 있습니다. 종목마다 같은 비중으로 평균한 결과는 equal_asset_average.csv입니다. 전체 평가 행 평균과 종목별 동일 비중 평균을 구분했습니다.

현재 비교한 방법 중 어느 종목도 평가 기간 평균 폭 5%p 이하와 포함률 80% 이상을 동시에 충족하지 못했습니다. 그러므로 아직 승인 후보가 없습니다. 가장 좁은 직접 분위수 모델은 손실 포착이 더 나빠졌고, 시장 검색 연결도 종목별 개선을 입증하지 못했습니다. 다른 방법의 가능성을 부정하는 결과는 아니지만 현재 모델을 완성됐다고 할 수는 없습니다.

## 포트폴리오 계산은 별도 ML 없이 처리합니다

종목별 가상 손익 = 보유 평가금액 × 종목별 계산 수익률 / 100

예를 들어 삼성전자 계산 수익률이 -10%이고 보유금액이 100만원이면 가상 손익은 -10만원입니다. 현대차가 +5%이고 200만원이면 +10만원입니다. 합산 가상 손익은 0원입니다. 이는 산식 확인용 예시이며 실제 모델 출력이 아닙니다.

apply_asset_returns 함수는 같은 시장 상태, 충격 조건, 분석 기간의 종목별 결과만 합산합니다. 누락 종목이나 서로 다른 시나리오가 섞이면 오류로 처리합니다. 개별 종목의 구간 하한이나 상한을 합산해 포트폴리오 80% 구간으로 표시하지 않습니다. 종목별 중앙값을 합산한 가상 손익도 포트폴리오 분포의 중앙값이라고 표시하지 않습니다.

holdings_example.json에는 저장된 실제 종목별 모델 출력에 삼성전자와 현대차 각 5,000만원을 적용한 역사적 평가 예시가 있습니다. 별도 포트폴리오 모델의 예측은 사용하지 않았습니다. 각 종목의 80% 구간은 그대로 별도로 보관합니다. 채택 모델이라는 의미는 아닙니다.

이 코드는 로컬 계산 및 검증용입니다. 기존 Azure 리소스나 공개 웹앱 경로를 변경한 것은 아닙니다. 포트폴리오 전체 확률 구간, VaR, ES와 공동 손실 모델은 확장 기능으로 분리합니다.

## 검증 한계와 재실행

실제 과거 거시 충격을 사후 조건으로 넣은 5거래일 반응 재구성 평가입니다. 충격 발생 여부나 인과효과를 입증한 것은 아닙니다. 기존 연구에 사용한 기간으로 독립 블라인드 테스트가 아니며, Gold의 과거 공표 시각과 데이터 수정 이력이 부족해 완전한 시점 일치 데이터도 아닙니다. 현재 선정 종목에 따른 생존 편향이 남습니다.

STRESSLAB_AUDIT_ROOT를 로컬 프로젝트 경로로 설정하고 asset_first_audit.py를 실행합니다. 기존 adaptive_residual_20261103 및 search_linked_20261103의 predictions.parquet와 Gold v1.1 파일이 필요합니다. 원본 데이터와 예측 파일은 저장소에 다시 올리지 않았습니다.

평가 기준은 종목별 중심 오차, 포함률, 폭, 급락 하방 이탈입니다. 포트폴리오 성적을 종목 모델 채택 기준으로 다시 사용하지 않습니다. 기존 연구 결과는 보존하지만 직접 포트폴리오 모델은 우선 개발 경로에서 제외합니다.
