# 종목별 피처 확장 및 조건부 분포 재학습

20종목을 실제로 재학습했습니다. 확장 LightGBM은 기존 Ridge보다 중심 오차가 2.8% 작았지만 기존 LightGBM보다 좋아지지 않았습니다. 평균 폭 5%p와 포함률 80%를 함께 통과한 종목별 후보는 없습니다. 급락 손실 포착까지 고려하면 이번 확장 모델을 정식 모델로 채택할 근거는 부족합니다.

## 학습 표와 비교 조건

Gold v1.1에서 시장 상태, 종목별 5·20·60일 추세와 변동성, 같은 기간 시장 대비 상대수익률을 생성했습니다. 예를 들어 상대수익률은 종목 20일 수익률에서 KOSPI 20일 수익률을 뺀 값입니다. 충격 조건은 같은 시작일 이후 5거래일의 실제 환율, 미국 10년 금리, 유가, VIX 변화이고, 정답은 같은 기간 종목 가격 수익률입니다. 금리 변화 단위는 bp입니다. 배당 재투자를 포함한 총수익률이 아닙니다.

연구 학습 표는 100,871행입니다. Gold 계약을 바꾸지 않고 로컬 연구 표에만 파생 피처를 추가했습니다. 원본 Gold는 수정하지 않았습니다.

업종 상대수익률은 생성할 수 없었습니다. Gold의 sector_id가 전부 NULL이고, 확인한 별도 업종 자료는 현재 시점의 분류입니다. 이를 오래된 과거에 소급하면 당시 업종 정보라는 근거가 없으므로 사용하지 않았습니다. 연구 표의 relative_sector5/20/60은 NULL로 보존하고 학습에서 제외했습니다. 이 부분까지 구현됐다고 보고하지 않습니다.

모든 모델은 동일한 2,872개 종목/날짜 표본을 평가했습니다. 20종목, 시작일 2023-01-02~2026-10-19, 종목별 72~152개 표본입니다. 최근 상장 종목은 학습 자료 부족으로 평가 기간이 더 짧습니다. 비교 모델 사이에서는 같은 종목의 같은 날짜를 사용했습니다.

연도별 학습, 보정, 평가를 분리하고 정답 종료일에 20일 여유를 두었습니다. 보정과 평가의 5거래일 정답 기간은 겹치지 않습니다. 5년 보정 자료는 과거 각 연도의 학습 경계를 지킨 모델의 외표본 잔차입니다. 현재 모델이 학습한 자료를 다시 예측해 만든 잔차가 아닙니다. 학습 표 자체는 일별 중첩 행을 포함합니다.

이는 연도별 모델의 외표본 오차를 축적하는 방식입니다. 5년 잔차 전체가 현재 모델의 학습 구간과 완전히 분리된 단일 보정 구간이라는 뜻은 아닙니다. 오래된 잔차는 이전 모델에서 생성됐으며 현재 모델은 그 이후의 자료도 학습합니다. 이 모델 간 잔차 이동 가능성은 보정 방법의 한계로 남습니다.

기존 Ridge 기준선이 동일한 표본에서 수치상 재현되는 것을 확인했습니다. Ridge alpha=30, LightGBM 250개 트리, 깊이 4, 학습률 0.04를 고정했습니다. 평가 결과에 맞춰 설정을 반복 조정하지 않았습니다. 다만 이 평가 기간은 이전 연구에서 사용됐으므로 독립 블라인드 테스트가 아닙니다.

## 종목별 전체 결과

MAE는 잔차 보정 전 모델 중심값의 평균 절대 오차입니다. Ridge는 조건부 평균 회귀, LightGBM은 중앙값 회귀입니다. 구간은 명목 80%이며 폭은 상한에서 하한을 뺀 전체 폭입니다. 잔차 방식은 현재 전체 가격 변동성에 정규분포 계수를 그대로 붙인 방식이 아니라 과거 외표본 오차를 정규화해 사용했습니다.

| 방식 | 중심 MAE | 포함률 | 평균 폭 | 구간 점수 | 종목 급락 시 하방 이탈 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 Ridge + 전체 변동성 | 4.77%p | 81.9% | 15.62%p | 23.16 | 40.6% |
| 기존 Ridge + 5년 잔차 | 4.77%p | 78.8% | 14.48%p | 23.13 | 54.2% |
| Ridge + 확장·상호작용 + 잔차 | 5.13%p | 77.2% | 14.78%p | 25.64 | 60.2% |
| 확장 LightGBM 중심값 + 잔차 | 4.64%p | 79.1% | 14.53%p | 23.05 | 48.3% |
| 확장 LightGBM 직접 분위수 | 4.64%p | 69.9% | 11.20%p | 23.29 | 71.2% |
| 확장 LightGBM + 시장 검색 잔차 | 4.64%p | 79.3% | 14.58%p | 22.86 | 48.6% |
| 최근 8년 LightGBM + 잔차 | 4.80%p | 78.9% | 15.01%p | 23.57 | 43.7% |

구간 점수는 폭과 실제값 이탈을 함께 평가하며 낮을수록 좋습니다. 종목 급락은 실제 해당 종목의 5거래일 수익률이 -5% 이하였던 389개 표본입니다. 표본들은 같은 날 서로 연관될 수 있어 389개의 독립 위기는 아닙니다. 급락 표본을 사후 선택했으므로 이 구간의 하방 이탈률을 명목 하방 확률 10%와 단순 대조하지 않습니다. 같은 급락 표본에서 모델끼리 비교했습니다.

## 중심값 오차 원인 확인

| 입력 또는 학습 범위 | 중심 MAE |
| --- | ---: |
| 기존 피처 LightGBM | 4.60%p |
| 확장 피처 LightGBM | 4.64%p |
| 확장 피처에서 충격 제외 | 4.87%p |
| 충격 피처만 사용 | 4.50%p |
| 확장 피처, 최근 8년 학습 | 4.80%p |
| Ridge 확장 피처, 상호작용 없음 | 5.00%p |
| Ridge 확장 피처와 상호작용 | 5.13%p |

충격을 제외하면 중심값 오차가 커졌습니다. 따라서 충격이 모델에 반영되지 않는 문제는 아닙니다. 반면 현재 시장 상태와 추세 피처를 추가하는 것이 이 표본에서 중심값 개선으로 이어지지는 않았습니다. 충격 피처만 사용한 비교에도 공통 변동성 정규화와 원래 단위 환산은 유지했으므로 완전히 시장 상태와 무관한 모델이라고 부르지는 않습니다.

확장 LightGBM과 Ridge의 MAE 차이는 -0.135%p였고 날짜 블록 재표본추출 95% 구간은 -0.353~+0.028%p였습니다. 뚜렷한 개선이 입증됐다고 단정할 수 없습니다. 상호작용 추가와 최근 기간만 학습하는 방법도 개선을 보장하지 않았습니다.

모든 종목의 중심값을 0%로 놓는 단순 진단의 MAE는 4.61%p였습니다. 확장 LightGBM이 이를 넘어서지 못했습니다. 이는 현재 피처와 모델의 조건부 중심값 설명력이 약하다는 신호이지, 금융 위험 분석 자체가 불가능하다는 증거는 아닙니다. 폭을 5%p로 강제로 고정하면 확장 LightGBM 포함률은 40.0%였습니다. 이 구간은 원인 확인용이며 채택 모델이 아닙니다.

Gold 가격에서 일별 절대수익률 35% 초과 행은 없었습니다. 분할 미반영 같은 극단적 가격 단절이 이번 오차를 전부 설명한다고 볼 근거는 확인하지 못했습니다. 이 검사 하나로 수정주가나 공표 시각 품질 전체가 검증되는 것은 아닙니다.

## A 검색을 B에 연결한 효과

A는 확정 일별 시장 상태만으로 거리와 가중치를 계산합니다. 사용자 충격은 제외합니다. B의 LightGBM 중심값은 시장 상태, 종목 상태, 사용자 충격을 함께 사용합니다. A에서 정한 시장 유사도는 B의 과거 외표본 잔차 가중치에 반영해 최종 구간을 바꿉니다. 같은 중심값으로 연결 전후를 비교해 검색 효과를 분리했습니다.

검색 연결 전후 포함률은 79.1% → 79.3%, 폭은 14.53 → 14.58%p, 구간 점수는 23.05 → 22.86입니다. 구간 점수 차이의 블록 재표본추출 95% 구간은 -0.35~-0.06으로 이번 표본에서는 개선 신호가 있었습니다. 그러나 전체 하방 이탈은 7.9% → 8.1%, 급락 시 하방 이탈은 48.3% → 48.6%로 줄지 않았습니다. 따라서 구간 점수 하나만 보고 채택하지 않습니다.

충격만 바꾸면 A의 검색 가중치가 정확히 유지되는 것을 확인했습니다. 시장 피처를 바꾸면 가중치가 달라집니다. 단일 피처 민감도 실험은 계산 연결 확인이며, 모든 가격·추세 지표가 함께 움직이는 실제 시장 경로를 재현한 실험은 아닙니다.

## 실패 구간과 종목별 차이

확장 LightGBM 잔차 방식은 고변동성 1,368개 표본에서 중심 MAE 5.42%p, 포함률 80.7%, 폭 17.83%p였습니다. 변동성이 높아지면 좁은 구간을 유지하지 못했습니다.

환율 변화 절대값 3% 초과 또는 금리 변화 절대값 75bp 초과로 구분한 강한 충격 표본은 38개, 평가 날짜는 2개뿐이었습니다. 포함률 63.2%, 하방 이탈 26.3%로 부족했습니다. 이 표본만으로 사용자가 임의 입력한 환율 +5%, 금리 +100bp를 승인할 수 없습니다. 기준은 protocol 및 코드에 고정했으며 표본을 유리하게 재선택하지 않았습니다.

| 종목 | 확장 LightGBM 중심 MAE | 포함률 | 폭 |
| --- | ---: | ---: | ---: |
| 삼성전자 | 4.17%p | 75.7% | 13.25%p |
| 현대차 | 4.35%p | 79.6% | 13.04%p |

2026-10-08 시작 삼성전자 평가의 실제 수익률은 -17.75%였습니다. 확장 LightGBM 중심값은 -3.16%, 잔차 구간은 -15.69~+8.40%였습니다. 검색 연결 후에도 -15.99~+7.96%로 실제 손실을 놓쳤습니다. 직접 분위수 구간은 -10.02~+4.23%로 더 좁았지만 손실 과소평가가 더 컸습니다. 해당 시점의 실제 충격 조건과 종목 상태는 evaluation_inputs.parquet에서 확인할 수 있습니다.

## 포트폴리오 보조 평가

별도 포트폴리오 ML을 학습하지 않았습니다. 삼성전자와 현대차 각 50%로 종목별 중심 수익률을 합산했습니다. 1억원이면 각 종목 수익률에 5,000만원씩 적용합니다.

위험 구간은 같은 과거 날짜에 발생했던 두 종목의 잔차를 맞춰 공동 시나리오를 만든 다음 합산 수익률의 분위수를 계산했습니다. 종목별 하한과 상한을 단순 합산하지 않았습니다. 이는 보조 분포 방법으로, 모든 임의 포트폴리오의 공동 분포가 검증됐다는 뜻은 아닙니다.

| 방식 | 중심 MAE | 포함률 | 평균 폭 |
| --- | ---: | ---: | ---: |
| 종목별 Ridge 합산 + 공분산 반영 변동성 기준 | 3.32%p | 83.6% | 12.21%p |
| 종목별 Ridge 합산 + 공동 잔차 | 3.32%p | 80.3% | 11.02%p |
| 상호작용 Ridge 합산 + 공동 잔차 | 3.47%p | 77.6% | 10.88%p |
| 확장 LightGBM 합산 + 공동 잔차 | 3.55%p | 76.3% | 11.36%p |
| 확장 LightGBM 합산 + 검색 가중 공동 잔차 | 3.55%p | 77.0% | 11.40%p |
| 최근 8년 LightGBM 합산 + 공동 잔차 | 3.95%p | 74.3% | 11.25%p |

모두 같은 152개 포트폴리오 평가 시점입니다. 변동성 기준은 두 종목 일별 수익률의 공분산을 반영한 20/60일 추정과 5일 환산을 사용했습니다. 직접 분위수 모델의 개별 구간만으로는 공동 분포를 정할 수 없어 포트폴리오 구간을 만들지 않았습니다. 별도 독립성 가정을 추가해서 숫자를 채우지 않았습니다. 포트폴리오 폭 5%p 목표 역시 달성하지 못했습니다.

## 채택 판단과 남은 데이터

이번 확장 후보는 정식 채택하지 않습니다. 기본 Ridge보다 일부 지표가 좋아졌어도 폭, 포함률, 하방 포착을 함께 개선하지 못했습니다. 검색은 실제 계산에 연결됐지만, 그 연결이 신뢰할 만한 위험 추정치를 보장하지는 않았습니다.

정확한 과거 업종 분류와 업종 수익률 이력이 없어서 업종 피처 실험은 남았습니다. 과거 공표 시각과 수정 이력도 없어 당시 실제 이용 가능 자료만 사용했다는 완전한 검증이 불가능합니다. 20일 여유는 정답 중첩 방지 장치이지 공표 시각 증명이 아닙니다. 현재 선정 20종목의 생존 편향도 남습니다. 피처 생성 전에 미래 가격을 변경해 과거 상태 피처가 바뀌지 않는 것은 별도로 검사했습니다.

실제 발생한 충격을 사후 조건으로 넣은 재구성 평가입니다. 충격의 발생 예측이나 인과효과 검증이 아닙니다. 평가 기간을 반복 연구에 사용했으므로 새 방법의 최종 승인에는 아직 사용하지 않은 기간이 필요합니다. 현재 자료로 목표를 달성했다고 포장하거나 보정 폭을 강제로 줄이지 않았습니다.
