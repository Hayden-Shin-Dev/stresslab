# 장기 이력 기반 충격 반응 검증

206개 후보의 KRX 공식 이력을 2000년부터 2026년 10월 30일까지 조회했습니다. 상장 이전 자료와 거래정지 구간을 채워 넣지는 않았습니다. 누락 요청 1,731건을 모두 처리했습니다. 실제 확보 기간과 가격 오류는 source_quality.csv에 있습니다.

2021년까지의 정보로 101종목, 181개 종목과 충격 조합을 선정했습니다. 최소 6개 검증 연도, 충격 관측 80개, 방향 일치 60%, 시장 상태만 쓴 모델보다 3%p 개선, 연도별 개선 비율 60%, 계수 부호 일관성 80%를 요구했습니다. 평가 성적을 보고 종목을 다시 고르지 않았습니다. 예전의 101종목 탐색 목록을 그대로 사용한 것은 아닙니다.

선정 종목과 기존 비교 종목을 합친 102종목의 학습과 평가를 완료했습니다. 아래는 선정 101종목의 동일한 15,418개 관측을 비교한 결과입니다. 실제 5거래일 충격을 사후 입력한 조건부 반응 평가이며 인과효과 검증이 아닙니다.

| 방법 | 방향 일치율 | 중심 수익률 MAE |
|---|---:|---:|
| 시장 상태만, LightGBM | 52.2% | 4.76%p |
| 시장 상태와 네 충격, LightGBM | 57.7% | 4.59%p |
| 시장 상태와 네 충격, 2016년 이후만 학습 | 56.2% | 4.77%p |
| 시장 상태와 네 충격, Ridge | 56.6% | 4.90%p |

선정된 충격이 크게 관측된 구간만 중복 없이 모으면 5,700개입니다. 이 구간에서는 충격 추가 후 방향 일치율이 52.4%에서 61.3%, MAE가 4.87%p에서 4.63%p로 개선됐습니다. 큰 충격의 기준은 각 학습 기간 충격 절댓값의 상위 25%입니다.

충격 추가의 전체 방향 개선은 5.57%p이며, 3개월 블록 재표본추출의 95% 구간은 3.69~7.50%p입니다. MAE 감소는 0.17%p이고 구간은 0.08~0.27%p입니다. 모든 종목의 개선을 뜻하지 않습니다.

목표 달성은 아닙니다. LightGBM 중심값 주변에 고정 5%p 폭을 놓은 진단 포함률은 42.1%였습니다. 실제 5일 수익률이 -5% 이하인 2,246개 중 중심값도 -5% 이하인 경우는 125개였습니다. 상승 5% 이상인 2,672개 중 189개를 같은 기준으로 포착했습니다. 충격과 방향의 관계는 일부 확인됐지만 큰 움직임의 크기를 잡는 문제는 남았습니다. 구간을 넓히거나 실패 표본을 빼지 않았습니다.

## 확인할 파일

- 종목별결과.csv: 각 종목의 선정 충격, 반응 방향, 같은 표본의 개선 전후 결과입니다.
- selected_shock_counts.csv: 환율 증가에 음의 방향 62개, 금리 증가에 양의 방향 16개, WTI 증가에 양의 방향 14개, VIX 증가에 음의 방향 89개 조합입니다. 매번 같은 결과가 발생한다는 뜻은 아닙니다.
- all_candidate_pairs.csv, selection_quality.csv: 통과하지 못한 후보와 제외 이유입니다.
- cohort_comparison.csv: 전체, 충격 구간, 기존 20종목과 겹치는 13종목의 비교입니다. 서로 다른 종목 구성의 평균을 기존 20종목보다 개선됐다는 근거로 쓰지 않습니다.
- shock_sign_metrics.csv: 충격 상승과 하락을 나눈 실제 반응과 모델 결과입니다.
- paired_uncertainty.csv: 개선의 불확실성입니다.
- data_quality.csv, time_audit.csv, verification.json: 데이터 제외, 학습과 평가 시간 경계, 기존 Gold 보존 확인입니다.

2023~2026년은 이전 연구에서 사용한 평가 기간으로 독립 블라인드가 아닙니다. 현재 후보 목록의 생존 편향과 거시 데이터 공표 시각 및 수정 이력의 미확인 문제도 남습니다. 전체 코스피 성능이나 검증된 미래 확률로 해석하지 않습니다. Azure, 운영 모델, Gold 계약은 변경하지 않았습니다.

실행 순서는 collect_long_universe.py --selected, select_long_universe.py, train_long_universe.py, report_long_universe.py, summarize_long_universe.py입니다. 기존 연구 코드 asset_feature_research.py, select_exposure_universe.py, reselect_shock_direction.py와 로컬 원천 데이터가 필요합니다. 원천 데이터, 모델 파일과 인증정보는 공개 저장소에 올리지 않습니다.
