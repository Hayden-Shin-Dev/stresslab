# 종목별 조건부 스트레스 모델 재검토

종목마다 다른 충격 반응을 학습하는 것이 맞습니다. 다만 종목마다 모델 파일을 따로 만들어야만 가능한 것은 아닙니다. 기존 코드도 종목별 Ridge와 LightGBM을 각각 학습했습니다. 이번에는 종목별 독립 학습, 종목을 구분하는 공동 학습, 공통 계수와 종목별 차이를 함께 학습하는 방식을 비교했습니다.

## 1. 결론

공동 LightGBM을 다음 연구 후보로 선택할 근거는 있습니다. 기존 종목별 LightGBM보다 중심 수익률 오차가 2.47% 줄었습니다. 그러나 정식 모델 승인은 하지 않습니다. 평균 폭 5%p와 포함률 80%를 동시에 만족한 종목은 없었으며, 급락 손실을 놓치는 문제도 남았습니다.

Azure 리소스, 운영 모델, Fabric Gold 계약은 변경하지 않았습니다.

## 2. 비교 조건

- KRX, ECOS, FRED 기반 기존 Gold 102,909행, 20종목을 사용했습니다.
- 평가는 2023-01-02부터 2026-10-19까지 164개 날짜, 2,872개 종목-날짜 조합입니다. 독립 사건 2,872개라는 의미는 아닙니다.
- 학습, 보정, 평가를 시간순으로 나누고 정답 종료일에 20일 간격을 적용했습니다. 평가 시작점은 종목별 6행 간격입니다.
- 잔차는 각 과거 시점의 모델이 당시 보지 못했던 보정 자료에서 계산한 최근 5년 오류를 사용했습니다. 하나의 고정 모델에 대한 5년 보정 자료와는 다릅니다.
- 실제로 발생한 향후 5거래일 충격을 사후 입력하는 조건부 반응 재구성 평가입니다. 충격 발생 예측이나 인과효과 검증이 아닙니다.
- 이 기간은 이전 연구에서도 사용했습니다. 독립 블라인드 테스트가 아닙니다. 실제 공표 시각이 비어 있어 완전한 당시 정보 재현도 아직 인증하지 못했습니다.

## 3. 종목별 결과

아래는 종목-날짜 표본 평균입니다. 폭은 전체 80% 구간의 폭이며 단위는 %p입니다. 급락은 실제 종목 수익률이 −5% 이하인 389개 표본입니다.

| 계산 방법 | 중심값 MAE | 포함률 | 평균 폭 | 구간 점수 | 급락 시 하방 이탈률 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 종목별 Ridge + 변동성 | 4.772 | 81.9% | 15.623 | 23.156 | 40.6% |
| 종목별 LightGBM + 잔차 | 4.637 | 79.1% | 14.528 | 23.049 | 48.3% |
| 공통 계수 + 종목별 계수 차이 | 4.592 | 78.4% | 14.324 | 22.556 | 56.3% |
| 공동 LightGBM + 종목별 잔차 | 4.523 | 79.8% | 14.190 | 22.415 | 48.8% |
| 공동 LightGBM + 유사 시장 잔차 가중치 | 4.523 | 80.1% | 14.182 | 22.247 | 49.6% |
| 공동 LightGBM 직접 분위수 | 4.523 | 77.6% | 12.690 | 21.813 | 56.3% |

공동 학습의 중심 오차 개선은 −0.115%p입니다. 날짜 10개 블록 재표본추출 1,000회에서 95% 범위는 −0.195~−0.038%p였습니다. 이는 이번 평가 표본 안에서의 불확실성이며, 반복 연구의 모델 선택 편향까지 제거하지는 않습니다.

직접 분위수 모델은 폭이 좁아졌지만 포함률과 급락 포착이 나빠졌습니다. 최종 채택하지 않습니다. 종목별 상세 수치와 고변동성 결과는 per_asset.csv, 실패 사례는 failure_cases.csv에 있습니다.

## 4. 종목별 반응을 배우는 방식

독립 모델은 삼성전자 자료만으로 삼성전자 모델을 학습합니다. 공동 모델은 20종목을 함께 학습하되 종목 코드와 종목별 추세, 변동성, 시장 대비 수익률을 입력합니다. 같은 날의 거시 충격이 20개의 독립 사건처럼 과도하게 반영되지 않도록 날짜별 가중치를 적용했습니다. 잔차 구간도 종목별로 유지합니다.

공동 모델에서 종목 코드가 실제 분기에 사용됐습니다. 모든 숫자 입력을 고정하고 종목 코드만 바꾼 격리 실험에서도 출력이 달라졌습니다. 이는 종목을 구분한다는 구현 검증이지 종목별 경제적 반응이 정확하다는 증명은 아닙니다.

공통 계수와 종목별 차이를 결합한 선형 모델은 급락 포착이 악화됐습니다. 복잡한 구조라는 이유로 유지하지 않습니다.

## 5. A 검색과 B 계산 연결

A는 충격을 제외한 시장 상태로 검색합니다. B는 같은 상태와 사용자 충격을 받습니다. A의 거리 가중치를 해당 종목의 과거 외표본 잔차에 적용하는 경로를 비교했습니다. 소수 검색 사건으로 B를 즉석 재학습하지 않습니다.

- 근거만 표시하는 경로는 B의 숫자가 바뀌지 않음을 확인했습니다.
- 거리 가중치 연결은 구간 점수를 22.415에서 22.247로 개선했지만 중심값은 바뀌지 않습니다. 급락 하방 이탈률은 48.8%에서 49.6%로 악화됐습니다.
- 작은 상태 변화의 검색 집합 유사도는 평균 0.984, 큰 변화에서는 0.783이었습니다. 검색 안정성 검사이며 금융적 정답률은 아닙니다.
- 4개 군집 방식은 같은 국면 잔차가 부족해 65.5%에서 전체 잔차로 돌아갔습니다. 현재는 거리 기반 검색이 더 단순하고 설명 가능합니다.

따라서 A 연결로 구간 품질이 일부 개선됐다고 말할 수 있지만, 손실 추정 문제가 해결됐다고 말할 수는 없습니다.

## 6. 사용자 충격 실험

2026-10-30의 동일한 시장 상태에 2026년 평가용 고정 모델을 적용했습니다. 다른 충격은 0으로 고정했습니다. 아래는 공동 LightGBM의 연구용 중심 수익률이며 승인된 예상 수익률이 아닙니다.

| 가정 | 삼성전자 | 현대차 |
| --- | ---: | ---: |
| 모든 충격 0 | +3.109% | +2.281% |
| 환율 +3% | −0.188% | +0.482% |
| 환율 +5% | −0.188% | +0.482% |
| 금리 +50bp | +4.293% | +3.054% |
| 금리 +100bp | +4.293% | +3.054% |
| VIX +5포인트 | −3.748% | −2.814% |
| 환율 +5%, 금리 +100bp | +0.762% | +1.088% |

환율 3%와 5%, 금리 50bp와 100bp에서 같은 결과가 나왔습니다. 트리 모델의 구간별 동일 출력과 관측 범위 밖 반응 한계가 드러납니다. 큰 충격의 크기를 충분히 구분하는 엔진으로 승인할 수 없습니다.

복합 충격에서 삼성전자 중심값은 무충격보다 2.347%p 낮아졌지만 여전히 양수입니다. 이를 억지로 음수로 바꾸지 않았습니다. 금리 +100bp는 학습 범위를 벗어났습니다. 전체 이력과 최근 8년 학습을 비교하면 복합 충격 반응의 종목 순위 상관은 0.368로 낮았습니다. 순위가 안정적이라고 할 수 없습니다.

각각 100만원 보유했다면 연구용 중심값을 단순 적용한 금액은 삼성전자 약 +7,616원, 현대차 약 +10,885원입니다. 이 금액은 계산 예시이며 검증된 수익 전망이 아닙니다. 포트폴리오 ML은 만들지 않았고 종목 구간을 더해 포트폴리오 확률 구간으로 표시하지도 않았습니다.

13개 시나리오, 20종목, 모델별 결과는 asset_shock_sensitivity.csv에 있습니다. 최근 8년 민감도 모델의 구간은 별도로 보정하지 않아 비워뒀습니다.

## 7. Gold와 추가 자료

기존 Gold 컬럼 계약은 맞지만 내용이 완전하지 않습니다. sector_id와 가격 및 거시 데이터 available_at이 전부 비어 있습니다. 따라서 업종별 특성을 학습했다거나 실제 공표 시각까지 완벽히 통제했다고 주장할 수 없습니다.

5일, 20일, 60일 추세와 변동성, 시장 대비 상대수익률은 기존 Gold에서 ML 단계가 생성할 수 있습니다. 이를 Gold에 중복 추가할 필요는 없습니다. 업종 대비 상대수익률은 당시 유효한 업종 분류가 있어야 하므로 이번 학습에서 제외했습니다.

현재 DART 업종 정보는 결과 설명에만 사용했습니다. 이를 2000년까지 소급해 학습에 넣지 않았습니다. 기존 연간 재무 실험은 종목별 독립 공시가 1~4개뿐이고 성능도 악화돼 반복하지 않았습니다. 추가하려면 당시 공개된 분기별 재무 및 실제 외화 매출, 금리 노출 등 근거 자료가 필요합니다.

현재 20종목은 과거 상장폐지 종목을 포함한 전체 시장이 아닙니다. 보통주와 우선주가 같은 기업인 경우도 있습니다. 항공사 같은 업종은 없어 유가 충격의 업종 차이를 전체 시장에 일반화할 수 없습니다.

수정주가 연결의 기존 200행 검증은 재사용했습니다. 이것만으로 2000년 이후 모든 권리 변동이 검증됐다는 뜻은 아닙니다.

## 8. 유지할 부분과 보류할 부분

유지: 공식 출처 수집, 확정 일별 Gold, 시간 경계 검사, 종목별 비교 기준, 충격 없는 A 검색, 같은 상태를 쓰는 B, 종목별 손익 금액 계산.

연구 후보: 종목을 구분하는 공동 LightGBM. 독립 LightGBM보다 개선은 있었으므로 후속 비교의 기준으로 사용할 수 있습니다.

보류: 폭 5%p 위험 구간, 극단 충격의 승인 수치, 업종별 학습 완료 주장, 실시간 분봉을 일별 모델에 직접 삽입, A 연결의 정식 승격.

## 9. 다음 구현 순서

1. 계약 변경 없이 기존 공표 시각과 업종 컬럼을 실제 자료로 채울 수 있는지 확인합니다. 확인 불가능한 시각은 임의로 만들지 않습니다.
2. 이번 고정 모델과 비교 코드를 보존하고, 새로 확보되는 기간을 별도 최종 평가로 남깁니다.
3. 종목별 오차, 구간, 급락 누락을 함께 확인합니다. 평균 점수만으로 승인하지 않습니다.
4. 승인 모델이 생기면 상태 식별자, 모델 버전, 충격 단위, 지원 범위와 함께 Stress Engine으로 연결합니다. 과거 관측과 모델 추정은 응답에서도 분리합니다.
5. 포트폴리오 금액은 종목별 결과에 보유 평가금액을 곱해 합산합니다. 공동 확률 구간은 별도 검증 후 확장합니다.

이번 결론은 구조가 구현 가능하다는 것과 현재 숫자를 신뢰 가능한 서비스 결과로 승인하는 것은 다르다는 것입니다. 종목별 차이를 반영하는 구현과 비교 실험은 끝났지만, 요청한 정밀도와 극단 충격 신뢰성은 달성하지 못했습니다.

## 10. 재현 자료

model_redesign_research.py가 학습과 A/B 비교를 실행합니다. complete_redesign_sensitivity.py가 종목별 구간과 격리 실험을 보완하고 summarize_model_redesign.py가 평가표를 생성합니다. protocol.json에 데이터 해시와 시간 경계를 기록했습니다. 원본 Gold와 평가 입력은 로컬에 보관하며 공개 저장소에 가격 원본을 올리지 않습니다.
