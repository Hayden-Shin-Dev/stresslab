## 복원 검증

- 원본 학습 후보 191,501행과 동일. 과거 모델 2,189개의 학습 날짜 해시 및 표본 수 모두 일치.
- 2,189개 모델을 재학습. 원본 계수와 최대 차이 1.67e-16.
- 기존 과거 예측 132,394건 모두 재현. 최대 수익률 차이 8.89e-15%p.
- 최종 실행 파이프라인에서도 같은 과거 예측 재현. 원본 가중치를 단순 복사해서 맞춘 검사가 아님.
- 원 관측자료는 Fabric 보관 경로에서 직접 읽었고 기존 파일 해시와 동일. 기존 데이터는 수정하지 않음.
- 원 자료가 끝난 뒤 확인할 수 없는 충격은 결측으로 남김. 0 충격으로 연장하지 않음.
- 240개 종목 시나리오 출력은 실제 AI 근거 조립 코드에서 읽힘. LLM 호출과 배포는 하지 않음.

원본의 `policy_available_at`는 연구용 발표 시각 가정이며 실제 과거 입수 시각으로 인증된 값이 아닙니다. 원 관측 충격은 사용자 가정 또는 사후 관측 입력입니다. 미래 충격 자체의 예측이나 당시 입수 가능성의 입증으로 해석하지 않습니다.

## 동일 조건 비교

세 버전의 공통 평가 행 120,332건에서 같은 날짜와 종목으로 비교했습니다. 아래 결과는 종목별 지표를 계산한 뒤 20종목을 동일 가중 평균한 값입니다. 원래 Huber 서비스에는 구간 출력이 없었으므로 세 버전 모두 같은 과거 잔차 보정 규칙으로 구간을 새로 계산했습니다.

보정 규칙: 분기 시작일 08:30 이전에 정답과 두 충격 자료의 정책 시점이 충족된 공통 과거 잔차, 최대 756개, 최소 100개, q05~q95. 따라서 아래 구간은 원래 서비스의 구간을 복원한 결과가 아닙니다. 원본과 복원본의 중심값 및 같은 규칙의 구간은 동일합니다.
