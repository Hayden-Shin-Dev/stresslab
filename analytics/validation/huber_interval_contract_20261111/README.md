# 원본 구간과 평가 조건 고정 검증

2026-11-11. 현재 Fabric Gold를 로컬에서 읽어 20종목 전체 학습과 시나리오 출력을 다시 실행했습니다. 성진 담당 파이프라인, Fabric 노트북, Azure 배포는 수정하지 않았습니다.

## 고정한 기준

기존 B152 중심값과 v173/v174 비교 실험의 90% 구간 계산을 한 계약으로 고정했습니다. 이전 PR14에서 추가한 756개 로그오차 방식은 현재 실행 경로에서 제거했습니다. 원본 132,394개 평가 키, 학습일, 충격 분류와 종목별 집계 규칙도 고정했습니다.

- 종목/기간별 과거 실제 예측오차의 최근 252개. 정답과 충격 정책 시점 모두 학습일 08:30 이전.
- 최소 60개에서 단순수익률 절대오차/scale의 ceil((n+1)*0.9) 순위값을 사용.
- 중심값 양쪽에 순위값*현재 scale을 더하고 빼서 구간 생성.
- 원본 초기 4,608건은 당시 사용한 B147 반폭으로 동일하게 처리. 새 추정치로 대체하지 않음.
- 현재 40개 종목/기간 패키지는 모두 과거 오차 252개를 사용. 초기 대체 구간을 사용하지 않음.

## AI 출력 변환 검사

12개 시나리오와 240개 종목 출력에서 중심값, 90% 구간, 보수적 하단을 계산 후 그대로 전달하는지 확인했습니다. 모델 계산과 응답 형식 사이 수치 차이는 0입니다. 실제 근거 조립기가 읽는 q10/q90과 보수적 하단도 입력과 같습니다. q95는 현재 근거 조립기가 소비하지 않으므로 AI가 90% 상단까지 활용한다고 보고하지 않습니다. LLM 호출과 운영 배포는 하지 않았습니다.

q10/q90은 같은 과거 오차에 80% 순위식을 적용한 추가 출력이며 원본 90% 성능을 바꾸지 않습니다. 필드명은 기존 AI 계약을 따릅니다. 80% 구간의 별도 승인이나 비대칭 조건부 분위수 학습을 의미하지 않습니다.

## 실행과 재현

`analytics/src/huber_pipeline/README.md`의 실행 명령을 사용합니다. `verification.json`은 원본 구간 대조, `full_run_receipt.json`은 Gold부터 새로 실행한 산출물 해시, `output_verification.json`은 AI 형식 변환 검사입니다. `contract.json`에 고정 규칙을 기록했습니다. 테스트 14개 통과. 추가 80% 구간의 테스트에서 십진 소수의 8.88e-16 차이를 발견하여 해당 기대값 비교만 1e-14 허용오차로 수정했습니다. 원본 복원 검사의 허용오차는 1e-10입니다.

원본 발표 시각은 연구용 가정이며 실제 과거 입수 시각 인증이 아닙니다. 원본과 동일하게 복원했다는 검증과 새로운 환경의 예측 성능 승인은 별개입니다.
