# 코스피 요인 분해 CatBoost

## 로컬 실행

```powershell
.\.venv\Scripts\python.exe analytics/model_market_factor_catboost/train_market_factor.py --out analytics/outputs/model_market_factor_catboost_rerun
```

기본 출력은 `analytics/outputs/model_market_factor_catboost`입니다. `metrics.csv`에는 전체 및 시장충격 그룹별 지표, `paired_differences.csv`에는 동일 날짜·종목·정답·충격을 대조한 뒤 계산한 차이와 95% 블록 부트스트랩 구간이 있습니다.

## 데이터 분할

로컬 Gold의 한국 거래일과 수정주가를 사용합니다. 1·5·20일 각각 `yᵢ = 100 ln(Pᵢ,t+h / Pᵢ,t)`를 만듭니다. 2020년 이전으로 두 모형을 적합하고 2020~2022년으로 구간의 두 꼬리를 보정합니다. 2023년 이후에는 같은 D/E 평가 행을 사용합니다. 정답 종료일이 다음 구간의 시작일에 걸친 행은 앞 구간에서 빠집니다. CatBoost 반복 수는 2017~2019년으로 선택한 뒤 학습 구간 전체에서 재적합합니다.

## 입력

- 시장 회귀에는 시장충격 4개, 시장 상태 13개, 충격×상태 상호작용 52개를 사용합니다. 상태는 코스피 추세·낙폭·변동성, 환율 추세, 미국 금리·VIX·WTI의 수준 및 변화, 국고채 3년물 수준과 변화입니다. 결측 대체값과 표준화는 학습 구간에서만 적합합니다.
- 잔차 회귀는 종목 상태 CatBoost와 동일한 수치 30개와 범주 2개를 사용합니다. 시장 17개, 종목 13개와 종목·업종 코드입니다. 종목 피처는 수익률, 변동성, 낙폭, 시장 대비 강약·순위, 코스피와 거시 요인에 대한 60거래일 베타입니다.

## 계산

1. 날짜당 하나의 행에서 `m = 100 ln(KOSPI[t+h] / KOSPI[t])`을 시장의 실제 구간 수익률로 계산합니다. 이를 코스피 변동성 척도로 나눈 값을 Huber 회귀로 학습합니다.
2. 기준일의 코스피 베타에 `b = 0.25 + 0.75 × clip(beta60, −0.5, 2.5)`를 적용합니다. 학습 정답의 종목 잔차를 `r = yᵢ − b × m`으로 정의하고, 종목 변동성 척도 `sᵢ`로 나눕니다. CatBoost는 이 값의 2.5·5·10·50·90·95·97.5% 조건부 분위수를 pinball loss로 학습합니다.
3. 추론에서 분위수는 `b × m_hat + sᵢ × Qτ(r / sᵢ)`입니다. `m_hat`은 Huber가 같은 시장 상태와 충격으로 추정한 코스피 수익률입니다. 실현된 미래 코스피 수익률은 학습 정답 구성에 쓰입니다.
4. 최종 종목 수익률과 원구간의 차이로 보정기의 하단·상단을 적합합니다. 보정한 80·90·95% 구간이 중첩되도록 정리합니다.

평가에서 시장충격은 과거에 실현된 값을 넣었습니다. 실제 시나리오에서는 환율·미국 10년 금리·WTI·VIX의 가정 변화가 필요합니다. 평가 기간은 기존에 사용한 개발 평가 구간입니다.
