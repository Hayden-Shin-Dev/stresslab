# 공통 API 통합

2026-11-12 민철 수정입니다. 공통 API 코드와 이미지만 변경했습니다. Fabric, ML 모델, AI 실행기, 실시간 담당자 코드와 웹 화면은 변경하지 않았습니다.

## 프론트에서 사용할 응답

로그인한 웹에서 기존 `POST /api/stress/analyze`를 호출합니다. 기존 입력과 결과 필드는 유지합니다.

| 필드 | 의미 |
| --- | --- |
| `assets`, `portfolio_hypothetical_pnl_krw` | 종목별 계산값과 전체 가상 손익입니다. |
| `model_context` | ML 입력 기준일, 데이터 버전, 입력 해시와 검증 상태입니다. |
| `market_context` | 현재 장중 스냅샷과 관측 시각입니다. 일별 ML 계산에는 넣지 않습니다. |
| `ai_context` | 같은 계산값을 AI 담당자의 기존 근거 형식으로 옮긴 자료입니다. |
| `analysis_id` | 이번 응답 식별자입니다. 저장된 결과를 조회하는 ID는 아닙니다. |
| `ai_handoff` | AI 전달 준비 상태입니다. 현재는 자료만 준비됐고 자동 전달은 연결되지 않았습니다. |

`market_context.freshness`는 관측 후 120초를 기준으로 한 경과 시간 표시입니다. `recent`라도 원본 `quality_status`가 검증됐다는 뜻은 아닙니다. 시장 API가 실패하면 ML 계산값은 반환하되 장중 자료는 없다고 표시합니다.

계산 전후 ML 입력 해시와 종목별 데이터 버전·기준일을 검사합니다. 변경이 감지되면 409로 재요청을 안내합니다. 현재 ML이 예측마다 입력 해시를 반환하지 않으므로 이 검사를 원자적 스냅샷 고정과 동일하다고 보지는 않습니다.

## 실제로 막힌 부분

1. 토론 실행기는 `STRESS_ENGINE_URL`이 없어 `/app/runs`의 개발용 파일을 읽습니다. 웹의 새 분석 ID를 전달하면 파일 없음으로 실패합니다. 기본 토론의 `stress_run` 파일 안에는 `run-test-001`, 기준일 2026-10-30이 들어 있습니다. 오늘 ML 결과를 설명하는 토론이 아닙니다.
2. 공통 API 결과를 영구 저장하는 테이블과 조회 경로가 없습니다. 현재 공통 관리 ID에도 테이블 생성 권한이 없습니다. 기존 테이블이나 권한은 변경하지 않았습니다.
3. 현재 배포 ML은 18종목을 지원하며 입력 스냅샷은 2026-11-09입니다. 최신 Gold가 만들어졌다는 사실만으로 이 ML 입력이 자동 갱신됐다고 판단하면 안 됩니다.
4. 충격별 기여도와 과거 유사 시장 사례는 현재 ML API에 없습니다. 공통 API에서 임의로 생성하지 않습니다.

## 다음 연결 순서

1. 공통 API에서 사용자 ID, 분석 ID, 요청, 모델 결과, 장중 스냅샷을 하나의 변경 불가 결과로 저장하고 본인 결과만 조회하도록 구현합니다. 전용 테이블에는 필요한 읽기·쓰기 권한만 부여합니다.
2. AI 담당자는 `sources.py`의 결과 조회를 파일에서 인증된 결과 조회로 연결합니다. 요청 ID와 반환 결과 ID가 같은지 검사하고, 분석 시 고정한 장중 스냅샷을 사용합니다. 인증 없이 공개 조회하도록 연결하면 안 됩니다.
3. 그 뒤 프론트가 저장된 결과 ID로 토론을 요청합니다. 현재 `a-` 분석 ID로 토론을 요청하면 공통 API가 409로 막습니다. 기본 개발용 토론은 기존 동작을 유지하므로 실제 분석 설명 버튼에 연결하지 마세요.

`ai_context.stress_run`과 `ai_context.market_snapshot`은 기존 `services/debate/src/evidence.py`의 `build_bundle`에 넣어 검사했습니다. 충격 단위, 기준·충격 후 수익률, 종목 손익과 합계가 일치합니다. ML의 90% 구간을 AI의 80% 구간 필드에 옮기지 않습니다. 없는 기여도와 과거 사례는 그대로 비워 둡니다.

## 검증 실행

로컬 검사는 기존 README 명령으로 실행합니다. Azure APIM·ML·보유종목 분리·새 PubSub 수신 검사는 다음 명령입니다. 기존 서버용 구독키를 메모리에서만 사용하며 저장하거나 출력하지 않습니다. 일반 브라우저 로그인 검증과는 구분합니다.

```powershell
python infra/gateway/verify_integration.py --output integration-result.json
```

이 검사는 전용 테스트 사용자의 보유종목을 잠시 저장한 뒤 원래 값으로 복구합니다. 다른 사용자 보유종목은 변경하지 않습니다. AI 실행 검증은 개발용 자료라는 점을 구분해서 별도로 수행했습니다.
