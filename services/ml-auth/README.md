# ML 서버 인증

기존 모델 이미지와 계산 함수는 그대로 두고 서버 호출 인증만 추가합니다. 원래 `/predict`, `/metadata` 경로의 Entra 인증은 유지합니다.

공통 API가 관리 ID로 Key Vault에서 요청에 서명하면 `service_auth.py`가 공개키로 검증합니다. 서명의 유효시간은 30초이며 호출 주체, 서비스, 메서드, 경로, 본문 해시가 일치해야 합니다. 이 경로는 조회와 계산만 허용합니다.

인증을 통과한 `/service/metadata`, `/service/snapshot/metadata`, `/service/predict/auto`만 기존 함수에 전달합니다. 기존 모델의 지원 종목, 수익률 단위, 연구용 표시는 바꾸지 않습니다.

모델 담당자가 새 이미지를 배포할 때 인증 래퍼 없이 기존 이미지를 덮어쓰면 서버 연결이 끊깁니다. 새 모델 이미지 digest로 Dockerfile의 기반 이미지를 갱신한 뒤 래퍼와 함께 배포해야 합니다. 모델만 교체한 뒤 연결 검사를 반드시 실행하세요.

배포, 키 교체, 복구 방법은 [배포 안내](../../infra/gateway/README.md)에 있습니다.
