# AI 토론 실행기

Service Bus의 토론 요청을 받아 스트레스 결과와 시장 상태 스냅샷을 조회합니다. 서로 다른 관점의 페르소나가 주장, 근거 확인, 반론, 수정 단계를 거쳐 결론을 작성합니다. Azure OpenAI를 사용하며 도구 API로 계산 근거를 확인합니다. 토론 진행과 결과는 Web PubSub으로 전달합니다. 합의되지 않은 쟁점도 결과에 남깁니다.

| 폴더 | 내용 |
| --- | --- |
| [src](src/) | 토론 순서, 상태 저장, 모델 호출 |
| [prompts](prompts/) | 페르소나와 주장 및 반론 지침 |
| [tests](tests/) | 근거 인용, 수치 일치, 종료 조건 검증 |
