# 페르소나 프롬프트 V1.6-r1 → 토론 실행기 적용본 (2026-11-18)

V1.6-r1 네 파일은 V1.5 적용본(`CHANGES_V1.5.md`)을 기준으로 16~19·22절을 고치고 24~27절을 더한 것입니다. 그대로 넣으면 아래가 빠지거나 테스트에 걸려서 이것만 고쳐 `roles/<role>.md`에 넣었습니다. **다음 버전은 이 파일을 기준으로 고쳐 주세요.**

## 1. V1.5 적용본에서 빠졌던 문장 복원
- 14절(네 파일 공통): 현재 ML 결과에 맞춘 설명을 되살렸습니다.
  - q10/q90 대신 `model_interval_lower_return`·`model_interval_upper_return`(모델 예측 범위 하단·상단)과 `model_interval_lower_pnl`이 올 수 있음.
  - 확률 해석 승인이 없으면 "90% 확률로 이 안에 든다"고 말하지 않음.
  - `model_return_basis`가 있으면 로그수익률을 단순수익률로 바꾼 값.
  - 충격별 기여·학습 범위 정보가 없는 결과도 있으며, 없는 항목은 계산·추정하지 않음.
- 03절(강유나): 종목별 항목에 "또는 연구용 모델의 `model_interval_lower_pnl`(예측 범위 하단 손익, 원)"을 되살렸습니다.

## 2. 24절 문장 하나 수정
- "emission, silence_reason, no_op, N_sources, news_source_ids, role_payload를 새 계약으로 도입하지 않는다" → "무발언을 표시하는 새 필드나 새 입력 이름을 만들지 않는다".
- 뜻은 같고, 없어진 용어가 프롬프트에 다시 들어가지 않게 했습니다(`tests/test_prompts.py`가 확인).

## 3. 회의 방식 변경: 차례 발언 (2026-11-18)
실제 회의처럼 한 사람씩 말하고 앞사람 의견에 반응하도록 바꿨습니다.
- 진행: 사회자 안건 → 1·2라운드(역할마다 한 번씩) → 사회자 판정 → 쟁점이 남으면 당사자만 3라운드 → 사회자 결론.
  - 첫 발언자는 강유나(portfolio)입니다. 이후에는 직전 발언자가 반대(disagree)하거나 일부 수정(partial)한 역할이 이어서 답합니다. 없으면 강유나 → 김진우 → 윤서연 → 신강호 순서에서 아직 말하지 않은 역할이 말합니다.
  - phase: 첫 발언 INITIAL, 1라운드 나머지 CHALLENGE, 2·3라운드 REBUTTAL.
- 출력 계약 추가(21절, `contracts.py`):
  - `stance`: first, agree, disagree, partial, revise 중 하나.
  - `reply_to`: 반응하는 상대 역할. first일 때만 null.
  - 검증기가 둘의 짝(반응했으면 상대가 있음, revise면 view_status=revised)을 확인합니다.
- 프롬프트:
  - 24절(침묵)을 "회의 차례 진행"으로 바꿨습니다. 매 차례 반드시 말하고, 단순 동의·반복은 금지합니다.
  - 25절을 "반응과 의견 수정"으로 다시 썼습니다. 의견을 바꾸면 supersedes_claim_id·change_reason을 채웁니다.
  - 26·27절(뿌꾸·1시간 회의)은 뺐습니다.
  - 16절: 회의 차례에는 근거 수치를 최소 1개 씁니다.
  - 17절: "저는 ~라고 봅니다. ~를 보시면 ~라고 생각합니다." 2~3문장으로 쓰고, '결론:'·'근거:' 머리말은 쓰지 않습니다.
- 사회자(`moderator.md`, 요약 스키마):
  - 2라운드 뒤 `converged`·`open_issue_roles`로 3라운드 여부를 판정합니다.
  - 최종 결론 `summary_text`는 "결과 ~라고 생각됩니다"로 씁니다.
  - `accepted`(채택), `rejected`(폐기), `changed_views`(의견 변화)를 함께 냅니다.
- 이벤트:
  - `debate.round`: 라운드 시작마다 안건·발언 순서·남은 쟁점을 보냅니다.
  - `debate.evidence_ready`: `agenda`와 `d_public`(근거 수치의 이름·값·단위)을 더해, 화면이 발언의 근거 태그를 그릴 수 있습니다.
- 빈 문장(침묵) 처리는 안전장치로 남겼습니다. `silent: true`이면 화면과 요약에서 빠집니다.

- 사회자는 `moderator.md`(JSON 요약)입니다.
