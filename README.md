# StressLab

Azure와 Microsoft Fabric을 사용하는 실시간 금융시장 위험 분석 및 포트폴리오 스트레스 시뮬레이션 프로젝트입니다.

현재 시장 상태와 과거 충격 사건을 연결해 보유 자산의 위험 노출을 살펴봅니다. 사용자는 포트폴리오와 환율, 금리 등의 충격 조건을 입력하고, 과거 종목별 반응을 현재 보유금액에 적용한 가상 손익과 위험 집중도를 확인합니다.

키움 시세는 현재 가격과 장중 시장 상태 계산에 사용합니다. KRX, ECOS, DART 자료는 과거 시장 환경과 사건 분석에 사용합니다. Fabric에서 데이터를 정제하고 시장 상태를 계산하며, 스트레스 엔진이 사건 검색과 포트폴리오 계산을 수행합니다. AI 토론은 같은 분석 결과와 출처를 바탕으로 서로 다른 관점의 주장과 반론을 정리합니다.

미래 수익률이나 충격의 인과적 효과를 확정하는 서비스는 아닙니다. 과거 사건 재현 결과와 가정을 사용한 탐색 결과를 구분합니다.
