# StressLab

Azure와 Microsoft Fabric을 사용하는 실시간 금융시장 위험 분석 및 포트폴리오 스트레스 시뮬레이션 프로젝트입니다.

사용자는 포트폴리오와 환율, 금리 등의 충격 조건을 입력하고 가상 손익과 위험 집중도를 확인합니다. 과거 사건의 실제 반응과 조건부 ML의 추정 결과를 구분해서 제공합니다.

키움 실시간 시세는 현재 위험 표시와 포트폴리오 평가금액 갱신에 사용합니다. 시장 국면 검색과 조건부 스트레스 ML은 최근 확정 일별 데이터를 사용합니다. ML 학습·검증은 Fabric Data Science, 모델 관리는 MLflow, 서비스 추론은 Container Apps의 Stress Engine에서 담당합니다.

AI 토론은 같은 분석 결과와 출처를 바탕으로 서로 다른 관점의 주장과 반론을 정리합니다. 미래 수익률이나 충격의 인과적 효과를 확정하는 서비스는 아닙니다.

## 트러블슈팅과 방향 변경

| 진행 단계 | 확인한 문제 | 정리한 방향 |
| --- | --- | --- |
| 처음 기획: 충격의 영향을 직접 예측 | 주가가 환율 때문에 움직였는지 경기·금리·뉴스 때문인지 분리하기 어려웠습니다. 확보한 데이터와 개발 기간 안에서 인과효과를 검증하기 어려웠습니다. | 충격 발생 여부나 인과효과를 단정하지 않고, 사용자가 가정한 충격 아래의 위험을 분석하는 조건부 스트레스 테스트로 변경했습니다. |
| PoC 조건부 ML | 일부 구간의 포함률은 확보했지만 단순 변동성 기준보다 일관되게 좋지는 않았습니다. | 포함률만 보지 않고 구간 폭, 손익 오차, 큰 손실을 놓치는 정도를 함께 평가합니다. |
| 장중 시장과 오래된 과거 시장 비교 | 실시간은 분봉, 장기 과거는 일봉이어서 같은 기준의 비교가 아니었습니다. 과거 분봉 기간도 제한됐습니다. | 실시간 위험·평가금액과 확정 일별 검색·ML의 역할을 분리했습니다. 이 구조를 유지합니다. |
| 과거 사건 재현과 손실 보정 | 사건 재현만으로 임의 충격의 크기를 설명할 수 없었습니다. 민감도·잔차·변동성 가정을 조합하면 결과가 크게 달라졌습니다. | 실제 과거 반응과 조건부 ML 추정을 별도로 보여줍니다. 검증되지 않은 가정의 최솟값·최댓값을 신뢰할 위험 구간으로 표시하지 않습니다. |
| 학습 데이터 점검 | 보조 ETF 결측 때문에 정상 종목의 학습 구간도 빠졌습니다. 거시 관측일과 실제 공표일도 달랐습니다. | 종목별로 표본을 만들고 관측·공개 시각을 분리했습니다. 같은 평가 표본에서 재학습했지만 개선은 제한적이므로 정식 모델 승격과 구분합니다. |

최종 구조는 키움 실시간 분석, Fabric 확정 일별 처리와 ML 학습, Container Apps 스트레스 계산, 근거 기반 AI 토론입니다. 장중에는 위험 지표와 평가금액을 갱신하고, 장 마감 후 검증한 일별 자료를 다음 분석에 반영합니다. 데이터 갱신이 모델 재학습이나 승인을 자동으로 의미하지는 않습니다.

[Fabric 전달 계약](contracts/README.md)과 [ML 구현 안내](analytics/README.md)를 기준으로 각 파트를 진행합니다. 현재 로컬 검증은 일부 종목 범위이며, Azure 전체 연결과 모델의 정식 승인은 별도 작업입니다.
