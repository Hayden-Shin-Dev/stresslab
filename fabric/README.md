# Fabric 담당 안내

외부 API 수집과 키움 연결은 수집 담당이 구현합니다. Fabric 담당은 전달받은 데이터의 적재, 분석, 검증을 맡습니다.

| 담당 | 입력 | 최종 전달 |
| --- | --- | --- |
| [batch](batch/) | 수집 담당의 과거·일별 원본, realtime의 마감 자료 | ML용 확정 일별 Gold, realtime용 종목·업종·전일 종가 |
| [realtime](realtime/) | Event Hubs 시세, batch의 종목 기준정보 | 서비스용 시장 상태 스냅샷, batch용 마감 자료 |

내부 테이블과 처리 방식은 각 담당자가 설계하면 됩니다. 입력 원본의 저장 위치와 형식은 수집 담당과 맞추고, 외부로 전달하는 결과는 [공통 계약](../contracts/README.md)을 따르세요.
