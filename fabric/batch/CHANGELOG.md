## 실제 검증 결과

- Silver → Gold와 수집 → Silver → Gold 실행 모두 성공했습니다. 전체 경로는 13:01~13:08 KST에 수동 검증했습니다. 다음 오전 8시 예약 실행은 아직 관측하지 않았습니다.
- Gold는 20종목, 103,009행, 34개 컬럼이며 최신 거래일은 2026-11-06입니다. 가격과 거래량은 수정 전과 같습니다. 중복 키는 없고 기존 격리 104행을 유지했습니다.
- 입력 조건 통과 행은 40,357개, 과거 구간 계산 후 피처는 32,547행입니다. 미확인 거시 자료 등을 포함한 62,652행은 입력 조건에서 제외됩니다. 모든 NULL을 채웠다는 뜻이 아닙니다.
- 기존 검증 날짜의 피처 32,467행과 확정 정답 32,427행은 로컬 검증값과 같습니다.
- 기존 CatBoost를 재학습 없이 연결해 20종목의 무충격 및 네 충격 동시 입력을 확인했습니다. 기여도 합계와 가상 손익 계산이 일치했습니다.
- 미래 자료, 오래된 관측, 과거 정정값 혼입, 가격 연결 단절의 실패 조건을 검사했습니다. 같은 원본을 재실행해도 Gold 값과 행 수는 같았습니다.

자세한 수치는 [검증 결과](quality/verification_20261109.json)에 있습니다. [검증 코드](quality/verify_ml_input.py)는 `--bundle 기존모델폴더 --snapshot Gold묶음폴더 --output 결과.json`으로 실행합니다. 로컬 ML 의존성을 설치한 환경에서 실행하세요.

## 그대로 둔 부분과 주의점

성진이의 ML Notebook, Gold 계약, Azure 리소스 설정과 모델 파일은 변경하지 않았습니다. 테이블은 `lh_whatif.gold_stock_market_daily_v11`을 사용합니다. ML 연결은 [README](README.md)의 Gold 묶음과 기존 `read_gold` 어댑터 기준입니다.

정확한 공표 시각은 미확인이면 계속 NULL입니다. 근거가 있는 사용 가능 시점은 별도로 읽어야 합니다. 기준일 11월 6일에도 환율 관측일은 10월 30일이며, 이를 11월 6일 환율로 표시하면 안 됩니다. 과거 자료의 근거가 추가되면 별도 검증 후 제외 구간을 복구합니다.

현재 검증 가격 자료와 Silver 관리 종목은 20종목입니다. 종목 확대, 새 기업행사 반영, 120일보다 오래된 Silver 결측 복구는 별도 확인이 필요합니다. 매번 주가를 임의 보정하거나 미래에 수집한 정정값으로 과거를 덮어쓰지 않습니다.
