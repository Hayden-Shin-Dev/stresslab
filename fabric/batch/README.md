# Batch 작업 순서

외부 데이터 수집은 수집 담당이 구현합니다. Batch는 전달받은 KRX, ECOS, DART 등 원본을 정리해 확정 일별 데이터를 만듭니다.

| 단계 | 작업 | 폴더 |
| --- | --- | --- |
| 1. 입력 확인 | 원본 위치, 기간, 종목 범위, 수집 완료 여부를 확인합니다. | pipelines |
| 2. 원본 보관 | 원본과 수집 시각, 출처, 정정 이력을 Bronze에 보관합니다. | notebooks |
| 3. 정제 | 종목 코드, 거래일, 단위, 수정주가 기준을 통일하고 Silver로 정리합니다. | notebooks |
| 4. 마감 자료 확인 | Realtime이 넘긴 분봉과 누락 내역을 받아 일별 자료와 대조합니다. 검증 전에는 확정 종가를 덮어쓰지 않습니다. | notebooks, quality |
| 5. 품질 검사 | 중복, 결측, 거래정지, 기업행사, 공표 시각을 검사합니다. 실패한 자료는 분리합니다. | quality |
| 6. 결과 전달 | 검증한 배치만 버전을 붙여 Gold로 게시합니다. 실패하면 기존 버전을 유지하고 재실행합니다. | pipelines |

## 넘겨줄 결과

ML에는 [gold_stress_daily](../../contracts/README.md) 한 테이블을 전달합니다. 한 행은 거래일 하나와 종목 하나이며 Lakehouse Delta 테이블로 제공합니다. 로컬 확인용은 Parquet입니다. 시장 피처와 향후 5거래일 충격·정답 수익률은 ML 담당이 생성합니다.

Realtime에는 기준일이 있는 종목·업종 정보, 전일 확정 종가, 거래일 정보를 전달합니다. DART 공시 원문은 출처와 공개시각을 보존해 AI 근거용으로 별도 관리합니다. 내부 테이블 구성은 담당자가 정하면 됩니다.

관측일과 실제 이용 가능 시각은 구분하고, 모르는 시각은 만들지 않습니다. 거시 시리즈를 임의로 다른 지표로 대체하지 않습니다.

완료 기준은 ML 담당이 Gold를 읽을 수 있고, 원본 추적과 품질 검사가 가능하며, 같은 배치를 다시 실행해도 중복 없이 같은 결과가 나오는 상태입니다.
