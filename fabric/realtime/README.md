# Fabric 실시간 시장 상태 분석

키움 시세를 Event Hubs에서 받아 현재 시장 흐름을 분석합니다. 급락 감지만 담당하는 것이 아닙니다.

| 폴더 | 작업 |
| --- | --- |
| eventstreams | 시세 수신, 중복 제거, 원문 보관, Eventhouse 적재 |
| kql | 누적 흐름과 최근 수익률, 변동성, 거래량, 업종 등락, 하락 확산, 동조화 계산 |
| notebooks | 장중 이력 저장, 장 마감 검증과 일별 담당 전달 |
| reference | 로컬에서 검증하는 Python 계산 기준 |

[실시간 계약](../../contracts/realtime/README.md)의 market_state_snapshot v2를 시장 상태 API에 전달하세요. UI, 경보, AI 분석 근거로 사용합니다. 일별 시장 검색과 조건부 ML은 확정 일별 데이터만 사용합니다.

업종 분류와 전일 종가는 일별 담당에게 전달받습니다. 비교 이력이 부족하면 평소 대비 지표는 NULL입니다. 당일 누적량을 과거 하루 전체 거래량과 비교하지 않습니다. 참고 코드를 KQL 등으로 구현한 뒤 같은 입력에서 결과가 일치하는지 확인하세요. Python 참조 구현을 제공한 상태이며 Fabric 실행 검증은 별도입니다.
