# Fabric 2

Event Hubs의 시세를 받아 장중 시장 상태와 이력을 관리합니다.

| 폴더 | 작업 |
| --- | --- |
| eventstreams | 수집 담당과 입력 형식을 합의하고 Eventhouse에 적재 |
| kql | 현재 위험 지표와 잠정 시장 상태 계산 |
| notebooks | 장중 관측과 상태 이력을 Lakehouse에 보관 |

공급자 시각, 수신시각, 거래소, 세션, 관측 종목 범위를 보존하세요. 확정 일별 상태와 잠정 일별 상태는 구분해야 합니다. 일부 종목 평균을 코스피 지수로 대체하지 마세요.

내부 테이블 구성은 담당자가 설계하면 됩니다. ML에 반영할 지표는 검증 후 [최종 Gold 계약](../../contracts/)에 정리합니다. 이전 이벤트 스키마와 예시는 폐기했으므로 구현 기준으로 사용하지 마세요.
