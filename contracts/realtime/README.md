# 실시간 시장 상태 계약

Fabric 실시간 담당은 장 시작부터 현재까지의 흐름과 최근 구간의 변화를 분석합니다. 위험 신호는 분석 결과의 일부입니다.

| 전달 | 형식 | 내용 |
| --- | --- | --- |
| 수집기 → Event Hubs → Fabric | quote_event v1 | 한 종목의 관측값 |
| Fabric → 시장 상태 API | market_state_snapshot v2 | 시장, 종목, 업종 분석과 위험 신호 |

[schema.json](schema.json)은 전달 규칙입니다. [mock.json](mock.json)은 합성 예시이며 첫 항목은 시세, 두 번째는 기존 v1 출력, 세 번째는 새 v2 출력입니다. 한 메시지에 한 항목을 보냅니다. 기존 v1은 호환용으로 남겼습니다. 새 구현은 v2를 사용하세요. 일별 Gold 계약은 변경하지 않았습니다.

## 계산 기준

[지표별 쉬운 설명](../../fabric/realtime/README.md#지표별-의미)과 함께 확인하세요. 아래는 같은 결과를 만들기 위한 산식입니다.

| 항목 | 계산 |
| --- | --- |
| 전일 종가·오늘 시가 대비 등락률 | 100 × (마지막 완료 분 종가 / 해당 기준 가격 - 1) |
| 최근 5분 가격 등락률 | 연속 6개 종가로 100 × (마지막 종가 / 5분 전 종가 - 1) |
| 최근 5분 시장 방향 | 계산 가능한 종목의 5분 등락률을 동일가중 평균 내 부호로 구분 |
| 최근 30분 변동성 | 30개 1분 로그수익률(%)의 표본 표준편차(ddof=1), 연율화하지 않음 |
| 당일 누적 변동성 | 첫 완료 분 종가 이후 1분 로그수익률(%) 제곱합의 제곱근 |
| 당일 누적 거래량 | 09:00부터 완료된 분봉 거래량 합계, 주 단위 |
| 평소 대비 거래량·변동성 | 현재 값 / 이전 최대 20거래일 같은 시각 값의 중앙값, 유효 15일 이상 필요 |
| 하락 종목 비율 | 최근 5분 등락률이 음수인 종목 수 / 계산 가능한 종목 수 |
| 업종별 움직임 | 같은 업종의 관측 종목별 등락률을 동일가중 평균 내고 하락 비율도 계산 |
| 종목 간 동조화 | 최근 60개 1분 로그수익률의 종목 간 상관계수를 평균, 계산 가능한 비상수 종목만 사용 |
| 동반 하락 비율 | 최근 60분 중 유효 종목의 80% 이상이 하락한 분의 수 / 60 |
| 위험 신호 | 최근 5분 평균 등락률 ≤ −1%, 하락 종목 비율 ≥ 80%, 평소 대비 변동성 비율의 중앙값 ≥ 2배를 각각 판정. 연구용 기준 |

09:00~15:20 연속매매 구간을 대상으로 합니다. 완료되지 않은 분과 동시호가는 제외합니다. 가격은 원입니다. 최근 집계의 유효 종목이 80% 미만이면 NULL입니다. 누적 거래량과 누적 변동성은 당일 분봉이 빠지면 NULL로 두고 확보한 거래량은 observed_volume에 별도로 기록합니다. 자료 부족을 0으로 채우지 않습니다.

업종 분류, 전일 종가, 같은 시각 이력이 없으면 해당 결과는 NULL입니다. 일부 종목의 결과를 코스피 전체라고 표시하지 않습니다. 위험 신호 임계값은 연구용 규칙이며 검증된 예측 경보가 아닙니다.

## 시각과 저장

시각은 UTC Z 형식입니다. 공급자 event_time과 수신 received_at은 구분합니다. 날짜 추정과 미확인 세션은 그대로 표시하세요. 분봉 종료시각을 실제 체결시각으로 대체하지 않습니다. 세션 인증 없이 신선한 운영 시세라고 판단하지 않습니다.

로컬 참조 구현은 1분마다 계산합니다. Fabric도 동일한 완료 분 기준으로 연결하세요. 원문, 분봉, 스냅샷을 계속 저장하고 장 마감 후 누락과 중복을 확인해 일별 담당에게 전달합니다. 장중 스냅샷은 UI와 AI 근거용이며 확정 일별 ML 입력을 덮어쓰지 않습니다.

## 확인 범위

[참조 계산 코드](../../fabric/realtime/reference/realtime_market_state.py)를 제공했습니다. 저장된 실제 200종목 분봉으로 11일, 44개 시점을 재생했습니다. 이는 계산 검증이며 Fabric 배포나 실제 WebSocket 지연 검증 완료를 뜻하지 않습니다. 일부 종목은 보관된 DART 업종 코드로 집계합니다. 전체 업종 분류와 200종목의 같은 시각 장기 기준값은 추가 확보가 필요합니다. daily_state_date는 전달받은 확정 일별 기준일이며 확인하지 못하면 NULL입니다.
