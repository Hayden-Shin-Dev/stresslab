# ML 데이터 전달 계약

기존 스키마와 예시는 폐기했습니다. Git 이력에서 이전 내용을 확인할 수 있습니다.

기존 Ridge 모델을 유지하고 현재 시장 상태와 과거 사례 검색을 연결하는 구조를 검증하고 있습니다. 채택할 입력값이 정해지면 Fabric에서 분석 담당에게 전달할 Gold 테이블 하나로 정리합니다.

Fabric 내부 Bronze와 Silver 구성은 담당자가 설계합니다. 최종 계약에는 Gold의 컬럼, 타입, 단위, 기준시각, 충격 관측 구간, 정답 수익률 구간, 품질 조건만 정의합니다. 아직 확정된 Gold 스키마는 없습니다.
