# 데이터 전달 기준

Fabric 담당자는 [테이블 안내](tables/README.md)와 [컬럼 목록](tables/fabric-columns.csv)을 확인하시면 됩니다. 실제 데이터는 Lakehouse Delta 테이블로 전달하며, 이 저장소에는 정의와 합성 예시만 보관합니다.

| 담당 | 작업 위치 | 결과 |
| --- | --- | --- |
| Fabric 1 | fabric/batch | 과거 데이터 정제, 확정 일별 상태 |
| Fabric 2 | fabric/realtime | 시세 수신, 분봉 이력, 장중 및 잠정 상태 |
| 분석 담당 | analytics | 사건 생성, 유사도 계산, 포트폴리오 재현 및 검증 |

Fabric이 최종 손실액이나 미래 정답을 만들 필요는 없습니다. 분석 담당이 일별 수익률에서 동일한 5거래일 구간의 종목 반응을 만들고, 같은 구간의 거시 변화와 연결합니다. 이 미래 구간 자료는 과거 사건의 결과이며 현재 시장 상태 피처에 포함하지 않습니다.

사용자가 입력하는 충격은 API 요청으로 별도 전달받습니다. 과거에 관측된 충격과 사용자 충격을 같은 값으로 취급하지 않습니다. DART는 공시 근거이며 무조건 ML 피처로 넣는 데이터는 아닙니다.

v1은 데이터 전달용 초안입니다. 잠정 검색의 성능이나 임의 충격 계산이 검증됐다는 뜻은 아닙니다. 피처 선택과 검색 가중치는 분석 담당이 별도로 검증합니다.
